## Closed technical boundaries

### Destructive operations

Compile replacement, source persistence/deletion, storage switch/drop/reindex and transaction restrictions have stop-loss behavior. Failed replacement cannot destroy the previously confirmed workspace or persistent generation.

### Mind ownership

Request-local and published transaction Minds have explicit ownership and cleanup paths across success, exception, JVM `Error`, logout, expiry and shutdown.

### Session authority

The parent gateway is the only supported browser session authority. Credential rotation, validation and logout are generation-aware and preserve local recovery state under transport uncertainty.

### Rendering

Plain values render as text. The narrow legacy description channel recognizes only exact bold/line-break tokens. Interactive choices and semantic objects use explicit DOM construction and listeners. New history records are versioned plain UTF-8 payloads.

### Operation sequencing

Only one authoritative mutation is active. Reads and semantic snapshots are generation-aware. Six semantic views publish through one coherent barrier, and late timed-out mutation responses trigger resynchronization rather than stale UI completion.

### Workspace semantics

Authenticated responses carry one canonical post-operation source, storage and transaction projection. Browser guesses cannot override confirmed server state.

### Containment and errors

The supported console runs in `sandbox="allow-scripts"` without `allow-same-origin`. The bearer remains in the parent and child requests cross a source/origin/generation-validated broker. Browser failures distinguish application, operation, session, transport, protocol and containment domains.
