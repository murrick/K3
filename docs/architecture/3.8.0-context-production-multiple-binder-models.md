## Representation and proof obligations

The relational interpretation now keys original choices by an immutable
`Binder(Source, ordinal)`, not Source alone. This is a model-choice identity;
it does not construct a native transport Origin or create proof authority.
Transport Origin construction, native capture/binding and branch audits remain
unchanged. Every original slot is evaluated with its own ordinal. All occurrences
of one ordinal agree; distinct ordinals may coincide. Opposite truth requirements
can force different values without turning identity into inequality.

Search discovers every original binder and retains its selected value for the
matching actual final Origin. Original bundles with multiple binders route the
automatic writer to the relational backend even when every predicate is unary.
The older explicit-basis unary path is unchanged. Primary bundle rank remains
at most four, inherited from the existing capture/native profile; no arbitrary
mixed quantifier or multi-Origin native-literal support is implied.

The independent original auditor preflights every declared ordinal and its
actual occurrence, concrete value and exact Source ownership before truth.
Missing/extra choices or collapsed opposite demands fail. The witness budget
counts each choice across all logical cuts, independently of search.
The final auditor validates Origin ordinals against whole original source ranks,
checks exact final inventories and requires every original binder's same value
at the barrier. Imported Origin choices also have an independently checked global
budget. It cannot replace binder 1 with binder 0 merely because their Source is
the same. A valid original receipt alone still cannot authorize publication.

Independent A-X and B-X interpretations may choose different values for the
same Source/ordinal. TRUST still qualifies all physical members as one cut.
Chosen denotations remain hypothetical model values, not persisted facts.
