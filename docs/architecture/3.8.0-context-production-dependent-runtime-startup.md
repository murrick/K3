## Fresh entry and first pass

Automatic inspection obtains a new `ContextDependentRuntimeModelInspection` result from the actual parent/child and complete cuts. This freshly reconstructs the exact append manifest and supported base/proposed families, checks all four native original/final model obligations, projects all raw proposed occurrences and independently checks indexed shape/truth. Invalid guesses or exhausted preparation bounds return INCOMPLETE with no retained startup/iteration prefix.

The checked proposed family/history is the first input boundary. It is not an empty-family bypass of candidate qualification: the existing preparation may already have a stable supported family. The loop independently reprojects/audits that input and requires its raw obligation count to match fresh startup qualification. It then discovers the first plan automatically and follows the same producing/complete-receiving/source/model/typed/frontier cycle as every subsequent pass. There is no fabricated first production, receiving history or extra two-barrier transition. A private configuration-only bounds/rebase request is never inspected as a first-barrier capability.

A first pass with no discovered residuals is permitted. It still replays a complete producing and receiving boundary, checks actual originals and final raw obligations, constructs/audits its received frame, and compares the complete typed/full-Source/minimum-depth frontier. Empty discovery alone does not assert semantic completeness or skip qualification.

## State, models and failure

Successful automatic results have `first == null` and a fresh historical `startup` preparation, immutable cycles and the final received frame/frontier under the owned STABLE_PENDING epoch. The old runtime/model getters cannot advertise the startup frame as the current state. The existing provider checks the common preparation's row policy under its owner lock/currentness guards, retaining only complete stable iteration results. Wrong-thread preparation, replacement, failure, native changes and close retain the established lifecycle.

Initial interpretations come from the preparation's parent-original proposed model map and are rebound only through the freshly reconstructed append manifest. Each subsequent receiving interpretation remains separate and may choose other witness values without changing native Cvars or symbolic function graphs. Supplying interpretations is still required; this stage does not construct or search models. All native original and raw receiving/indexed checks precede stability. No native fact, revision, factory row or durable packet is written.

Every automatic preparation/round failure clears startup, first, frame, frontier, cycles, history, counts and epoch. Actual base/candidate source refusals retain their distinct source-only preparation evidence with no runtime/iteration capability. Late round refutations retain only their sourced opposition evidence. Interruption preserves its flag and throws; changed actual views throw through final guards. Resource limits bound their named passes, not unrestricted inference termination or whole-process heap/CPU.
