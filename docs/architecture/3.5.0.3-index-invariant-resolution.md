# KANGER 3.5.0.3 — Index invariant resolution

## Scope

This checkpoint resolves the first three invariant candidates recorded for:

```text
kanger-data-dumb/src/org/kanger/storage/Index.java
```

The work is intentionally narrow. It does not change the index file format, block layout, public ID domain, or the effective empty-key exception contract.

## I1 — `IndexOne.compareTo`

Historical implementation:

```java
return (int) (id - indexOne.getId());
```

This violated the `Comparable` contract for the full `long` domain through overflow and narrowing.

Resolved implementation:

```java
return Long.compare(id, indexOne.getId());
```

The internal index maps are keyed by `Long`, so this correction does not alter block ordering or persistence layout.

Regression gate:

```text
IndexOneComparableSafetyRunner
```

It covers ordinary ordering, negative IDs, full-range boundaries, distances greater than 32 bits, equality, and antisymmetry.

## I2 — empty `firstKey()`

The effective historical behavior is retained:

```text
empty Index.firstKey() -> NoSuchElementException
```

The apparent `-1` branch remains unreachable. Returning `-1` was not adopted because `-1` has not been proven outside the public ID domain.

No executable semantic change was made for I2.

## I3 — empty iterator factories

Historical behavior:

```text
empty iterator()     -> null
empty iterator(true) -> null
```

This violated the `Iterable` boundary and caused ordinary consumers to fail outside the iterator abstraction.

Resolved behavior:

```text
empty iterator()     -> non-null iterator; hasNext() == false
empty iterator(true) -> non-null iterator; hasNext() == false
```

`IndexIterator` now recognizes the empty index after `flush()` and completes construction without asking `baseIndex.firstKey()` or `lastKey()`.

The public factories no longer translate arbitrary construction failures to `null`. Unexpected failures are surfaced as `IllegalStateException` with the original cause.

Regression gate:

```text
IndexEmptyBoundarySafetyRunner
```
