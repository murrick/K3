## Concrete obligation

With `!@a $u @b rel(a,u,b);`, `!q(2);` and receiver `!@a @u ~(rel(a,u,1)&&q(a));`, the first match yields a symbolic `rel(a,u(a),1)`. Resolving `q(a)` later binds `a=2`. Exporting only the first match's own substitution would leave an obsolete unresolved application in the materialization input. The correct whole-chain result is `rel(2,u(2),1)`. This demonstrates a handoff requirement, not a newly proven defect in the existing production materializer: the dependent adapter is not activated there.

## Handoff

`NativeDependentMatchFrame.materialize(Match)` first rechecks the complete actual proof. It applies the producer's own substitution and every subsequent substitution to the entire producer atom, including declaration-ordered binders. It also applies every substitution to the whole initial receiver. The final residual, cumulative depth and whole Source union accompany the result. Each producer retains its own Source in chain order; the receiver retains its whole original Source and native clause index.

The immutable partial snapshot stays symbolic and is never updated by later matching. The immutable complete snapshot can share canonical application nodes across producers while preserving unresolved universal parameters. Refutation does not require inventing ground names. `verify(Materialization)` replays the underlying proof and recomputes the handoff against the exact current whole inventory. Work and proof-depth limits cover composition; quadratic composition is bounded, not a performance or completeness claim.
