# Stage529: bounded construction of all-value dependent interpretations

`ContextDependentModelSearchInspection` constructs interpretation tables instead of accepting them from the caller. It freshly runs the supported native family diagnostic, observes actual originals and every raw common/private final occurrence, searches per-cut total quotient tables, and independently confirms native-original, detached-final and indexed-runtime truth. Results are MODELLED_PENDING, actual sourced REFUTED, or INCOMPLETE. No interpretation choices become native facts, Cvar assignments, revisions or durable state.

## Schema and value domain

The caller supplies an ordinary concrete ALL-other representative, optional additional typed palette points and resource bounds. Every actual native/final typed constant is collected automatically into the relevant cut's named basis, deduplicating by semantic typed equality. Numeric and string values stay distinct. Required constants cannot be omitted; the ALL-other representative must lie outside every named basis. Extra palette points are model partitions, not assertions. A named-point limit can make construction incomplete.

A separate observer reconstructs predicate signatures, exact physical Source/binder declarations and their preceding-universal dependency rank from actual native rows. Each independent cut includes X and its own physical members. Whole TRUST members share one model. Final common/private graphs additionally contribute their vocabulary, constants and imported functions; importing a graph does not import the foreign original as a premise. Full Sources, repeated occurrences and strict-superset alternatives remain audit obligations.

The generated models interpret the entire admissible value domain by named classes plus ALL-other, rather than testing only named examples. Functions are total class tables with exactly their declared dependency arity. Different witness origins may choose the same output. Required signatures/functions must match exactly in the independent auditors, with no missing or extra declaration.

## Search and refusal

For each cut, search first tries uniform relation and function defaults. It then enumerates full finite class tables when the palette has multiple classes, storing non-default cells as exceptions over false/zero defaults. Function and relation assignments use iterative mixed-radix cursors, without arity bitmasks or recursion by rank. Uniform successes avoid Cartesian expansion even for65 dependencies. Dense class-cell counts are checked by bounded multiplication before allocating tuples. The full table format can express nonconstant witness functions, not just one value per existential.

The candidate-attempt limit is shared across all cuts and both phases. Construction/schema work and the native audit-work budget are separately shared; native original/final per-attempt allowances remain explicit. Model table/exception storage, search choice cells, palette, raw occurrence, projection/copy/audit/indexed shape/truth limits are separate. Named limits do not promise whole-process heap/CPU or termination of unrestricted inference. Search order is deterministic for the observed descriptors, but bounded success is not a general completeness or performance guarantee.

Only a typed internal false-truth result rejects an individual guess and advances search. Unsupported shape, changed views, missing declarations and exhausted audit work are not retried as false interpretations. Existing supplied-model APIs retain their statuses/messages; false native truth remains an IllegalStateException subtype. After each chosen cut, only local temporary state holds that model. If any later cut or confirmation fails, the result exposes no models, family, frame or positive audit counts; tried is only spent search work.

Exhaustion, a too-small chosen quotient, or unsupported language gives INCOMPLETE, never a logical no-model proof. REFUTED is returned only from the fresh native family's actual sourced collision result, before search. Existing native false-conflict/missing-conflict gates remain open; this feature does not repair them or activate ordinary admission.

## Independent confirmation and lifecycle

Search candidates are checked directly against native originals and actual detached final graphs. The formula/graph audit does not use the generator's clause encoding to decide truth. A fresh whole-family confirmation repeats both passes after all cut models are found. The exact checked history is then losslessly projected and independently audited as indexed DAGs; indexed truth must cover the same raw obligations. Search cannot expose a model after original truth alone.

Internal numeric bounds allow the projector/indexed auditor to consume this independently qualified family without fabricating an append request. The public fresh-append projector still requires an actual qualification request. Native original formula truth, detached graph truth and indexed graph truth remain separate consumers; the checked positive-prefix decoder is shared with the existing language observer.

The pending provider's `inspectDependentModelSearch` reconstructs the actual whole topology under existing owner/currentness guards. It is read-only and retains no live capability: successful or incomplete search preserves a prior still-current prepared capability. Wrong-thread, changed-child and closed-lease calls refuse. Results are detached historical interpretations, not reusable write/settlement authority. Interruption preserves its flag and throws. No caller-supplied family receipt replaces fresh qualification.

## Controls and continuation

Controls cover nonuniform numeric/string tables, actual derived obligations, a nonconstant dependency function, a consistent two-class theory that is INCOMPLETE in a one-class quotient,1/7/17/65 dependencies, coinciding witness choices, independent disagreement versus whole TRUST refutation, imported foreign function tables without imported premises, negative facts plus imported positive graphs, both cut orders, an independent8-valuation oracle over32 native clause subsets, shared cross-cut limits/no-prefix, early Cartesian refusal, hard audit-limit classification, final/projection/indexed-only failure and actual provider guards. A separate QA checker reconfirms returned models; its deliberately false imported interpretation satisfies all originals but must fail both final and indexed truth.

This is standalone fresh-family model authoring. It is not yet automatic base/proposed/receiving-model construction inside the startup/iteration controller; preserved parent-original Source rebasing and changed receiving states still need their own fresh integration. Broader quotient/palette search, model-search pruning, resource scaling, ordinary integration eligibility, native RED/full-family/default gates, signed/multi-cut recovery, unused-prefix/broader language, config/compiler caches/provider-retained/branch results and Question3 remain open. Semantic01/02/03 and public manuals are unchanged.
