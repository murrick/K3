## Architectural model accepted

### 1. Three ownership levels

```text
Escalera = Mind-visible transactional linked snapshot
IBase     = one logical persistent schema/address space
IData     = owner of one selected physical storage generation and its bases
```

None of these levels may absorb the ownership of the others by terminology alone.

### 2. Linked order is authoritative

Escalera and persistent storage traverse `IStep.next`. Numeric IDs, hashes, DUMB index positions and cache entries accelerate or address records but do not define semantic chain order.

### 3. Snapshot checkpoints are not durability commits

`Escalera.mark/commit/release` manage LIFO root frames. They do not flush storage. `Escalera.update()` is the materialization boundary that converts the leading memory Step segment to persistent Sapato records through a borrowed IBase.

### 4. Storage bases are borrowed

Factories and Escalera borrow schema-specific IBase references from the User-published generation. User/IData own generation acquisition, publication, flush, close, remove and storage-wide reindex sequencing.

### 5. Cache categories remain separate

```text
Escalera maps/sets = derived snapshot acceleration metadata
IBase cache        = implementation-specific physical hydration/storage cache
factory cache      = canonical unit and transaction visibility boundary
```

No cache metric or acceleration index is semantic authority.
