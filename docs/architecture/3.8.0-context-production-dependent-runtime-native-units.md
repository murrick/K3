# Stage523: original native units as runtime execution donors

The checked runtime executor now accepts `Donor.original(Ref)` alongside visible runtime occurrences and internally earlier outputs. The reference names the physical context and native primary rule; the owning preparation binds its exact current Source. The whole original must be a unit. A literal selected from a larger rule, a missing original, or a unit outside the receiving cut is refused.

## Whole native capture

Positive primary units use the existing checked leading-prefix observation. Universal binders become symbolic variables keyed by their original declaration positions. Each existential binder becomes an APPLICATION with the exact original Source/binder and the ordered tuple of all preceding universals. Later universals never become dependencies of an earlier witness. Ordinary values remain typed VALUE nodes. A witness does not receive a model-chosen concrete value or scalar native Cvar assignment.

Negative ordinary units use their whole signed native literal, retaining repeated variable slots and typed constants. Each native unit contributes its singleton whole physical Source and depth0. The existing executor freshly instantiates each donor use, preserves correlations within a use, and applies one substitution across all pivots. Mixed original/runtime/earlier chains retain complete support unions and depth1+max(donors). No Source alternative is minimized.

The original lookup allows X and the actual physical members of the selected receiving cut. Independent B cannot borrow A's original unit even if declaration metadata or a possible model is known globally. A TRUST cut can consume originals from each of its physical members. Function Source identity remains the declaration's physical origin, not the receiving context or a textual predicate/native-id alias.

## Direct native certificate verification

The independent execution auditor recognizes original donor references and rereads the actual native unit. It checks the instantiated donor tuple directly against that unit's native prefix or signed literal, using the per-donor substitution certificate. It does not call the executor's native-unit graph builder.

For each used existential slot it verifies Source, binder position, dependency rank and each ordered preceding-universal argument. Universal slots and repeated occurrences must equal their certified bindings; constants must remain exact typed values. The variable manifest contains the exact reachable universal declaration positions. Positive and negative signs, whole singleton Source ancestry, depth0 and receiver visibility are checked before the existing whole-step proof audit completes. The shared prefix decoder and ordinary-clause parser remain common infrastructure; this is not an independent language parser or most-general-unifier theorem.

A QA-only probe alters witness dependency order, binder identity, native donor roots and variable manifests, confirms certificate refusal, restores fixtures and audits again. No production mutation seam is exposed.

## Outcomes and ownership

EXECUTED_PENDING still denotes local checked proof outputs. A rigid failure is NO_MATCH for the explicit recipe and proves no inequality or semantic falsity. Invalid original references/nonunit inputs and exhausted bounds remain INCOMPLETE with no earlier successful execution/preparation prefix. Model guesses do not become input facts. Interruption/currentness and the provider's existing owning-thread/epoch/topology/parent-child-retained guards remain in force. Original donation requires no caller-supplied frame or diagnostic receipt and changes no native factory/revision.

This stage does not broaden the native observation language. Unused prefix binders remain explicitly unsupported by the existing decoder and produce INCOMPLETE before donation. The default engine's known RED gates remain open. Native units extend the donor vocabulary of the scoped executor; they do not change query, orphan/hypothesis or admission semantics.
