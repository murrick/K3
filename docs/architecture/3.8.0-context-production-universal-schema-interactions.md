## Concrete starting barrier

The stage3en family counterexample and stage3ep local route controls retain
`unbound-waiter-composition:<rule>` as an outstanding native schema gap. Before
this stage that string names only the literal owner's native Rule. It does not

proofs can be reconstructed, but cannot establish complete universal coverage.
The existing structural `Clause.resolveWithUnits` can compute a principal flat
resolvent; it alone supplies neither native observation nor Source authority.

It does not erase the prior refusal or treat computed resolvents as knowledge.

## Native capture

`ContextProductionCapture.observeSchemaInteractions` explicitly enables metadata
for the existing waiter-composition callback. Each detached `SchemaInteraction`
contains both whole branch clauses, their exact pivot positions, both native
Rule IDs and their actual primary producer label alternatives. Whole declaration
shapes preserve variables even while native arguments have transient bindings.
Pivot indices are recovered after structural literal deduplication, retaining
correct positions when the original branch repeats a literal. No live Mind is
retained in the record.

Both endpoint shapes must be captured within8 branches/8 literals/8 arguments.
Failure to obtain the endpoints retains a separate unobserved-schema gap. Every
record consumes the existing capture event budget. The old raw schema gap is
always preserved; opt-in metadata does not change the ordinary strict path.
Snapshots expose the immutable records and observer-state flags.

The observer also records whether an encounter occurred before opt-in or failed during typed recording. This
missed-history flag is sticky: a later native pass with identical Rule IDs does
not retrospectively complete the earlier journal. Disabled observation is not
evidence that no schema interaction existed.

## Symbolic audit

`ContextUniversalSchemaInteractionAudit` operates on the exact active replay/
capture boundary and retains its replay UUID. Both whole original native-bound
Entries, every corresponding shape and the complete actual singleton Source/
depth0 primary label alternatives must match. Omitting an owner/alternative or
substituting equal text under another Source fails without an obligation prefix.
The component authenticates semantic provenance; connection/provider-lease
eligibility remains a separate owning-frame requirement.

The supported encounter has one positive variable-containing unit and one
positive definite, range-restricted Horn clause, resolved at its negative body
pivot. Unification standardizes parent variables apart and preserves fixed values
and repeated-variable equalities. The output is an immutable symbolic obligation
with its exact whole-source alternatives. The residual may itself be universal:
`forall x gate(x)` plus `forall x (gate(x)->mid(x))` requires `forall x mid(x)`;
no finite set of mentioned values is substituted for this statement.

A native attempt may have incompatible constants or repeated-variable bindings.
That case is explicitly `unifiable=false`, with no resolvent. It is not an empty
resolvent or a collision. Other unsupported clause interactions, missing metadata,
exhausted capture/work budgets and pre-observer encounters leave the audit
incomplete with an empty obligation list. Shared work accounting bounds the
entire audit. Source pairs refer to original whole rows; a unit and Horn conjunct
in one original row use that same Source once, without synthetic clause Sources.

`observedComplete` means only that this journal's observed encounters have been
checked within the supported scope. It does not certify that native traversal
visited every theoretical interaction or that all residual obligations are
proved/retained. A vacuous observed list is not full theory coverage. The initial
compound/compound test fixture actually produced no callback; it was replaced
by an actual unit/multi-head encounter for the unsupported-shape control, rather
than treating absent observations as coverage.
