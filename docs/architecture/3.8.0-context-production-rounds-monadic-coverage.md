# Monadic Horn coverage of qualification production rounds

Status: bounded reference contract, stage2g. This is not a runtime publication
gate, a DMZ replay certificate, or a completeness claim for the full language.

## Admitted compiled shapes

All primary occurrences in X and every effective participant must pass the
same structural check. Each occurrence is compiled alone in an isolated Mind;
this preflight never combines sibling knowledge. Every native branch must
have a detached shape. Shape observation preserves declared TVariable roles
even when the live variable has a current value; it is not a proof-pool input.

The admitted forms are:

* Positive or negative unary units. An argument is a named/string or numeric
  scalar, or a universally quantified variable.
* Ground definite Horn clauses over unary predicates and those scalar values:
  zero or more positive premises imply one positive head.
* Uniform universal definite Horn clauses: all arguments in the clause are
  the same variable, with positive premises and one positive head. Multiple
  premises and multiple compiled branches are permitted.

There must be at most one distinct native TVariable in the entire primary
rule, not merely in each branch. Native rotation collects variables across
all branches; multi-variable tuple filtering is deliberately outside this
certificate. A clause mixing a variable with a fixed argument is excluded.
Functions, calculated/system predicates, local rule IDs, C-variable witnesses,
structured arguments, multiple positive disjuncts and non-unary predicates
do not receive this certificate. Existing source-gap checks still apply.

## Why finitely many representatives suffice

Let C be the finite set of semantic scalar values occurring anywhere in the
primary family. Include constants in ground rules as well as units. Let e be
a fresh arbitrary parameter absent from every primary value, verified by exact
semantic comparison. Values are vocabulary, not predicate assertions: collecting
a scalar from B does not import B's fact into A.

For this ordinary unary Horn signature, each universal clause acts at one
argument value. Ground clauses can couple the finitely many values in C, but
they mention no value outside C. Universal units constrain every value alike.
There is no function, equality/type test, destructuring term or additional
variable in a universal clause that could distinguish two unnamed values.
Thus all scalar values outside C have the same source constraint pattern.

Restricting a model to C and a representative unnamed value gives a model of
the finite representative theory. Conversely, a model of that theory extends
to the remaining scalar values by assigning each the representative's unary
predicate pattern. Ground clauses are preserved because their values are all
in C; uniform clauses are preserved pointwise. This establishes the finite
reduction for the ordinary scalar producer surface admitted above. It does not
add interpreted rich-term semantics to this surface.

The finite representative theory is Horn. Forward unit propagation obtains
its least positive closure; a violated negative unit refutes it. Additional
sound signed-unit propagation and reductions of clauses cannot destroy that
refutation completeness. This argument concerns consistency of the supplied
qualification cut and its native unit/residual production process. It does not
claim enumeration of every entailed negative fact, every consequence obtainable
by hypothetical assumptions, or the query/orphan protocol.

## Connection to the implementation

Ordinary private closure runs first so synthetic bindings do not suppress a
previously discovered ground proof. A fresh replay then seeds all native
variables with every representative in C and at least one fresh parameter when
the rule has a variable. All represented values are canonically projected.
No parameter predicate, knowledge source or waiter assumption is installed.

Within the admitted rule shape there is only one native variable, so the
rotator visits each supplied value. Multi-variable TSolve joins are absent;
the existing unary tuple behavior does not filter these rotations. Ground
unit applications use the exact-match mechanism qualified by the stage1 fix.
Inference and binding remain entirely native.

The observer records proved applications before stored-conclusion suppression
and records residual clauses at their live binding. Proof closure reconstructs
every premise from primary or already proved units and retains whole source
sets. Missing reconstruction, unlabelled applications, unobserved materialization
and all other gaps stop certification. Only the generic waiter gap is discharged
by the admitted shape plus the completed representative pass.

Each participant reaches private closure using fresh replay. Foreign-only
intermediates remain private. Only results with an X-dependent proof enter the
next immutable round. A parameter result is generalized by semantic parameter
identity; repeated argument identity is retained. Source-group alternatives and
minimum carried depth remain separate from the generalized clause.

The ordinary producer vocabulary, representative set and source occurrence set
are finite. Signed units and reduced Horn clauses therefore have finitely many
semantic/source-group entries. The algorithm stops when no new entry or improved
minimum depth is added. Event, work, depth, rank and comparison budget stops
return INCOMPLETE; they do not prove termination of arbitrary native programs.
The implementation precharges planned added rotations, but does not claim
complete CPU/memory accounting of native compilation and inference.

The completed reference reports `Coverage.MONADIC_HORN` only with SATURATED.
COLLISION needs a native witness and no saturation certificate. Unsupported
quantified primary shapes report INCOMPLETE with
`unproved-symbolic-coverage` after preserving any individually proved products.
Legacy ground-only observation closure can still report SATURATED, but with
`Coverage.NONE`; it does not inherit this new certificate. A future runtime
consumer must respect the coverage scope, not merely the status name.

## Proven counterexample to the previous symbolic boundary

```text
X: @x (p(x) || q(x))
A: @x (~p(x) || q(x))
   @x (p(x) || ~q(x))
   @x (~p(x) || ~q(x))
```

Each Boolean valuation of p and q violates one clause. Under the author's
confirmed arbitrary-value quantifier semantics, no valuation at value1 is
possible. Native monolithic controls reject both additional p(1) and ~p(1).
The intermediate reference nevertheless returned SATURATED: there was no
universal unit waiter, so no generic waiter gap was recorded. Absence of such
a gap was not evidence of coverage.

The new primary-shape boundary returns INCOMPLETE for this case. It does not
invent a native collision witness, add a second runtime resolution engine, or
alter Core inference. Raw pre-guard evidence and its probe are retained in
`target/context-production-rounds/evidence-stage2g/` and the driver includes
both an independent four-row truth table and the native controls.

## Validation and remaining limits

The independent finite test oracle enumerates all64 two-predicate combinations
of two directed rules, universal positive roots and ground negative units.
It computes positive reachability independently of native inference and checks
collision versus a completed scoped certificate. Additional controls cover
consistent cross-participant chains and whole X/A/B support at depth2, negative
universal propagation, named versus numeric representatives, sibling opposite
universals, the constant-head exclusion, binary argument exclusion, declared
shape survival under live binding, and multiple variables hidden in separate
unary branches of one native rule.

Previously proven multi-variable products, positional matches, signed heads
and alternative supports remain checked. Their final status is now INCOMPLETE
where complete symbolic coverage is unproved; the proofs themselves are not
discarded. Positive native collisions still take precedence.

Next coverage extensions need explicit proofs for multiple argument positions,
multiple variables and tuple filtering, interpreted terms, and witnesses.
Real effective-view/pin verification and shared atomic runtime gates remain
pending. Query/hypothesis/orphan semantics and DMZ proof-restriction completeness
remain outside this certificate.
