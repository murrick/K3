# Stage2l: detached multi-premise residual obligations

This is a preparatory checker, not a wider saturation certificate. Neither the
runtime write gate nor the admitted scope of AUDITED_LINEAR_HORN changes.

ContextHornResidualVerifier consumes externally observed clauses and whole
supports. Its bounded input is definite Horn clauses of at most three literals
and two clause-local variables, instantiated over the caller's finite basis.
For every nonempty subset of literals whose opposites have proved ground units,
it requires an existing proof of the remaining ground clause. Every Cartesian
combination of whole producer and donor support groups is checked separately.
The required source group is their union; the maximum permitted minimum depth
is max(producer depth, donor depths)+1. An asserted unit instead needs its
producer's unchanged depth. Exhaustion propagates to the caller, never success.
No missing residual, unit, collision witness or native binding is generated.
An entirely falsified clause refuses certification rather than manufacturing a
native collision report.

The subset oracle exercises all seven consistent donor subsets for
~a(1) || ~b(1) || r(1), including negative-head reduction. It constructs all
required proper residuals independently. Removing each residual, increasing its
depth or replacing its support with a foreign-only proof must fail. Further
controls preserve carried producer depth and distinct donor support alternatives.

This checker intentionally requires exact ground proof entries. It does not yet
use a symbolic residual as evidence for all ground instances. Native capture can
retain a universal residual without emitting each ground instance, so wiring
this checker into the current reference would require a separate verified
instance-evidence bridge. Primary shape metadata alone is insufficient.
The caller must establish finite-basis adequacy, native rotation evidence,
source conformance and proof authenticity. Passing this detached obligation
check alone is not a consistency or completeness certificate.

that evidence bridge before introducing any wider reference certificate.
