## Representation and policy

Whole primary capture, signed plans/direct audits and relational original/final
models carry arbitrary finite binder lists subject to charged work. Witness and
Origin map copies no longer truncate/refuse at 64. Every ordinal is still checked
against actual whole original rows, every occurrence and every actual final
Origin; no inequality is inferred from distinct identities.

Automatic requests add `rank=8` and `origins=8`; the existing `witnesses=8` stays.
All old numeric defaults remain. Rank must be positive; the two choice budgets
are nonnegative. These three settings have no small fixed maximum:

- rank limits distinct Origins per signed seed/fact packet and barrier;
- witnesses limits original Source/binder choices over all model cuts;
- origins limits imported-Origin model choices over all cuts.

A lower choice count cannot be justified by assigning the same value to many
Origins: native symbolic identities and model denotations are separate things.
Increasing rank alone does not increase global choice budgets. Symbolic formula
Origin inventories are traversed under existing work/clause bounds instead of an
unconditional eight-Origin shape rejection. Literal/predicate/row/depth/candidate/
cell/fresh-value limits are unchanged; bounded search is still incomplete.

## Propagation and independent checks

The exact signed frame policy reaches initial and successor seed/fact barriers,
private scopes and constraint transfers. Independent initial/successor union
audits receive that same configured rank and count actual coordinates. Legacy
transport and the four-argument union audit retain rank8 where no explicit signed
request is present. The older unsigned row classifier still refuses its prior
unsupported wide-rank profile. Manual/default writers are not redirected.

Relational original and final auditors independently enforce global witness and
imported budgets. Lowering the recorded rank to64 cannot certify65 actual Origins.
Missing original/final ordinal64 also fails. A valid original model can still be
rejected at the final imported-Origin barrier; original truth alone is never
permission to publish.
