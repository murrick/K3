# Stage3v: separate Horn models at a closed common unit frontier

ContextGroundHornFamily adds a bounded synchronous unit executor and a detached
consistency certificate for the existing ordinary signed cut scope, restricted
to Horn clauses (at most one positive literal). Every orientation must satisfy
the stage3u variable-binding guard. Witnesses, universal units, interpreted/
structured values and unbound reverse heads remain outside this scope. These
restrictions are checked across the entire selected family before any replay.

Each round evaluates self and every independent X–foreign cut against exactly
the same sealed input. A complete merge may return sourced COLLISION; otherwise
INPUT_STEP obligations must be covered. Changed proof alternatives/depths require
another round. An unchanged shared pool is still insufficient: the final
certifier repeats exact-input merge authentication, requires unchanged state,
checks LOCAL_CLOSURE obligations and excludes opposite local proof atoms in each
cut. Success returns UNIT_FIXED_POINT with a privately constructed UnitCertificate bound
to that exact immutable frontier. Failure/stops return INCOMPLETE without any
certificate/collision prefix. Limits are explicit per phase/cut and include a
family round limit; there is no promise of arbitrary inference termination.

The certificate is detached diagnostic authority for these exact native-bound
snapshots. It is not a live database write permit. No default or explicit
candidate gate is redirected in this stage.

## Model argument

For each cut separately let P contain all its actually proved positive ordinary
ground atoms, including original units and shared X-dependent inputs. Interpret
exactly P as true and every other ordinary ground atom as false over all
admissible values, including unmentioned ones. Constants retain their semantic
identities. No raw atom from another foreign cut is added.

Positive primary units belong to P. Negative primary/carried units are satisfied
because opposite local proofs are excluded. Consider any ground instance of a
nonunit Horn clause. If any negative body literal is true, the clause is already
satisfied. Otherwise all its corresponding positive body atoms belong to P.
The coverage matcher considers their coherent donor combination. The head is
bound by the supported-scope guard; no finite enumeration of the domain is used.
For a positive head, local closure requires an observed positive head in P. For
a purely negative constraint, choosing any literal as head requires an observed
negative atom opposite its positive body atom; the no-opposition check excludes
this case. Thus every ground instance is satisfied. This is a model-existence
argument, not a claim that native proof discovery is complete: missing observed
proofs cause INCOMPLETE.

Unchanged authenticated merge ensures every exported X-dependent proof route
is already in the common frontier, including its whole-source alternative and
minimum observed depth. Consequently all independently certified cuts use the
same fully qualified shared unit productions. Their models may disagree on raw
foreign facts. There is deliberately no joint A+B model requirement.

The Horn restriction is necessary for this particular model argument. The four
p/q disjunctions of all sign combinations have no enabled unit steps but no
model; stage3u coverage alone cannot admit them. Non-Horn source rows refuse
before evaluation, including rows in a later selected cut.

## Controls

The original X left/right→p fixture with A left+p and B right+negative-p returns
COLLISION at round2 in both A/B orders, with exactly the four causal sources.
Unrelated X with opposite raw sibling p facts receives separate models and an
empty shared pool. A cross-cut a→b→c chain certifies at round3 and retains depth2
source authority. A changed pool, missing self, stale receipts and depth/work/
event/round stops cannot certify. Empty X, dormant universally quantified rules,
negative heads, pure-negative constraints, local foreign-only intermediates and
cyclic source alternatives have explicit controls.

An independent truth-table oracle enumerates all eight p/q/r assignments for
64 pairs of ground Horn declarations. Every returned certificate/refutation is
checked against that oracle: 60 pairs obtain certificates; the four contradictory
unit pairs remain INCOMPLETE without certificates (no typed refutation is
claimed for those native refusals). The original multi-cut fixture separately
exercises actual sourced COLLISION evidence. These finite oracle checks do not
replace the universal-domain argument above.

## Residual-family boundary demonstrated before integration

X `left(x)&&right(x)->p(x)`, A `left(1)`, B `right(1)` has separate Horn
models and an unchanged empty unit frontier. However an actual opt-in native
capture of X–A observes the two-literal residual `right(1)->p(1)`. The general
production protocol must carry that X/A residual to B and eventually prove p(1).
The unit-only executor cannot do this. Its runner reproduces both observations;
the reason explicitly says residual-family saturation UNKNOWN. This boundary
also exists in the earlier reference milestones, which already support compound
residuals; the new Core signed-unit transport has not yet absorbed that support.

Thus UNIT_FIXED_POINT is not a full production-family fixed point and cannot
be mapped to candidate admission. It proves existence of independent models for
the current unit-augmented cuts, plus unit-transport stability only. Next: bridge
source/depth-preserving ordinary compound residual capture, transport and
coverage into the Core signed rounds, using the existing reference controls,
before candidate/default integration. Question3, non-Horn/witness/TRUST/general
language and broader acceptance remain open.
