## Implemented boundary

`ContextWitnessSeedReplay.inspectObservedUniversals` has a separate immutable
`ObservedUniversals` result type. It binds the exact input packet/replay, verifies
all replayed whole owners against native-bound original Entries, checks ordinary
parent-X/foreign cut identities, and authenticates every zero-premise witness
observation through the stage3eo verifier. Shared native settlement/imported-seed
code is factored out without changing the strict `inspect` behavior.

A separate `observedUniversalScope` permits reconstruction in the presence of the
specific `unbound-waiter-composition` gap. The original gap list is copied to
`outstandingGaps`; other unsupported gaps still fail. This is permission to
verify individually observed steps, not evidence that schema interactions are
covered. The ordinary scope entrypoints retain their original gap rejection.

The chain verifier accepts explicit authenticated instance receipts only through
an overload used by this local path. A universal instance uses an actual imported
proof mentioning that exact canonical carried root as its binding evidence. Its
sources are the union of that anchor proof and one original universal producer
alternative, and its depth is anchor depth+1. Repeated/fixed arguments, complete
original producer binding, witness lineage and single-root scope retain the
stage3eo checks. The receipt is matched to this replay/snapshot; omitted or foreign
observations cannot become zero-premise rules by assertion alone.

Anchor alternatives are reduced only when another carried binding proof uses a
subset of sources at no greater depth. Equal support/depth is deduplicated;
incomparable source alternatives or a shorter proof remain. This reduction
selects evidence that a carried witness is available, not premises of a Horn
predicate, and does not remove any original imported proof from the pool.
Ordinary Horn joins still preserve full donor sources and add one cumulative
level. Materialization correspondence continues through the existing verifier.
No universal route is relabelled as an original depth0 primary seed.

The local result contains proof routes and outstanding gaps, not a Packet, round
receipt, covered cut or admission verdict. It cannot be passed to existing family
export APIs. Calling strict `inspect`/`exportNext` on the same native pass still
refuses its uncovered gaps. Raw private routes remain local; no common input
packet is mutated. Full universal closure/all-admissible-value reasoning and
connection/provider-lease admission checks remain required before integration
into family qualification.

## Carried-origin counterexample caught before delivery

The first local-route implementation used only the universal Source plus the
raw original witness Source at depth1. That is insufficient when a private
witness reaches another branch only through an X-dependent carried product:
it loses the actual carried X support and understates the binding depth.

The dedicated native case starts with private A seed&&flag, X anchor and
seed->pone->ptwo->pthree. Only X-dependent products cross to the common packet;
raw A seed/flag do not. In B's replay, its universal gate is instantiated on the
carried A origin, and X pthree&&gate->finish consumes it. The earliest actual
carried binding is pone at depth1 with `{A seed, X seed->pone}`. The gate instance
must therefore retain `{A seed, X seed->pone, B universal}` at depth2. A raw
`{A seed, B universal}` depth1 proof is not an authenticated carried binding.

`/tmp/k3-stage3ep-carried-origin-red.log` records the exact failed assertion on
initial experimental production classes from run-pq6tirjs. The corrected route
uses the actual imported binding proof as its prior/donor. Final focused
run-02z6hynj passes164 checks including this case. The failed experimental helper
was never committed or used by the default writer. This is a caught provenance/
depth implementation error, not evidence against synchronous rounds themselves.
