# Whole-family native engine selection (stage 3bm)

The package-private validatePendingProductionCommit adapter prepares ordinary native
commit integration. The production default validateCommit route is unchanged at
this checkpoint; tests temporarily route actual native validation to this adapter.
Existing explicit writer scopes retain their selected engine and their own limits.

The owning pending lease first binds the complete proposed X and every initialized
foreign cut. It does not classify only the new statement or accept a successfully
bound prefix. Any unsupported primary in any cut yields INCOMPLETE before inference
or selection. After binding, one bounded scan of all primary entries selects:

- WITNESS if any cut contains a native-bound witness bundle;
- otherwise UNIVERSAL if any clause in any cut contains universal variables;
- otherwise GROUND.

Selection uses bound native kinds/clauses, not an origin-text heuristic. The selected
engine runs once against those same immutable snapshots. Witness runs the existing
full-cut proof/coverage fixed-point evaluator, ground uses its closure audits and
separate checked models, and universal retains its independent family audit. Engine
results remain their existing typed diagnostics. INCOMPLETE never retries another
engine. No historical decision or partial coverage enables publication; the adapter
continues only the original native commit after a complete selected-engine result.

Both binding preparation and selection/inference/audit have bounds. The selection
scan has its own work counter; it does not claim an aggregate shared CPU budget.
Ordinary defaults reuse universal request limits plus 100000 ground probes. Explicit
attempt scopes take precedence without replacing their limits with these defaults.

The native ingress controls prove both masked barrier2 A/B orders for ground and
universal rules, full refusal evidence and parent/revision purity, sibling-only
disagreement with safe ordinary publication, ground candidate/X selecting universal
because of a foreign universal declaration, and foreign-only witness bundle selecting
the witness engine (without claiming its unsupported declaration is admissible).
Ordinary witness publication/refutation uses the witness engine; its round-bound
INCOMPLETE does not fall through. Ground model-bound and universal audit-bound
refusals similarly retain the selected engine. A foreign function row prevents a
positive collision prefix from the otherwise supported masks; an existing uncovered
witness producer cannot be hidden behind a new ground assertion. Explicit user
rejection retains its child and automatic ground qualification of the parent allows
rollback. An active explicit writer keeps its own engine and round limit.
