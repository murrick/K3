physical-child reservation, source baseline, topology and failed/closed-attempt guards are
inherited unchanged. Nested attempts are rejected; finally clears the installed selection.

unchanged: explicit pending attempts are checked before and after existing effective connection
validation. An explicit writer still checks without foreign connections. Ordinary/native
compile failures retain their ordinary acceptance/error semantics, with no fallback write.
The settled-root baseline guard retains its existing supported topology/ownership boundary;
this is not a general activation for retained user children or every trusted topology.
