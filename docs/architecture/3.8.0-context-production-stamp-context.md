## Cause and correction

The reduced theory is X ~p1(1) plus
`!@x @y @z q(x,y,z)&&~p1(x)->out(x,y,z);`, private universal q donor,
private out(x,y,z)->mid(x,y,z) Bridge and private ~mid(9,9,2).
It is consistent even as a full union. Before correction it was certified and
published by both Public and Native paths, yet ordinary reopening raised the
false opposition p1(1) / ~p1(1). Stage3cy's strict desired-behavior contract remained
RED, with exact stored source/native clauses/pins/revision checks excluding a
changed primary theory as the explanation.

A temporary execution trace narrowed this to Linker.updateDatabase's application
of an already proved production stamp. For p1, the stamp was [9], while the cached
variable's active execution view still selected its parent's current1. The
materializing Mind was15 and the variable's stale active Mind10. The canonical
(variable,9) lookup therefore used the parent's TValueFactory, returned absent,
and ArgumentsList.applyStamp silently left current1. The resulting stored
production was p1(1). The value9 was not lost from the proof stamp or persistent
primary clause.

ArgumentsList.applyStamp now selects each cached TVariable's existing thread-local
execution view with setMind(mind) before the canonical find and setValue operations.
The canonical lookup guard, TValue identity policy and proved stamp are unchanged.
This restores the requested9 in the actual materializing Mind, preserving other
current projections. No inference rule, proof Source set, storage schema, logical
consistency gate, default engine selection or resource allowance is changed.
General Argument access behavior is unchanged; the correction is restricted to
the explicit stamp-restoration boundary used by Linker materialization.

Temporary trace /tmp/k3-cz-stamp-trace.log shows requested9/find absent/stale
parent1. Narrow-patch probes /tmp/k3-cz-narrow-probe.log and
/tmp/k3-cz-narrow-authoring-probe.log confirm both compatible reopen and genuine
conflict refusal. The maintained desired-behavior contract and stamp regression are
