# Stage3av — bounded read-only universal family inspection

`ContextUniversalFamilyInspection.inspect` orchestrates the sealed flat ordinary
universal family path. It accepts actual X/foreign snapshots and explicit common
round, local round, cumulative depth, total instance, model-assignment and work
limits. Invalid numeric bounds throw; unsupported/missing evidence or exhausted
limits return INCOMPLETE. No native write consumer or storage mutation is added.

## Three disjoint outcomes

* CONSISTENT carries only the exact historical stable family certificate from
  stage3au. All cuts, including self, have independently checked all-value models;
  all exact inference/export/common-stability obligations have been rechecked.
* COLLISION carries only an immutable complete-barrier record: its exact input,
  all verified receipts, and actual X-dependent sourced opposition proofs. It is
  obtained from the existing complete merge, never inferred from a failed model
  search or from a partial collection of cuts.
* INCOMPLETE carries neither certificate nor collision evidence. Its reason and
  completed-barrier count are diagnostic; no tentative ledger/model/proof prefix
  is exposed. A completed changed barrier may be counted even when the next
  required qualification round exceeds a limit.

Every local inspection uses factored inference on the SAME immutable common
baseline. All cuts finish before merge. A changed merge begins another common
round; it cannot certify consistency at the last permitted round. Local/source
recipes keep their existing cumulative depth rules. Raw foreign facts stay inside
private cuts, and independent siblings may use opposite model interpretations.

Only an unchanged merge permits model search. Each model is bound to the exact
stable receipt closure ledger. Final certification independently reruns family
coverage and raw-ledger model checks rather than trusting search success.
Models cover all admissible values through stage3at's projection construction;
this is not a known-values-domain shortcut.

## Shared limits

One work counter spans initial family validation, every cut/local/common round,
all inference audits, every merge, model construction/check and final certificate
recheck. Package-bound helper entry points reuse this counter; existing public
helpers preserve their prior independently bounded behavior.

One model-assignment counter spans ALL private model searches. One instance
counter (capped at65536) spans their expansions, construction-time witness checks
and final family witness rechecks. A successful earlier cut cannot reset either
counter for the next cut. No models are searched in changed common rounds.
Model search failure remains INCOMPLETE, not a sourced collision verdict.

## Regression controls and next boundary

The driver covers self-only/empty foreign families, independent opposite siblings,
generic p->q requiring barrier2, the exact three-source q/~q(9) barrier2 collision
in both orders, diagonal factoring collision at barrier1, incomplete common/local/
depth/work bounds and exact model-assignment/instance allowance edges. A collision
proved in one cut cannot escape an unfinished later cut, in either order. Returned
certificates and collision barriers are independently rechecked/replayed. Evidence
lists are immutable; duplicate/null contexts refuse.

All tests use disposable native fixtures. Validation totals/recovery are recorded
in the main rounds checkpoint. No new full DMZ/reactor run is implied.
