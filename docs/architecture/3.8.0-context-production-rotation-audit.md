# Finite native rotation measurements

Stage2j adds an explicit qualification experiment, not a wider completeness
certificate. Default inspect/inspectWithParameters behavior and runtime gates
remain unchanged. Use inspectWithRotationAudit to request measurements.

## What is measured

After ordinary private closure, seed the native TValue vocabulary with fresh
parameters and all collected ordinary scalar constants. These are values only,
not predicate assertions. Register a detached audit basis before linking.
Each currently visible quantified Rule is catalogued with its entire ordered
TVariable scope and every compiled branch. For a basis of size B and rank r,
each branch has B^r possible ordered bindings. Repeated argument positions do
not add variables; separate branches do not shrink the whole Rule scope.

Two opt-in hooks record distinct binding vectors:

* Terminal admission, immediately after rotateVariables/TSolve filtering and
  before linkDomains can change current bindings.
* Database evaluation, after predicate matching and function processing, just
  before linkDatabase examines the live literals.

Only complete ordinary bindings whose values belong to the exact semantic
basis count. Numeric and named values remain distinct. Rule ID, branch index,
ordered variable IDs and argument identity are checked. Repeated passes over
the same vector do not increase its count. Snapshot metadata contains detached
counts, not native variable pointers or assumed facts.

For the configured catalogue, allRotationsAdmitted and allRotationsVisited
compare unique observed cardinality with B^r. An unconfigured capture returns
false even when its audit list is empty. These methods describe observations;
neither method is a logical inference or source/view/completeness certificate.
The hooks do not bypass TSolve or change any native binding or rule.

## Resource and scope boundaries

The audit admits rank at most3. Planned branch/phase observations must fit its
finite event budget before linking. Each new phase/vector and catalogue entry
is included in snapshot eventCount. Semantic basis comparisons, catalogue
searches and repeated callback comparisons have a separate cap of64 times the
event limit. A limit throws an explicit incomplete result in the reference.
This does not claim full CPU/memory accounting of native inference.

A changed scope or an uncatalogued quantified rule records a capture gap.
Ordinary proof reconstruction, exact transport checks and native collision
handling still run. Only the final settled private replay contributes its
missing-rotation marker to the outer round; an earlier replay may legitimately
have fewer useful bindings before new proved products are available.

The experiment preserves the structural unproved-symbolic-coverage guard.
Successful measurements on a multi-variable cut still yield INCOMPLETE and
Coverage.NONE. Conversely a missing database binding adds
missing-representative-rotations and cannot silently certify saturation.
Completed native collisions still have priority and need no audit certificate.

## Observed controls

With an otherwise unsupported p(x,y)->q(y,x) and a two-value basis, seeding
zero, one or both values for each variable yields respectively0,1,4 distinct
admissions and database bindings. Merely seeding both values without linking
records zero visits. No absent premise or consequent becomes proved.

For a real ordinary fact p(1,John) and rule p(x,y)->q(y,x), every variable is
seeded with both values. The observed run records expected4, admitted1,
database1. The matching conclusion q(John,1) is proved; q(1,John) is unknown.
Thus absence of the other Cartesian observations is not evidence of a missing
logical consequence. It does prove that seeding a full basis cannot itself
serve as evidence of full native traversal. The measurements do not attribute
all pruning to one particular TSolve condition or predicate-matching step.
In the reference's fresh private replay, already proved products can change
subsequent native bindings and make a later audit complete. An earlier missing
measurement must therefore not be carried forward as an unconditional final
gap. The constrained reference control checks the unchanged structural boundary
while retaining observations of its actual replays.

The simple universal p(x,y) / p(x,y)->q(y,x) reference experiment records14
audited branch snapshots, all with complete admissions and database counts,
and retains a proved two-variable q template. Its final status remains
INCOMPLETE/Coverage.NONE. Successful visits alone do not close the outstanding
proof obligations for multi-variable production and residual coverage.

Further controls check entire-Rule scope across multiple branches, repeated
positions, typed representatives, immutable snapshots, plan stops, event
accounting and inactive default capture. The runner is included in the focused
suite and in the DMZ manifest for future CI runs.

Next work must connect these finite observations to the supported Horn
fragment and its whole-source proof closure, or justify why pruned bindings
cannot affect the qualification result. No general TSolve defect or correction
is claimed here. Witness transport, exact effective view/pin verification and
runtime publication gates remain pending; question3 remains open.
