# Stage502: native ordinary unit/headless constraint refutations

## Before-counterexample and scope

The exact501 production Console JAR still accepts both insertion orders of:

```text
!@a @b pair(a,b);
!@a ~(pair(a,1)&&pair(a,2));
```

The first row supplies both instances for any shared a. The second forbids them.
The reproduced native gate is RED16/missing5/exit1. Stage502 repairs these two
compound cases. The three alternating existential/universal cases remain OPEN;
the same gate becomes RED16/missing3/exit1, not PASS.

The new helper proves only contradictions between ordinary positive primary
unit rows and an ordinary headless compound clause. It does not produce units,
perform general Horn saturation or decide consistency. Functions, witness slots,
system/calculated predicates and generated/query rows are excluded. All clauses
of a selected original Rule are checked and retained; a branch of a mixed
unsupported original row is never detached into an alleged ordinary root.
The entire original Rule remains the root, with its exact selected clause index.
Conjunctive positive donor rows are not split into unit roots by this scope.

## Symbolic search and order argument

NativeUniversalConstraintCollision reuses Clause.resolveWithUnits, including its
standardization of parent scopes, principal unifier, typed-value comparison and
substitution into the whole residual. It never seeds an arbitrary named value,
reads a current TValue as a universal meaning or stores a generated consequence.
This is a separate native refutation adapter, not a replacement for stage402's
sealed, sourced DMZ constraint ledger. It creates no Source, packet or admission
receipt and never claims all Source alternatives or a family fixed point.

For each headless clause, search discharges the first remaining negative literal,
enumerating EVERY compatible positive original unit. A successful unifier applies
to the entire remaining clause, so shared-variable equations survive each step.
The residual always has one fewer literal. If a ground instance of all premises
is supplied by these universal units, its first donor is among the enumerated
choices. Its substitution factors through that donor's principal unifier. The
remaining ground instance therefore remains a solution of the residual. Induction
on clause length proves that choosing the first premise loses no unit/headless
refutation in the unbounded search. Enumerating permutations of premise order is
unnecessary in this exact fragment. This argument does not extend the carrier to
Skolem-dependent witnesses, functions, new Horn productions or DMZ round closure.

Each search has a one-million-work-unit budget and at most512 pending/explored
states. Caps throw; no partial proof or negative certificate is returned. The
first complete proof suffices for native rejection. A null return means only no
additional refutation from this helper. There is no completeness, Source-minima,
scale or global runtime guarantee under those caps.

## Exact multi-root proof and capture boundary

A live Proof pins its actual Mind, actual constraint Rule and all unit Rules.
verify rejects a different Mind, replaced/deleted roots, changed whole origins,
changed clause shapes or a changed proof. Evidence is detached and immutable:
every whole root with native identity/origin/all clauses, the constraint branch,
every unit-root index/pivot, and every residual through the final empty clause.
Evidence.check reconstructs every principal resolvent and checks that exactly the
retained roots were used. It reuses the qualified unifier; it is not advertised as
an algorithmically independent unifier. The independent join oracle is below.
Detached evidence remains a historical logical observation after a live root is
deleted; it is not thereby a current-context certificate or accepted provenance.

Analyzer runs this fallback only for ACCEPT or explicit current-context CHECK,
and only when the existing analysis/direct-unit checks have no refutation. The
existing query/hypothesis path is unchanged. A diagnostic witness lists the whole
constraint and every used unit statement; unrelated anchors are omitted.

A proof with three or more originals MUST NOT masquerade as the old native
collision pair. CollisionProofCapture now records a separate SymbolicConflict
stream with the detached evidence and ALL original Graphs. Event-time replay
source observations remain observations, including their original outcomes.
Legacy snapshot() explicitly throws when such an event exists. Consumers unable
to handle complete multi-root evidence cannot silently omit premises and invent
a smaller Source proof. symbolicSnapshot() is immutable and separate. No DMZ
admission consumer is automatically migrated to this new observation stream;
legacy evidence consumption can therefore conservatively refuse this new scope.
Existing ordinary pair captures remain unchanged when no symbolic event exists.

## Independent qualification

NativeUniversalConstraintCollisionRunner intersects independently generated tuple
sets for nine binary patterns over all mentioned typed constants plus one other
representative. Every9x9 pair is checked in both insertion directions and both
constraint-body orders:324 actual native authoring comparisons. Numeric/string
values, repeated/independent variables and incompatible donor tuples are distinct.
This oracle is sufficient for the function-free equality patterns under test;
it does not redefine @x as quantification over stored or finitely enumerated values.

Every rejected authoring operation checks atomic whole-input rollback and actual
conflict diagnostics. Additional checks include:

- explicit CHECK qualification, exact three-root capture and all three physical
  replay source labels, excluding an unrelated anchor;
- full evidence reconstruction, immutable snapshots, wrong-Mind and deleted-root
  refusal, work/state exhaustion with no mutated input;
- refusal of the legacy pair reader for multi-root evidence;
- 17-premise refutation without a clause-width-eight ceiling in this native helper;
- the consistent dependent-witness control stays accepted and outside the helper;
- an open constraint yields no refutation, unseen-value queries still work and
  the existing negative conclusion for its missing conjunct remains negative.

The last query control initially expected UNKNOWN during test development;
with p and not(p and missing), not-missing is entailed. The test was corrected
before the frozen source/JAR qualification; no query implementation was changed.
Final new driver:1134 checks. Development overlays are excluded from final evidence.
