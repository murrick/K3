# Stage3at — checked universal quotient interpretation

`ContextUniversalQuotientModel` finds and independently checks a chosen model of
an exact sealed `ContextUniversalUnitLedger`. This is a historical private-cut
witness, not family closure, source-bound collision evidence or write authority.
Default authoring and existing ground/family qualification paths are unchanged.

## Scope and all-value extension

The ledger admits flat ordinary relational clauses: variables or opaque ground
values in argument slots, universal variables, no interpreted equality, calculated
predicates, variable-containing functions or native witness requirements. Existing
native binding and ledger opening enforce this boundary; the model does not widen
it. Each semantically distinct actual ground value is a singleton class. A further
abstract class OTHER covers every admissible value unequal to all those values.
OTHER is neither a ground term nor an eigenparameter nor a sampled database value.
Even a constant-free ledger has this representative; its domain is never empty.

For every actual value v define projection pi(v) to its semantic singleton, or
OTHER. For each predicate choose a truth table on representative tuples. Interpret
that predicate on actual tuples by pulling back through pi. Every arbitrary
variable valuation projects to an enumerated representative valuation, preserving
all repeated occurrences of the same variable and fixing every ground slot.
Thus each atom, literal and clause has the same truth value before and after
projection. Checking every representative valuation proves that this chosen
interpretation satisfies the clauses over ALL admissible values, including values
never mentioned in the database. Collapsing two distinct unmentioned values is
permitted for this chosen relational interpretation; it supplies no equality fact.
Interpreted equality/functions would invalidate this argument and remain excluded.

## Construction and independent witness check

Construction inventories semantic constants, expands representative valuations to
Boolean clauses and searches predicate profiles. An independent checker scans the
raw ledger, validates the complete actual constant manifest and profile signature,
then evaluates every valuation with an odometer. It does not reuse the encoded CNF
or the search assignment array. A model is exposed only after this check succeeds.
The checker requires exact ledger identity. Lists and profile tuples are immutable.

One work allowance spans construction, search and final check; construction and
check also share the instance allowance. Bounds: 64 constants, 256 profiles,
16 variables/256 literals per clause, at most 65536 total instances, plus caller
model-assignment/work limits. Limit or check failure returns no model prefix.
Failure to find a model supplies no sourced collision proof. Absent profiles are
false only in this chosen interpretation, never exported negative knowledge.
No knowledge row, Source, inference depth or production is created by search.
