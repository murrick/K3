# Bounded construction of fixed-original unary extensions — stage483

## Contract

`ContextSignedUnaryExtensionSearch` constructs candidate extensions of an ALREADY checked
original-row unary interpretation and an authentic completed QUIESCENT_SUPPLIED signed branch.
It does not construct or alter original models, expand the named basis, run native inference,
select the default writer, or relax eligibility. Success returns only the existing independently
issued actual-final unary model receipt from stage482. There is no new self-certified search receipt.

The producer independently inventories actual common/private atoms, fresh units/compounds,
and all terminal proof clauses per actual final cut. It counts every Source proof alternative
against the obligation bound. Candidate vocabulary and Origins are collected from these carriers.
Original truth cells, named values and own Source/binder assignments remain unchanged. Each
required imported Origin independently ranges over the receiving cut's existing named points.
Distinct Origin tokens may have equal denotations; they are not disequality constraints. Independent
A-X/B-X interpretations are preserved; a TRUST aggregate is still one checked logical cut.

Each newly required unary predicate has one Boolean cell for every original named point and
one ALL-other-admissible default. All assignments are candidates only. Mixed-radix enumeration
starts with false cells/first named point and includes combinations rather than greedy choices.
A fresh `ContextSignedUnaryBranchModel.run` audits EVERY candidate's original/native receipts,
exact final manifest and semantic truth before returning its sealed receipt. Unsupported shape,
false candidate, lost coverage or stale carriers cannot become success by producer authority.

Hard policy maxima:64 candidates,16 NEW truth cells total (including outside cells),8 imported
Origin choices total; original bounds<=16 named points/cut and<=16 cuts remain. These are
additional construction limits, not full language completeness. Each candidate may be expensive:
there is one fresh original/native preflight and at most64 fresh full final audits, each bounded
by the caller's explicit child audit policy. A SEPARATE cumulative construction budget covers
inventory/support counting, choice allocation, candidate preparation and radix advancement.
Child audits have their own bounded budgets; these are not reported as one shared work counter.

Result is CONSTRUCTED_FINAL_UNARY or INCOMPLETE without partial receipt. Candidate cap, work,
shape/vocabulary/obligation cap and exhaustion of this fixed-basis space all mean INCOMPLETE,
NEVER REFUTED/conflict/no-model proof. Other original models, bases, outside partitions or
larger language may work. Search provenance/candidate count grants no writer capability.

## Concrete checks

New negative product absent from original self vocabulary is assigned false and passes.
New positive product initially false fails the independent audit; a later true candidate passes.
An imported Origin initially denotes named point1, where a generated negative literal is false;
it must denote point2 instead. The member retains its independently checked original point1
witness assignment. The original self truth cell remains true, proving no silent truth rewrite.
A foreign universal mark row that generates no shared mark obligation remains in its own cut;
no mark extension is invented in X, preserving context independence.
A one-candidate limit misses the second-point valid extension and returns INCOMPLETE. With both named
points incompatible with the generated literal, finite space exhaustion is also INCOMPLETE.
