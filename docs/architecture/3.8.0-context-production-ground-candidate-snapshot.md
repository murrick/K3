## Separate staging from evaluator choice

ContextProductionCandidate.stage now owns the existing native trial machinery:
preflight exactly one complete assertion, verify all source identities, rebuild
ALL original X primaries in a private Mind, append exactly one new primary,
verify whole native declarations, and map each original Source to precisely one
staged Source. Duplicate/replacement/query/script inputs cannot masquerade as a
new assertion. Whole source occurrences, including conjunctive clauses, remain
accounted. Every foreign Snapshot/pin/initialized view is preserved unchanged.
Staged and StagingResult have private constructors and immutable source maps and
cut lists. Trial identity participates in the staged inventory fingerprint;
independent trials cannot reuse one another's candidate view.

The old prepare API selects the old family assembly AFTER this shared staging.
Its evaluator and write bridge retain their prior behavior. The new
ContextGroundClauseCandidate.qualify selects ContextGroundClauseFamily on the
exact staged snapshot. A rule-only candidate in an empty X no longer depends on
the legacy positive-seed assembly path. This is evaluator separation, not an
artificial seed or Source. Its certificate.frontier.x IS artifact.staged, never
the unstaged original base. Consequences and typed collisions cite the actual
candidate source plus unchanged foreign sources and cumulative depths.

All existing native staging constraints remain: an immediate private native
compilation refusal, duplicate, unsupported binding or bound failure gives
INCOMPLETE without a certificate. It is not mislabeled as a sourced collision.
Universal candidate clauses still cannot gain ground approval. A staged artifact
can exist for an unsupported ground-family scope; that artifact alone has no
authority. The real caller Mind and its presentation stores are not used as the
trial runtime or mutated by the trial.

## Fresh owned DUMB2 diagnostic

DB.qualifyGroundProductionCandidate opens a new ContextProductionSnapshotSession
and calls qualifyGroundCandidate under the provider monitor. The session guards
the owning thread, settled physical root, exact local identity/revision, complete
connection topology, all pinned initialized inventories and their fingerprints.
It binds current native source snapshots before staging and checks requireCurrent
again in finally, including failed qualification paths. Closed, cross-thread or
stale authority throws instead of returning a supposedly fresh certificate.
No TRUST view is flattened into independent cuts.

A pinned old revision remains valid after an unrelated new HEAD publication.
Changing its effective private initialization invalidates the old session while
a fresh call captures the new effective view at the SAME physical pin. Changing
local source rows or removing a source also invalidates the old session.
Historical diagnostic artifacts remain immutable after these changes.

The new method is read-only. Even GROUND_FIXED_POINT never calls source.query,
consumes no write lease and changes no physical primary, revision, solution,
hypothesis or log. Existing writeProductionCandidate still performs its own fresh
LEGACY qualification. It accepts no caller-supplied ground Evaluation or historical
