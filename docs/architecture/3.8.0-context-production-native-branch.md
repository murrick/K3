- INCOMPLETE returns neither stable receipt nor refutation prefix, regardless of how far

ALL original initial cuts precede initial refutation. All original grouped certificates
precede later refutation, using existing checks unchanged. Later unsupported/unready or
resource failure suppresses earlier partial results. A stable controller alone cannot
