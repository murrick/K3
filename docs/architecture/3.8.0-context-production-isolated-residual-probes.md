## Reproduced cause

For X `@x @y anchor(1)&&rel(x,y)->out(x,y)` and a foreign anchor(1),
rel(John,Mary), seed two fresh parameters plus the same three owner constants.
The existing rotation audit plans 25 ordered assignments. Full native replay
has one multi-variable TSolve and admits/visits only one assignment; it observes
no two-variable generic residual. Keeping the identical candidate vocabulary
but omitting the concrete relation from the measurement view yields no
multi-variable TSolve, 25 admissions/visits and 16 generic residual events
(not 16 distinct theorems). The controlled driver reproduces both results.

Linker.rotateVariables calls isValidFor before terminal admission. Its existing
TSolve suffix join requires compatibility with a registered multi-variable tuple;
unary tuples do not impose that cross-variable restriction. Thus candidate
registration alone cannot guarantee arbitrary native generic visits. This
ordinary query/link behavior is unchanged. The missing observation is addressed
by a proof-only view, not by disabling the compatibility filter globally.

## Checked proof-only views

ContextOrdinaryResidualRounds.inspectWithProbes first obtains complete ordinary
and parameter observations of the actual immutable X–foreign cut. It then plans
bounded supplemental views from that sealed baseline's proved local clauses
and actual opposite ground donor proofs. A view contains one whole owner clause
and one proved ground donor, with their exact original Support alternatives.
The caller cannot supply arbitrary view clauses or source labels. New probe
outputs do not feed another probe's plan in the same call.

Each view is a fresh native runtime. Its source-bound recipes are projected once
as derived carriers; their whole-clause roundtrip, owner instance, actual ground
premises, source unions and cumulative depth undergo the existing verifier.
Freshness still covers ALL original family knowledge, carried clauses and the
selected proof-view clauses. Parameters remain candidate bindings, not facts.
Only actual reconstructed native observations may generalize. A selected derived
donor keeps its existing depth and every causal source, then adds one native step.

A primary source may contain several conjunctive clauses. Selecting one as a
proof leaf preserves its original whole source identity and Support depth0;
it does not invent a narrower source, new primary record or admission verdict.
The complete source already proves each of those clauses in the sealed baseline.
This is an observation of a logical consequence from a proof subset, not a
qualification of the parent context with rows silently removed.

The final receipt retains the COMPLETE original owner set and full baseline
local knowledge, including the concrete relation omitted from an isolated view.
All added recipes merge with that full ledger. INPUT_STEP/LOCAL_CLOSURE and all
later independent cuts still see the complete original scope. Foreign-only
lemmas remain local; no raw sibling fact becomes a probe donor. Ordinary,
parameter and isolated passes share one work/event budget plus an explicit
maximum probe count. Any incomplete pass, merge or limit returns an empty
unverified receipt, including after an earlier successful isolated theorem.
Typed collisions still require a complete family barrier.

## Evidence and remaining scope

The exact stage3y two-free-variable example now passes the unchanged strict
symbolic INPUT_STEP and LOCAL_CLOSURE audits. It contains
`@x @y rel(x,y)->out(x,y)` with exactly X/anchor sources at depth1. Original
concrete facts and consequences remain in the final receipt. Carrier replay
preserves coverage. An anchor derived by seed→anchor contributes both foreign
causes and its depth1, giving the generic X-dependent theorem at depth2.

Controls include conjunctions stored under a single source, local foreign-only
lemmas, named values, repeated-variable equality, negative heads, missing/stale/
work/event/depth/probe limits and independent raw sibling opposition. Split A/B
still needs the next common barrier to combine its actual knowledge and preserves
depth2 in both orders. A separate negative-out context refutes the carried result
at the third complete barrier, proving that isolated views did not erase the
full original context. The ordinary and parameter-only negative controls remain.

This API supplies sound observed proofs only. Coverage is still separately
required. Its single-donor views are not a claim of arbitrary clause-to-clause
resolution, complete witness/general language support or a publication permit.
No default/candidate/provider admission path or unit-only Horn certificate is
redirected. Universal units remain unsupported. Next: join complete ordinary
residual receipts, per-barrier coverage and a scoped Horn consistency argument
in a bounded family executor, preserving explicit UNKNOWN outside that scope.
