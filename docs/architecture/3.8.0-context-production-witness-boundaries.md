# Stage2p: native witness scope observations and transport boundaries

## Concrete counterexamples before transport design

The existing scalar clause carrier excludes C-variables. Keeping that boundary
is necessary: the following native qualification controls have different answers.

| Knowledge | Added restriction | Accepted |
| --- | --- | --- |
| exists x p(x) | not p(1) | yes |
| p(1) | not p(1) | no |
| forall x p(x) | not p(1) | no |
| exists x (p(x) and q(x)) | forall x not(p(x) and q(x)) | no |
| exists x p(x); exists x q(x) | same restriction | yes |
| forall x exists y edge(x,y) | forall y not(edge(1,y) and edge(2,y)) | yes |
| exists y forall x edge(x,y) | same restriction | no |

Thus naming a witness with an ordinary constant or universalizing it creates
false collisions. Freshening it independently per conjunction branch loses a
real collision; merging independent scopes creates one. Dropping mixed-prefix
scope can also change acceptance. These are counterexamples to lossy transport
schemes, not claims of a newly discovered native qualification bug.

## Detached observation

ContextWitnessScopeObservation compiles exactly one sourced assertion in a fresh
private Mind without linking or querying. It records native witness term IDs,
owner Rule IDs, indices, domini flags, immediate parent IDs, witness-use positions
(branch/literal/argument/predicate/sign), and the set of native universal IDs.
It preserves a shared C-variable across conjunction branches, repeated argument
positions, and distinct binders within a Rule. A fresh observation UUID scopes
all operational IDs: identical raw IDs in separate Minds/replays are never a
cross-context identity assertion. Source occurrence/view/revision labels are
retained exactly as supplied; real effective-view validation remains pending.
All returned collections are detached and immutable. Scan work and capture
events are bounded; exhaustion throws rather than returning partial metadata.

This is metadata only. It has no proof supports, adds nothing to the production
pool, and cannot authenticate a witness or certify saturation. In particular:

- the universal-ID set is not a quantified dependency vector or prefix AST;
- domini distinguishes the demonstrated prefixes but is not claimed to encode
  every alternating-prefix dependency;
- a fresh replay token prevents accidental aliasing but is not stable witness
  identity across synchronous rounds;
- primary isolated observations do not characterize generated child projections,
  conditional production instances or Skolem dependencies;
- nested nonordinary/function argument forms stop this observer.

The ordinary SemanticTermSnapshot carrier still rejects C-variables, and
inspectWithVerifiedHornCoverage still rejects existential inputs at preflight
with INCOMPLETE/NONE. Observing scope metadata must not remove either guard.
No native inference, durable storage or runtime qualification path changes here.

## Query surface remains separate

An exploratory probe found native ?exists y edge(1,y) and edge(2,y) returning
true under both mixed prefixes above, while adding the displayed restriction
is accepted only under forall-exists. This query result is not used as evidence
for transport or common-witness entailment. Query/hypothesis/orphan semantics
(question3) remain open; the observation needs separate interpretation before
calling it a bug or changing query behavior. The tracked boundary runner uses
native acceptance/rejection and structural observations, not that query result.

## Next bounded work

Establish an authenticated bundle carrier for a narrowly admitted witness scope,
starting with shared existential primary conjunctions without universal
variables. Keep the entire sharing relation and source proof group together;
first prove roundtrip acceptance/rejection equivalence on the counterexamples
above before allowing derived witness productions. Mixed prefixes and generated
witnesses remain outside the certificate until their dependency/identity
obligations are established. Effective views/pins and shared atomic runtime
qualification gates remain later work.
