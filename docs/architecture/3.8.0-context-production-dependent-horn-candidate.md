# Stage509: typed dependent Horn productions in an owned candidate

The new opt-in local-X inspection builds genuine consequences of ordinary Horn rules using dependent positive-unit seeds. It materializes them as immutable typed rows in a private candidate, permits earlier products as later donors, and checks every original headless constraint against the original and final finite unit pools. It runs through the actual pending-provider lease introduced in508. No native scalar CVar or generated legacy Rule is installed in the live child or DB.

## Concrete before/after obligation

```
!@a $u @b rel(a,u,b);
!@a @u @b rel(a,u,b) -> tagged(a,u,b);
!@a @u ~(tagged(a,u,1) && tagged(a,u,2));
```

The initial unit pool contains no `tagged` unit. The supplied Horn step creates `tagged(a,u(a),b)`. The final pool now refutes the constraint using two fresh instances of that generated unit, with the same original witness function. The collision must include the seed, Horn rule and constraint Sources. If the seed is `!@a @b $u rel(a,u,b);`, the generated application is `u(a,b)` and that shared-witness refutation does not follow. A global witness has no parameter; a cross-`a` constraint distinguishes it from `u(a)`. These are required native/compiler-produced controls in both insertion orders and an alpha variant.

## Profile and production ledger

Every actual original is natively checked against a fresh compiler copy before any inference. A whole source is either a supported positive prenex unit, or one ordinary Horn/headless clause with at most one positive head. Horn/constraint slots are ordinary typed constants or rule-owned universal variables. Calculation, user functions, CVar slots in Horn bodies/heads, multiple positive heads, multiple native clauses, generated/deleted rows and opaque initialization are outside this profile and refuse whole preparation. Existential witnesses enter through the positive-unit dependency scope already checked in503–508.

A request supplies ordered Horn steps and the donor for each negative literal in the compiler's body order. Donors refer to original positive-unit occurrences or earlier product indexes. Forward/self references, partial bodies, wrong roles and nonunifying donors refuse. Units are standardized apart on every use, including variables nested inside function arguments. One whole MGU is propagated through the entire remaining body, output head and all previously consumed donor instances. A later body premise can therefore refine an earlier witness from `u(a)` to `u(2)` without mutating an older unit.

The materialized row carries a typed head, its whole Horn Source, the complete union of donor ancestry Sources, and generation depth `1 + max(donor depth)`; original units have depth0. A constraint refutation is one level above its deepest donor. This depth is not the old frame's resolution-step count and cannot substitute for an existing sealed receipt. Head-only universal variables remain arbitrary; no finite named basis, model value or witness inequality is introduced.

Source alternatives are retained as distinct products. Unit/constraint search enumerates every matching donor choice for the finite supplied pool, with fresh variables and full residual substitutions. It retains superset Source footprints. A tested pair of alpha-equivalent generated `tagged` rows has small and superset ancestry; the two-literal constraint retains all four donor combinations. State/frontier/proof bounds throw before any public result, even if an earlier branch closed. No partial pool is presented as a completed qualification.

## Original and actual-final reconstruction

The original unit-only constraint pass runs before generated rows exist. The final pass includes every supplied generated row. The complete product/donor/refutation graph is then reconstructed from a second fresh projection of ALL actual native originals, rather than treating products as new axioms. Canonical graph comparison binds source ordinals, original witness declaration coordinates, typed payloads, sharing, donor traces, Source supports, depths, and the exact captured context/revision/view. The audit header and graph share a bounded byte envelope.

The public result exposes immutable typed row views and separate original/final unit-refutation lists. Variable indexes are result-local. Witness symbols retain their actual original Source and declaration position across generated owners. The graph digest is historical comparison evidence, not a provider lease or a durable storage format for the production recipe. The existing version1 replay capsule format remains unchanged; the new graph helper is not a version1 encoding of Horn recipes.

This is independent fresh reconstruction using the same bounded symbolic kernel, not a second model checker or an unqualified full actual-final admission audit. The request does not enumerate all Horn consequences. Absence of a unit refutation is not a consistency, saturation, completeness or writer-eligibility certificate. Per-cut X–A/X–B/TRUST obligations, full family/branch results and original/actual-final admission receipts remain required.
