## Projection and native input receipts

`ContextUniversalFrozenReplay.replay` accepts only a sealed successful typed
closure. It rechecks the full DAG/depth, restores its actual local input in a
fresh native namespace, and internally derives the canonical Root->Origin map.
Callers do not select theorem subsets, target Minds or alleged native bindings.
Imported fact roots remain authenticated input receipts. Every other minimum
ledger proof is replayed, including ordinary schema roots and computed typed
schemas/frozen units. No live replay Mind is returned.

The renderer declares only genuinely universal variables. Every ordinary value
is projected semantically through the parameter queue; values are not reparsed
from their rendered text. A frozen argument is the actual existing canonical
Term from this restored input, not a new existential declaration or a universal
variable. Missing/ambiguous roots, wrong owner, parent alias or domini root are
refused. This preserves the same selected witness across all values of a
remaining universal variable, rather than choosing a new witness per value.

New package-private capture.replayTypedInput returns exactly one detached native
Input and verifies complete parameter consumption. Input.typedClause is opt-in
and captures actual rule structure: declared TVARIABLEs must belong to that
native Rule; frozen TERM values must be exact known canonical roots; ordinary
TERM values are snapshotted semantically. Branch/predicate/sign/argument sharing,
free-variable alpha-renaming and rigid original origins must match the proof.
The ordinary Input.clause/shapes fields retain their existing meaning and may
remain null for frozen inputs. Existing capture entrypoints do not opt in.

Input.source always remains null. The compiled rule receives its actual checked
Support, with every whole Source and proof depth. Computed units are not
relabelled as primary knowledge or reset to depth0. Replaying schema roots at
depth0 still refers to their original whole-row proof, never a synthetic clause
Source. Capture typed state is cleared after each call and on close.

The lower-level capture receipt and supplied labels are data, not proof authority.
Only the sealed high-level factory authenticates the original semantic map and
checked DAG. Existing primary verifier still refuses typed derived Inputs as
`derived-input-outside-primary-step`.

## Native producer binding and gaps

Equal clauses can coalesce to one native Rule. The receipt groups all exact
Proof tokens by actual native Rule ID; every observed event's complete Support
set must equal the checked Source/depth alternatives of that Rule. Different
Source sets or depths are not flattened into a union or omitted.

Witness events resolve their actual non-dominating lineage back to this replay's
known canonical origins. Ordinary events retain actual semantic values. Each
signed concrete event clause must be an instance of every bound producer schema,
with one consistent assignment for repeated universal variables and exact fixed
origins/constants. Coincident premise instances may normalize to one literal;
matching covers every actual literal, so an unrelated premise cannot be ignored.
The raw event remains available alongside its normalized instance.

Generic capture correctly records cvariable-input and nonordinary-primary-fact
for frozen parameters/units. These gaps remain in the Snapshot. The new bridge
accepts only the specific gap Rule ID already bound to an authenticated frozen
input, with a unit proof additionally required for the unit gap. It does not
clear or globally relax capture gaps. Existing supported raw observation/schema
gaps also remain outstanding; other gaps and transport mismatches fail.

Failure/depth/work/event limits return no input-binding/event/imported/map prefix
and no observation receipt. Success preserves common/local basis IDs, replay
UUID, exact typed closure, canonical map, native bindings, imported roots, raw
Snapshot and observed producer instances. Two frozen origins can be represented
faithfully in this separate proof-input layer; this does not widen the older
single-origin verifier or native/public DMZ admission grammar.

Producer binding alone does not authenticate actual premise donors or issue a
conclusion Support. A fixed frozen unit is already proved at its DAG depth;
instantiating a still-universal unit is a different inference and may require an
actual carried binding proof. The next conclusion layer must keep those cases
separate and verify stored materialization correspondence. This result creates
no output Packet, round stamp, family verdict or writer permit.
