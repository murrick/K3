## Exact cut capability

Witness Cut now retains group name plus every original member's context/revision/
private-view label, independently of its first routing inventory. Equality includes
that complete membership. Plan/family uniqueness checks account for every physical
context, including a hidden X alias or overlap behind another routing member.
Declaration validation, producer eligibility and merged output authentication use
membership of the exact member cut rather than equality to the first member.

Productive fixed-point replay opens with its sealed target Cut. New foreign
producer inputs must match a member's exact context/revision/view. A rejected
input marks the frame failed; it cannot later yield reconstructed proof. Before
verified export, the same complete target is required; another member set cannot
reuse that replay. Whole declaration/source shape checks remain independent and
unchanged, so membership alone is not permission to invent a primary rule.

Only this target-bound group path allows multiple foreign producer labels in
step verification. Local X labels still agree with the carried X cut. The legacy
unscoped seed-replay entrypoint retains its old one-foreign-context restriction.
Existing ordinary witness paths remain covered. This is not a global removal of
source-cut checks or a relabelling of every member as one synthetic Source.

A genuinely empty trusted target can carry an empty-target receipt for all its
members. A nonempty group cannot masquerade as empty. Foreign witness-bundle
members still refuse assembly explicitly: private local seeds and their canonical
reintroduction/branch refutation need separate evidence. Private ground-fact
coverage likewise remains incomplete where the existing witness engine cannot
cover it; those rows are never silently dropped.

## Scope, origins and actual publication

The196-check internal scope control evaluates eight combinations of shared versus
separate X witness bundles, member order and duplicate identical member producer.
All complete positive outputs retain the original seed Source/binder origin at
cumulative depth3; distinct seed/flag bundles stay distinct. Identical A producers
keep both minimal original member support alternatives. Irrelevant warm/flag
Sources do not get attached to out. In these plans foreign producers create no
new witness origin; this does not prohibit already-sound carried foreign origins
in the legacy transport API.

Further checks reject foreign producers outside the target, changed revision,
changed private view and wrong target-member export, with no proof packet. Legacy
unscoped multi-foreign replay still refuses. Empty group proof authenticates both
members and a nonempty group cannot claim that proof. A foreign private witness
bundle remains explicitly unsupported. A negative rule against a separate flag
witness gives INCOMPLETE/no refutation, not an invented collision or an unwarranted
consistency claim for uncovered negative clauses. Existing per-literal witness,
clause/variable/depth/event/work bounds are unchanged.

Eight actual native attempts: grouped versus independent A/B × both connection
orders × safe out/refuting negative flag. Each first runs an owning diagnostic,
then a distinct fresh automatic-policy evaluation at real native commit ingress.
Safe publication adds only the whole candidate and advances revision. Negative
publication has typed STORAGE_CONTEXT_CONFLICT, nonempty witness refutations and
exact source/revision purity. Every refutation uses original bundle+candidate+
both members at cumulative depth3, exact member pin/view/native primary ID, one
pending X view, and no irrelevant warm Source. Initialized foreign inventories
stay unchanged; no raw/group-derived primary imports. Every case closes/reopens
normally with exact settled whole primaries and ordered member pins.

The automatic-policy guard used for actual attempts is the existing explicit
ingress qualification test seam; production default is not switched. Group-local
native inference can cross its members within one pass, whereas independent cuts
continue to see immutable common barriers. No finite termination or enumeration
of every later-depth proof is promised.
