## Governing invariants

> A released RuleFactory checkpoint restores canonical Rule visibility, every derived ID index, promotion state, and the Linker continuation signal as one coherent pre-mark view.

> Candidate metadata locks protect coherent ID snapshots and memo publication only. Rule hydration, deletion checks, TValue resolution, and Mind-dependent semantic effects execute outside candidate metadata locks.

> Candidate metadata is an ID-only acceleration layer. Escalera/IBase and RuleFactory remain the canonical Rule authority, and ordinary unification remains the final semantic check.

> Generated-to-primary promotion changes the effective view without creating a new canonical Rule or changing its ID; durable mutation occurs only at the root pack/update boundary.

> Rule traversal ordering is an explicit Linker execution policy over the full long ID domain, not an accidental property of cache or candidate-index iteration.
