# Stage3y: fresh-parameter native residual observations

ContextOrdinaryResidualRounds.inspectWithParameters adds an explicit two-pass
observation API. The ordinary pass is retained; a second private native replay
starts from the same immutable family frontier and original cut declarations.
Both passes share one work and event allowance. Failure of either pass or their
proof merge returns an unverified empty receipt, including when the ordinary
pass already produced valid results. Existing inspect remains the single-pass
API, preserving the stage3x missing-general-observation control. No candidate or
default authoring entrypoint is redirected.

ContextOrdinaryResidualParameters adapts the reference path's native TValue
seeding. It finds actual rule-scoped variables (bounded rank2), creates distinct
ordinary eigenparameters, and checks their absence from every selected source
clause and carried recipe, including nested semantic occurrences. The native
capture freshness guard is also applied. Candidate values consist of these
parameters and the current cut's actual owner constants. Cartesian candidate
work is charged before adding TValue candidates. Neither a parameter nor a
candidate binding is inserted as a primary fact, proof donor or artificial
Source. Seeding candidates is not evidence that native inference visited them.

Every native reduction still undergoes the existing complete owner/instance
check and ground-premise proof reconstruction. Only after that reconstruction
may a clause generalize direct occurrences of fresh parameters to universal
slots using the existing checked structural generalization operation. Original
source alternatives and native derivation depths are retained. Structured
parameter occurrences, unsupported universal units, unmatched/unproved events
and all resource bounds refuse rather than supplying a partial proof prefix.
The ordinary and generalized local ledgers are merged at minimum observed depth
per clause/source group; only X-dependent productions enter the shared frontier.
Foreign-only generalized proofs remain local.

## Resolved stage3x counterexample

X `@x @y left(x)&&right(y)->pair(x,y)` with one foreign cut containing left(1)
and right(2) still fails the unchanged strict symbolic audit in single-pass
mode. The new two-pass API supplies the native partial observation with a fresh
parameter, then generalizes it to `right(y)->pair(1,y)`. This proof has exactly
X and left(1) sources, depth1, without the right(2) source. The symmetric theorem
is obtained as well. Both INPUT_STEP and LOCAL_CLOSURE audits now pass. The
ordinary pair(1,2) proof remains available with its original depth1 and three
sources; a split A/B fixture still transports its consequence at depth2 on a
later common barrier. Projecting and replaying the generalized carriers preserves
coverage and exact input identity.

Controls cover named constants, negative heads, repeated-variable equality,
foreign-only theorem isolation, dormant rules with candidates but no facts,
nonfresh primary/carried values, duplicate parameters, work/event/depth stops
and missing/stale receipts. A threshold control finds an event budget sufficient
for the ordinary pass alone and proves that exhaustion before the second pass
cannot leak its already successful proof prefix.

## Remaining observed boundary

X `@x @y anchor(1)&&rel(x,y)->out(x,y)` with a foreign anchor(1), rel(John,Mary)
is deliberately NOT declared covered. The native replay produces ground
consequences, but adding two fresh candidates does not yield the required
observed two-variable theorem `@x @y rel(x,y)->out(x,y)`. The unchanged symbolic
audit returns uncovered. No two-variable independence is inferred from diagonal
or ground samples. This is a concrete remaining observation boundary, not a
certificate failure silently converted to success. The precise native visit/
admission cause still needs measurement before a runtime change.
