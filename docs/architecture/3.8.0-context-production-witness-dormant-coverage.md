# Stage3d: dormant positive Horn cuts with interacting vocabulary

## Counterexamples that constrain the certificate

First, X carries p(w,1); A's p->q has already given q(w,1) with {X0,A1}.
A new B declaration p->q leaves the set of atoms unchanged, but the actual native
pass adds another q proof, {X0,B3}. sameContents is false and q has two complete
alternatives. A checker that tests only whether each rule head is already known
would lose new provenance. An enabled body must therefore refuse this empty
certificate even if its head is already present.

Second, from a carried ~n(w,1) and missing(x,1)->n(x,1), native inference derives
~missing(w,1) by contraposition, despite no positive missing premise. This
certificate therefore requires every carried literal to be positive. The older
disjoint-vocabulary certificate keeps its independent signed-packet scope.

## A structural no-first-application certificate

ContextWitnessDormantCoverage checks a sealed input packet and the entire
supplied declaration cut, using shared original Rule/source-cut validation.
Each declaration clause must be fact-free definite Horn: exactly one positive
head and at least one negative clause literal (a positive body atom). Every
carried Item must be positive, with carried proof depth within the requested
bound. Predicate overlap, rule cycles and two-variable bodies are allowed.

For each complete clause body, the checker exhaustively searches opposite-literal
matches against the immutable packet, retaining one consistent assignment across
all premises. It reuses the exact Stage3b canonical literal matcher: predicate,
arity, sign, fixed semantic equality and original witness identity. Repeated
variables must agree; independent variables may take equal or different slots.
A single enabled body refuses the empty certificate. Head-only variables do not
hide an enabled body: that case is refused before any head instantiation.

No enabled body means there is no first Horn application from this positive
literal pool. Consequently no chain or cycle can start, no positive atom can be
added, and no connected nontrivial Horn proof can add an old atom's source
alternative or lower its depth. This is a proof of inactivity, not a rule engine
that manufactures missing products or their supports.

The semantic model argument does not restrict the universal domain to observed
values. Interpret the old positive predicates as exactly their recorded tuples,
choosing distinct values for independent canonical existential origins; all
other tuples are false. With every Horn body disabled, that interpretation is a
model of all supplied clauses, so no additional positive literal is forced.
The uniform all-true interpretation also extends the positive packet and
satisfies all definite Horn clauses, excluding forced negative literals.
Arguments range over all admissible values, including fresh/unmentioned values.
There is no equality/system/function semantics hidden in this relational scope;
these inputs are refused by the shared whole-Rule boundary.

The finite operation enumerates matches of finite predicate extensions, not
values of a supposedly finite universe. Shared-variable bodies at independent
witnesses remain disabled; independent variables may enable them. Fixed argument
mismatches may disable a body, whereas semantically equal numeric spellings do not.

## Round integration and controls

exportDormantEmpty calls the verifier itself and uses the existing private
completed-empty Packet kind. Exact basis identity, target cut, captured producer
labels and all old Item proof groups are retained. No caller-supplied completion
flag or native zero-event shortcut is introduced. Family validation is unchanged.

The main fixture has B:q&&flag->out dormant while q is absent. An independent
A:p->q pass and B's empty certificate complete round1, whose union contains q but
not out: B cannot see same-round A results. At the next barrier, B's old certificate
is refused, and a fresh dormant check refuses the now-enabled body. The actual
next native pass gives out at depth2 with {X0,A1,B2}. All-certified-dormant families
can also return MERGED/changed=false without deleting source alternatives.

The49 new controls cover this sequence, native proof-alternative and
contraposition counterexamples, interacting dormant cycles, fixed/numeric/repeated
slots, independent origins/variables, head-only variables, signed/unit/function
refusals, unsupported later declarations, X producer participation, source cuts,
missing/duplicate declarations, depth/work/event stops and self-X cuts.

to cover its result. Productive proof closure and complete alternative/minimum-depth
