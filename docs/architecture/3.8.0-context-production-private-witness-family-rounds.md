## Implemented boundary

A private Branch carries an immutable native-bound PrivatePool. Its declarations
must match whole original Source/text pairs from that pool's snapshots. The same
X declaration set must occur in every branch, and physical member aliases remain
forbidden. Complete preflight checks every branch's ordinary declarations,
positive local pool and carried proof depth before inference or collision output.

`capturePrivate` accepts only a sealed PrivatePool and exact owning declarations.
The authenticated raw bundle supplies target ownership even when the target has
no ordinary rule of its own. An X producer can therefore run against a bundle-only
foreign target without inventing a foreign producer or an empty-target capability.
The ordinary capture entrypoints retain their existing target-producer checks.

Each round uses one immutable common input. Private branches first try complete
local Horn closure; if it is not established, they perform a verified native
continuation with input-enabled local-before/local-after obligations. Local-only
proofs and source alternatives remain in that exact branch's state. The new
common-output round receipt is issued only from this sealed verified continuation
or local closure. It binds exact common identity, complete target cut and producer
Sources; raw proofs are absent from its common items. Bundle-only targets are
recognized through the original private seed capability, not the first member's
routing address. Legacy unowned private replay still cannot obtain coverage.

A dormant branch needs no native application. The first integration probe found
that unconditionally replaying such a branch returned `no-witness-chain-applications`.
Checking complete local closure first handles the dormant case without interpreting
absence of a native event as proof. Missing or unsupported obligations still fail.

After every complete merge, all private states are rebased onto the exact merged
packet before the barrier callback. The callback receives an immutable cut-to-state
map. Family qualification scans every original cut, using its corresponding local
pool when private. Collision evidence is committed only after all scans complete.
Initial scans also follow full input preflight, including private carried depths.

Round evidence records commonChanged and privateChanged separately. Their union
is changed. An unchanged common pool cannot end a private-changing round, and a
new proof alternative counts even when no atom changes. Termination additionally
requires complete local Horn closure on every final rebased private pool and the
existing complete common closure on normal branches. Successful Result retains
immutable terminal private states; incomplete results expose no packet, round
prefix or private-state prefix. No finite-termination guarantee is introduced.

## Concrete qualification

* X has an unrelated anchor and a dormant warm rule. Trusted A has an existential
  seed; B has seed->hidden. The first round changes only the private pool. A second
  stable round is required. A one-round limit refuses; hidden never enters X.
* X has seed->mid and done->out. Independent A has existential seed&&flag; B has
  its own token witness and mid->done. Barrier1 contains mid, but B cannot consume
  it in the same round. Barrier2 contains done. A native pass may also close its
  local X rule done->out in that pass; the algorithm does not artificially force
  one rule application per barrier. All outputs retain cumulative depth and exact
  whole-source supports. A later unchanged, fully covered barrier is required.
* Replacing done->out with done->~flag proves a collision in A at barrier2, using
  A's original private flag and the common done product from B. Exact four-source
  support has depth3. B's unrelated token is not used as A's witness. Split seed
  and flag bundles give no false collision. Both branch orders give the same
  activation barriers and common proof pool.
* Adding a second same-text original member producer changes only a private proof
  alternative. The common packet and atom count stay unchanged, but another
  barrier is required. Explicit sealed continuation can resume the resulting
  local fixed point; rerunning the original Plan does not borrow hidden mutable
  cached state from a previous execution.
* Wrong Source/text substitutions, later unsupported original declaration,
  round/depth/work/event stops and carried-private-depth preflight refuse without
  publishing a prefix. Terminal state maps are immutable. Existing normal-family,
  empty-target and private-continuation controls remain in the selected run.
