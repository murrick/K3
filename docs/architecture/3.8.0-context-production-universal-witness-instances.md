## Local receipt

`ContextUniversalWitnessInstanceVerifier.verify` operates on the live owning
capture and a sealed replay restored from its real input proof packet. It accepts
only a positive zero-premise projection present by identity in that journal.
The package-private capture overload `snapshot(expectedBoundary)` requires exact
Mind identity as well as the existing owning-thread/active-journal lifecycle.
Equal local native IDs in two fresh replays cannot substitute for this binding.
No live Mind is added to detached Snapshot/receipt state.

For every observed primary producer alternative, verification requires its
original native-bound Entry. Every clause of the replayed whole owner must match
the original whole owner; missing/extra/changed clauses fail. The selected clause
must be a positive universal unit with at least one variable. The existing
producer-instance matcher checks predicate/sign/arity, ordinary fixed arguments
and repeated variable equality against the native observation. The complete set
of observed singleton Source/depth0 primary producer labels must equal the
complete corresponding native input bindings. An alternative cannot be omitted
or replaced by an equal statement under another Source.

Every observed witness slot must trace to a non-dominating canonical root in the
actual sealed replay's carried origin map. Exactly one distinct carried root is
supported; independent origins are not collapsed. Limits retain64 original
entries,8 whole clauses,8 arguments and2 universal variables plus an explicit
work budget. Ordinary inference, signed universal instances and changed owners
are refused by this entrypoint.

The immutable receipt retains replay UUID, the exact observed projection,
original whole Entries keyed by Source and exact carried origin bindings. It
creates no Support, inference depth, seed, Route, Packet, family coverage flag or
admission verdict. Its originals are semantic provenance, not a connection or
lease authority: eventual integration must still check the live owning X/foreign
cut and provider lease. In particular a valid per-clause receipt does not certify
other clauses of a mixed owner. Capture gaps remain untouched. The verifier is
not wired into native discovery or the default writer in this stage.

This deliberately avoids two unsupported promotions: a universal instance is not
an original ground unit at depth0, and finitely many observed instances do not
prove universal closure over all admissible values. Depth accounting and complete
symbolic/demand closure remain part of the next integration work.
