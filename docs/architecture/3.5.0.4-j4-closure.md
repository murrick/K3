## Architectural result

J4 establishes the boundary between separately allocated logical variables and canonical variable/value associations.

```text
TVariableFactory
    per-Mind logical-variable overlay
    allocation and Rule/name ownership
    direct cache checkpoint lifecycle

TValueFactory
    canonical (TVariable, Term) identities
    active current-binding projection
    layered acceleration index
    mutation action state
    nested rollback deltas
```

The two factories share parent-controlled child completion and root-only storage attachment but intentionally retain different auxiliary state models.

## TVariableFactory result

The class contract now explains:

- one factory instance per exact `Mind` level;
- child `Escalera` overlay initialization;
- creation of a fresh logical variable rather than invented name-based deduplication;
- the distinct roles of schema ID, variable index, Rule, name Term, and Mind ID;
- typed parent promotion and Mind rebinding;
- root-only schema hydration/update;
- deleted-variable packing;
- cross-factory removal of the same key from `TValueFactory.current`;
- the absence of a separate auxiliary checkpoint journal in this class.

## TValueFactory result

The class contract now separates these state dimensions:

```text
Escalera cache
    canonical TValue identity and transaction visibility

current
    transient active TVariable -> TValue binding projection

parentIndex / localByVariable
    layered ID-only acceleration metadata

action
    mutation/effect signal

additionsStack / actionStack
    nested checkpoint rollback journals
```

It documents:

- canonical identity by `(TVariable, Term)`;
- resurrection of a logically deleted canonical TValue before physical pack;
- preservation of canonical ID and object identity during resurrection;
- child-to-parent index layering;
- oldest-first historical substitution traversal;
- delta-based nested checkpoint rollback;
- action-state restoration on release;
- physical deletion and synchronization of index/current state during pack;
- full-range lexicographic `TValue.compareTo` order, distinct from substitution order.
