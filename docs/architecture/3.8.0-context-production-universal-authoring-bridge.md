# Stage3ay — explicit flat universal authoring bridge

`DB.writeUniversalProductionCandidate` is an opt-in writer for the supported flat
ordinary universal relational scope. Default authoring, the older production and
ground bridges and unsupported native residual/witness/function scopes are unchanged.
The method accepts statement text and bounds, never a caller's historical artifact,
certificate or audit as publication authority.

## Fresh owned handoff

Under the provider monitor the owning `ContextProductionSnapshotSession`:

1. requires an active settled physical source and current owner/revision/topology/
   initialized inventories;
2. freshly binds and stages the requested assertion, then runs bounded synchronous
   factored family qualification including all-value models;
3. checks the actual base/foreign binding used the exact inventory objects captured
   by this owning session, not another semantically equivalent historical view;
4. independently audits the exact trial and requested assertion, with the full
   stage3ax applicability/certificate/barrier/source-attribution checks;
5. requires current source and effective family again before choosing a verdict;
6. permits native settlement only for a verified CONSISTENT trial, consumes the
   lease BEFORE `source.query`, and returns actual before/after physical references.

A qualified/audited collision refuses regardless of whether its proofs use the
new candidate. Failed audit yields INCOMPLETE even if inference found consistency
or a collision; an unaudited inference verdict cannot become a writer verdict.
Incomplete staging/closure/models never fall back to native writing. Prewrite
refusal keeps the lease current/reusable for another fresh trial; once settlement
is attempted, the old authority stays consumed even on rejection or exception.

`UniversalProductionWriteResult` retains the exact historical trial and audit,
plus physical before/after references. Private staged Sources are diagnostic;
they do not become physical Source identities or reusable write permissions.
Foreign-dependent conclusions are not inserted as new primary assertions. The
native transaction remains responsible for actual source publication and ordinary
provider validation. A native rejection is reported as NATIVE_REJECTED. Exceptions,
including post-settlement TransactionSettlementException, propagate unchanged;
there is no retry, catch-and-fallback or reopening of the consumed lease.

Preparation retains its existing per-operation native binding/staging work/event
allowances; inspectionWork is shared throughout the full family inspection;
auditWork is shared throughout the final independent candidate audit. These are
explicit separate phases, not one aggregate native+inspection+audit CPU budget.
Instance/model/depth/round limits retain the existing evaluator/auditor meanings.

## Controls and boundary

Disposable actual-provider fixtures cover the masked universal left/right->p
barrier2 refusal, safe universal-rule publication, exact staged/audit binding,
no writes/presentation-store changes on declines, incomplete rounds, unsupported
variable functions, model and audit budget stops, cross-thread/closed/stale view/
topology/pending-child/unowned/read-only refusal, duplicate publication prevention,
old historical success versus later opposite X, ordinary local native consequence,
full universal composition barrier3 with five original causes, and durable reopen.

The attempted old-base p->q / foreign p / foreign ~q(9) fixture is already rejected
by the existing provider connection gate. The test keeps this positive protection
and does not bypass it to fabricate a reachable writer state. Candidate-independent
and mixed-proof attribution remain covered by the existing Core auditor driver.
The writer's collision branch makes no candidate-dependence exception.

A FailingUser performs a real durable flush then throws. The test requires the
same COMMITTED outcome/cause, one finalization call, consumed authority/no retry,
and persistence of the actual universal assertion after reopen. This checks the
critical irreversible boundary without redirecting native settlement.

Validation totals and journal recovery are in the main rounds checkpoint. No full
DMZ/reactor test run is implied by registration counts. Question3 and general
native residual/witness/function scope remain open; default last contract remains
stage3r RED56/2.
