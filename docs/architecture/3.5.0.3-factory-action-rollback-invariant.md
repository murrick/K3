# KANGER 3.5.0.3 — Factory action rollback invariant

## Scope

This checkpoint records and resolves a composite `mark / commit / release`
protocol defect independent of the Escalera empty-root checkpoint defect.

Focused regression gate:

```text
kanger-console/src/org/kanger/KangerFactoryActionRollbackSafetyRunner.java
```

## Affected state

Several factories expose an `action` flag consumed by `Linker.link()` to decide
whether another inference pass is required:

```text
RuleFactory
TValueFactory
FValueFactory
Hypothesis stores
```

The flag is not mere diagnostics. At the end of every pass Linker continues while
any participating component reports action.

## Historical asymmetry

`TValueFactory` journaled cache/index additions across nested marks, but did not
journal `action`:

```text
dropAction()
mark()
add(speculative value)  -> action=true
release()
    cache root restored
    variable index restored
    action remains true
```

After release, the mutation no longer existed, yet the factory still reported a
change to Linker.

The defect was reproducible with a non-empty baseline cache and therefore did not
depend on the separate Escalera empty-root mark failure.

## Invariant

> Releasing a speculative mark must restore every factory-local state component
> that participates in semantic lookup or Linker continuation decisions.

For an action flag:

```text
mark()     -> save previous action
commit()   -> discard saved action and retain current action
release()  -> restore saved action
```

Nested marks require one saved action value per frame.

## Production correction

`TValueFactory` now maintains:

```java
private final Stack<Boolean> actionStack = new Stack<>();
```

The stack is reset with the rest of the transaction-local state:

```java
additionsStack.clear();
actionStack.clear();
```

The active protocol is:

```java
public long mark() throws Exception {
    synchronized (indexLock) {
        additionsStack.push(new ArrayList<TValue>());
        actionStack.push(action);
    }
    return cache.mark();
}

public long commit() throws Exception {
    long result = cache.commit();
    synchronized (indexLock) {
        // retain the current action and discard only the saved frame
        if (!actionStack.isEmpty()) {
            actionStack.pop();
        }
    }
    return result;
}

public long release() throws Exception {
    long result = cache.release();
    synchronized (indexLock) {
        if (!actionStack.isEmpty()) {
            action = actionStack.pop();
        }
    }
    return result;
}
```

The additions journal and canonical variable index continue to follow the same
mark depth. Release restores both semantic lookup state and the Linker
continuation signal.

## Consequences

The correction prevents a rolled-back speculative mutation from:

- forcing an unnecessary extra Linker pass;
- repeating work that no longer exists;
- amplifying flood-control behavior;
- preventing convergence through a stale continuation signal.

It does not change committed action semantics: commit retains real action that
survived the frame.

## Regression gate

`KangerFactoryActionRollbackSafetyRunner` verifies that after speculative TValue
creation and release:

```text
canonical contents restored
speculative value no longer findable
action restored to its pre-mark value
nested mark discipline preserved
```

The gate is invoked explicitly by `KANGER CI`.

## Final classification

```text
composite rollback asymmetry: corrected
empty-root dependency: none
cache/index rollback: preserved
Linker continuation signal: restored on release
commit retains surviving action: yes
focused regression gate: present
```
