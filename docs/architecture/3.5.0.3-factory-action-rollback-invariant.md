# KANGER 3.5.0.3 — Factory action rollback invariant

## Scope

This checkpoint records a second defect in the composite `mark / commit / release`
protocol, independent of the empty-root Escalera checkpoint defect.

Focused regression gate:

```text
kanger-console/src/org/kanger/KangerFactoryActionRollbackSafetyRunner.java
```

## Affected state

Several factories expose an `action` flag consumed by `Linker.link()` to decide
whether another inference pass is required:

```text
RuleFactory
TValueFactory
FValueFactory
Hypothesis stores
```

The flag is not mere diagnostics. At the end of every pass Linker continues while
any participating component reports action.

## Proven asymmetry

`TValueFactory` journals cache/index additions across nested marks, but does not
journal `action`:

```text
dropAction()
mark()
add(speculative value)  -> action=true
release()
    cache root restored
    variable index restored
    action remains true
```

After release, the mutation no longer exists, yet the factory still reports a
change to Linker.

The defect is reproducible with a non-empty baseline cache, so it does not depend
on the separate Escalera empty-root mark failure.

## Invariant

> Releasing a speculative mark must restore every factory-local state component
> that participates in semantic lookup or Linker continuation decisions.

For an action flag:

```text
mark()     -> save previous action
commit()   -> discard saved action and retain current action
release()  -> restore saved action
```

Nested marks require one saved action value per frame.

## Consequences

A false retained action can:

- force an unnecessary extra Linker pass;
- repeat speculative work that has already been rolled back;
- amplify flood-control and performance behavior;
- in a self-reproducing speculative path, prevent convergence even though no
  durable semantic change survives the pass.

The regression gate currently proves the direct TValueFactory case:

```text
canonical contents restored
speculative value no longer findable
action must also be restored to false
```

## Classification

```text
composite rollback asymmetry: proven
empty-root dependency: none
semantic content corruption: not required for reproduction
control-flow impact: direct Linker continuation signal
production correction: pending
```

## Required correction boundary

The immediate production correction should add an action checkpoint stack to
`TValueFactory` and audit every other action-bearing component for the same
protocol. The fix must preserve:

- nested mark behavior;
- commit retaining real action;
- release restoring prior action;
- existing cache/index journals;
- Linker pass ordering and semantic kernels.
