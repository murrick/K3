# Stage3an: sealed private unit ledger and immutable unit steps

ContextUniversalUnitLedger is a private cut ledger, not the shared family Frontier
or a storage/authoring API. Row, ledger, Opened and Step constructors are private;
all row/evidence lists are immutable. The ledger retains exact native-bound X and
target snapshots, optional historical Frontier and a fresh identity. Successor
ledgers point to the exact previous identity.

## Authenticated rows and evidence

openPrimary inventories whole actual ordinary primary clauses of X and one
foreign context (or X alone). open additionally imports actual sealed shared
Products and successful compound Evidence for the exact input/cut. Snapshot
role/source identity, context separation, witnesses, work and carried depth are
checked. Failed opening returns no ledger or partial row inventory. Both opening
paths retain existing ground/default APIs unchanged.

Every row carries an actual whole Source group and cumulative depth. Equivalent
clauses keep distinct independent source groups; within the same group the
minimum depth wins. Ledger caps are64 semantic clauses and256 proof rows. No
caller Clause/Support pair can be inserted through a public constructor.

The unit kernel now accepts an exact sealed ledger. Both whole parents must
match actual rows; every actual Support alternative participates. Kernel Evidence
records the exact ledger object, in addition to historical X/input/target. Old
primary/frontier coverage modes reject ledger evidence. Reopening equal snapshots
creates a different ledger and cannot reuse exact-ledger step evidence.

## One immutable unit sweep

step enumerates all whole-clause pairs with at least one unit parent and every
opposite compatible pivot, including self pairs. A structural MGU trial skips
only typed unification failure. The receipt-authenticated kernel's existing
proof builder creates all actual whole-source/depth recipes; it does not trust
caller recipes. Only the immutable input supplies parents. A freshly derived
unit cannot feed another rule until a successor step is explicitly run.

Before returning any successful Step, the independent unit coverage auditor
checks all exact-input obligations with its equality-graph feasibility algorithm.
One work allowance spans enumeration, proof construction, row merging and audit.
The audit intentionally reuses the kernel for conclusion construction; this is
independent enumeration/feasibility, not another MGU implementation.

ADVANCED returns a new ledger and a changed flag about unit proof recipes only.
An unchanged unit step does not certify compound closure or family admission.
OPPOSITION returns all audited typed private unit oppositions and no successor
ledger. Each proof still states dependsOnX; this status itself is not a family
collision verdict. If any later inference/audit fails, INCOMPLETE returns no
successor, evidence or opposition prefix, even if an earlier proof succeeded.

## Concrete controls

* X @x p(x), A p→q, q→r: first step learns generic q with2Sources/depth1 but
  no r; second learns r with3Sources/depth2. The input ledger never mutates.
* Adding A ~r(9) produces an audited opposition at step2 with exactly the four
  original Sources and depth2, without constructing an empty Clause or Fact.
* An unrelated X plus foreign p and p→q gives a private generic q whose proof
  has no X Source. It does not become shared knowledge.
* Direct p→q and indirect p→r→q retain2/3-source alternatives at depths1/2.
  Composing q→done retains3/4-source alternatives at depths2/3. A depth2 bound
  refuses the whole result/step when the later alternative needs depth3.
* Importing a real sealed compound proof of universal left produces generic done
  with all three original Sources at depth2; wrong-cut evidence and depth reset
  are refused. No shared Product is created by the private ledger.

The driver also covers exact-ledger identity, reopening/stale evidence, old-mode
rejection, immutable lists, null input and work/depth failure without prefix.
The existing universal-unit refusal in the old Frontier start is still checked.
