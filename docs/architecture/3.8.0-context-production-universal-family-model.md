# Stage3au — exact stable universal family model evidence

`ContextUniversalFamilyModel.certify` combines two independently checked facts:
full factored stable-family inference coverage, and an all-admissible-value model
for every exact private closure ledger, including the X self cut. Success yields
an immutable historical certificate with explicit
`FACTORED_STABLE_FLAT_UNIVERSAL_FAMILY` scope. No native write path consumes it.

## Evidence and boundary

The certificate first reruns `FACTORED_STABLE_SHARED` coverage: exact complete
family/snapshot identity, original declarations, shared carriers, Source/depth
recipes, unchanged private closure, independent unit/compound/factoring audits,
retention/export obligations and an unchanged complete common merge. Changed
common consequences require another qualification round even if all current
private ledgers have models. Opposition or incomplete coverage refuses a model
certificate and exposes no partial certificate.

It then matches exactly one supplied immutable quotient model to each receipt's
`closureStep.input` by object identity. Semantic equality, an earlier local closure
or an earlier common frontier cannot replace that historical ledger. Receipt/model
order is irrelevant. Missing, duplicate, null and surplus witnesses refuse.
Each witness is independently rechecked against its ledger, including actual
constant manifest, predicate signatures and all representative valuations.

Coverage and every model recheck use one shared work allowance. All private model
checks also share one instance allowance, capped at65536 across the family.
Individual searches remain separately bounded operations with no certificate
status. Their previous successful checks are not trusted in place of rechecking.
Failure after any successful prefix yields no certificate.

By stage3at's projection argument, each checked model satisfies its ledger over
ALL admissible values. Coverage ensures that every relevant original declaration
and stable common production is present in each appropriate ledger. Thus every
A-X/B-X/etc. cut, plus X itself, has a model containing those common productions.
Each cut may have its own predicate interpretation. Opposite raw sibling facts
are permitted; no single model for the union of all foreign knowledge is required.
No model truth table becomes a knowledge row, negative fact or exported production.

This is consistency evidence for the sealed flat ordinary relational family,
not completeness of arbitrary native inference or authorization to mutate current
storage. Native residuals, calculated/system predicates, variable functions and
witness requirements remain outside the scope. A future authoring integration
must separately establish candidate/family freshness, actual source scope and
transaction lifecycle. Default authoring is unchanged (last stage3r RED56/2).

## Regression controls

The driver certifies independent opposite sibling interpretations in both orders,
checks exact per-cut bindings and list immutability, rejects stale/missing/reused
models and binary-only receipts, and refuses a changed common barrier despite
valid individual models. An actual generic p->q consequence certifies only after
cross-cut requalification; adding a sibling ~q(9) produces an actual collision at
the next complete barrier. Work controls demonstrate that coverage and each model
can pass individually at the selected allowance while their combined check must
refuse. An instance control exhausts the shared allowance after a successful self
model. No partial certificate is exposed.
