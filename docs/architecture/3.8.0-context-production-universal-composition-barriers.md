# Stage3ak: audited flat universal compounds across sealed barriers

ContextOrdinaryResidualRounds.inspectWithUniversalCompositions is a new opt-in
one-sweep observation API. It uses the existing immutable Frontier, private
Receipt/Product constructors and complete-family merge. Existing ground APIs,
certificates, explicit writers and ordinary default authoring are unchanged.
It is not universal closure, a model certificate or write admission.

## Proof path and immutable round

The initial native ordinary/parameter/probe passes produce a verified sourced
ledger. One shared work allowance covers those passes, structural composition,
proof authentication and the stage3aj coverage audit. Native passes additionally
share the existing event budget. Failed baseline receipts propagate directly.

The composition sweep deduplicates actual whole compound clauses, enumerates
all opposite compatible pivots and includes independently renamed self pairs.
A structural MGU trial rejects only a typed Clause.UnificationFailure. Work
exhaustion, cycles and other failures are not misclassified as an impossible
pivot. The stage3ai kernel then authenticates both complete parents and every
actual Support alternative before any Product is constructed. No native
composition observation is claimed: native baseline evidence authenticates the
parents, and the checked logical rule proves their resolvent.

Only the immutable baseline supplies parents. Newly composed conclusions cannot
feed another composition in the same call. Before a successful receipt is
returned, the independent stage3aj equality-graph obligation audit requires all
baseline compound-pair consequences. Its package-private overload consumes the
same work budget rather than resetting it. Conclusion construction still reuses
the kernel, as documented in stage3aj.

All local proofs retain their original Source unions and cumulative depths.
Only positive-depth products with an X source are exported. Foreign-only
compositions remain local evidence. No caller can manufacture a Receipt or
Product, and no supplied detached evidence is accepted as authoring authority.
The existing merge requires one exact-input receipt per cut, including self;
missing, duplicate, stale or failed cuts block the entire barrier. The new
Frontier carries clauses through the existing native replay without replacing
variables by known-value samples or resetting proof recipes.

## Universal units: explicit incomplete boundary

The existing Product add gate continues to refuse a universal unit. Therefore
if any composed result factors to one universal literal, the entire cut is
unverified and has no products, local ledger or collision prefix. This includes
foreign-only unit results: unsupported inference is not silently omitted.
The family merge then returns INCOMPLETE. A detached stage3ai unit proof does
not authorize transport. Ground unit conclusions remain inside the old gate.

For example @x p(x)||left(x) with @y ~p(y)||left(y) has the checked detached
conclusion @z left(z), but this API refuses transport rather than sampling facts.
Supporting such carriers and universal unit parents requires a separate proof
and opposition path; it is the next step, not an admission shortcut.

## Concrete barrier controls

X: @x p(x)||left(x)
A: @y ~p(y)||right(y)
B: ~left(9); ~right(9)

The first common round exports the generic left(z)||right(z) clause with exactly
the X/A sources at depth1. The second common round proves contradiction in B,
with exactly the original X, A and both B assertions as causes. A/B and B/A
orders both collide at barrier2. Another test replays the generic carrier into
the actual private native ledger and verifies that it remains generic with its
original causes and depth. Inspection does not mutate the initial Frontier.

The single-source self-resolution @x p(x,1)||~p(2,x) transports the derived
p(1,1)||~p(2,2) with one original Source and depth1. An unrelated X with foreign
@x a(x)||b(x), @y ~a(y)||c(y) keeps b(z)||c(z) private; another sibling's
~b(1),~c(1) is not pooled with that private result.

The new driver also covers unit refusal, missing/duplicate/stale barrier
receipts, depth/work/events/probe limits with no prefix, and incoherent repeated
variables. Final validation counts are recorded in the main checkpoint/journal.

## Remaining scope

This is one audited compound sweep. Unchanged shared products do not imply
private or universal closure. Universal unit parents/results, a separate
factoring rule, full universal local closure/family certificates, witness/function
language and general write admission remain open. @x still ranges over every
admissible value, including unmentioned values. Default contract remains last
stage3r RED56/2. Question3/hypotheses/orphans remains open.
