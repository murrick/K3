# Stage3f: synchronous fixed point of a sealed positive Horn family

## Why a final unchanged barrier is necessary

With X:p(w),flag(w), A:p->q and B:q&&flag->out, round1 must not let B see A's
same-round q. Round2 gives out, but its changed union still is not a fixed-point
certificate. Round3 independently checks every branch against that common input
and proves that no atom, exact source alternative or minimum depth changes.
Reversing branch execution order yields the same proof pool and three rounds.

A provenance-only counterexample starts with both q and out already present.
A new A authority for q changes no atoms. That authority reaches out only through
B at the following barrier, and a third unchanged barrier is still required.
The implementation compares complete proof-pool content, never atom count alone.

## Unchanged coverage with enabled bodies

exportHornUnchanged validates the entire declaration cut and runs the Stage3e
Horn closure obligations on the sound immutable input itself. All applicable
heads and exact source/depth alternatives must already be present. Success makes
a private unchanged/covered branch Packet bound to that input identity, cut and
captured declarations, without requiring a new native application. The old
absence-of-observation path remains INCOMPLETE; no event heuristic is introduced.
This also supports already-enabled rules at a previously reached fixed point.

The Horn schema checks are extracted into a shared validate preflight. They
still require positive Items, fact-free definite Horn clauses, range-restricted
heads and the existing whole-rule/function-free/declaration bounds. The closure
checker itself still creates no products or supports.

## Immutable execution plan

ContextWitnessFamilyFixedPoint.Plan copies bounded Branch/declaration lists.
It requires exactly one explicit self-X branch and one cut per context, at most16
branches and1..64 declarations per branch. Every foreign branch must contain
exactly the same local-X Source/text snapshot as the self-X branch. Missing,
extra, duplicated or changed X declarations are refused rather than allowing
different parents in different cuts. Foreign raw declarations are used only in
their own fresh private pass. Caller list mutations cannot change the plan.

Before any native pass, all cuts and original declarations are compiled and
checked against the initial parent X and positive Horn schema, including later
unsupported branches. This is a sealed supplied-plan check, not authentication
of a complete live Context revision or discovery of every relevant context.
Full X scalar/rule state is not reconstructed from a detached witness Packet.

## Common-input rounds and outcomes

Each bounded round creates the existing immutable expected-cut family barrier.
Every branch receives the identical current Packet object. It first attempts
proved unchanged Horn closure; otherwise it executes native inference in its
own disposable Mind and calls exportCoveredNext. Only a branch carrying exact
coveredCut evidence can enter this loop's merge; legacy observed-only results
cannot establish completion. Native input/observation failures and unsupported
materialization cases remain INCOMPLETE.

After every expected branch completes, the existing family barrier validates
basis/cuts/producers and combines all results. A changed union becomes the next
common input. An unchanged union yields FIXED_POINT, specifically relative to
this supplied positive Horn plan. The result binds the immutable Plan and exact
initial Packet identity and has an immutable trace of barrier identities,
changed flags and productive/unchanged branch counts. The returned pool drops
individual branch tags, preventing it from impersonating a branch result.

Depth/work/event limits apply to the existing bounded verification/capture
phases; the explicit round bound limits repeated phases. A bound or failed branch
returns INCOMPLETE with no Packet or partial success trace, even after earlier
rounds produced sound knowledge. A changed last permitted round is not success.
No physical parallelism or live project/context mutation is introduced.

The cycle A:p->q / B:q->p reaches the scoped fixed point in four rounds in the
fixture. New returning source groups propagate through p, q and X's p->warm.
Their minimum depths remain2,3 and3 respectively. Existing shallower same-source
proofs discharge longer cycle obligations; infinitely many redundant proof paths
are not enumerated. No general termination promise is made outside this subset
or beyond supplied resource bounds.
