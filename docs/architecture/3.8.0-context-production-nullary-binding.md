`!nativezero;` no longer prevents a later ordinary assertion from completing whole
binding and automatic ground qualification. The production default remains unchanged.

projection now accept arity0..8 instead of1..8. No dummy argument is introduced.

represent zero arguments as an empty list. Predicate name plus argument-vector

`ready` and `ready()` and their signs survive text/native whole-declaration binding.

witness sharing/rank, native origin/shape equality and all upper bounds stay intact.

does not create or borrow a witness origin.

signed direct collisions, durable primary inventory, all-nullary masked barrier2
conflicts in both A/B orders, mixed universal/nullary barrier2 conflicts with full
independent family audit, nullary disjunction saturation with separate checked

actual native publication preserves the nullary premise. Negative nullary conclusions
can participate in full clause refutations, retaining Source/depth proofs. The
expanded witness-bundle roundtrip oracle compares restored bundles against ordinary
native qualification for nullary positive/negative restrictions and arity mismatch.
The automatic-policy compatibility control now asserts successful nullary binding,
ordinary native publication and retained nullary query truth.

## Separately proved existing capture limitation

X has `$w seed(w,1)&&gate` and `@w seed(w,1)->warm(w,1)`. WR has
`@w seed(w,1)->ready`. The pending proposal is `ready->out`. Complete binding now
succeeds, but witness family qualification refuses at round1 with
`unsupported-capture-gap:unobserved-materialization`. Native inference independently
proves `ready` from a local witness source and that rule, so this is a missing
observation/proof route, not a negative logical answer.

An entirely non-nullary control uses X `$w seed(w,1)&&flag(w,1)` plus the same warm
rule, WU `@w seed(w,1)->ready(1)`, and proposal `ready(1)->out(1)`. It produces the
same INCOMPLETE capture gap. This control was also compiled/run against the unchanged
stage3bm production classes, before the three arity checks were widened. Thus the
gap is not introduced by accepting arity0; both rules discard the witness from the
conclusion. Native-hook controls keep both refusals typed INCOMPLETE and preserve
physical revision. No missing event is silently invented and no incomplete prefix
is treated as saturation. Full witnessed nullary-result publication is not claimed.
