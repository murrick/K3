Native rules may coalesce alpha-equivalent clauses. The bridge groups the exact
proof objects by their actual native Rule ID and checks every observed producer's
complete Support alternatives, comparing both original Source sets and depths.

Sources/depth1 remain separate alternatives of one native producer. Sources are
not flattened into one union or depths reset to0.

Each witness observation must be an exact whole schema instance with preserved
fixed/repeated arguments. Its positive literals must refer to one known,
non-dominating carried canonical origin. Ordinary ground events receive the same
shape check and exact producer-proof label binding, using a new shape-only
GroundApplicationVerifier helper that grants no primary authority. Unsupported
roots/signs/transport gaps and work/event limits fail with empty bindings/events.

The immutable result retains input/common/local basis IDs, fresh replay UUID,
frame cuts, native producer->schema-proof bindings, observed producer events and
outstanding capture gaps. No live Mind is retained. It creates no conclusion
Support, Route, common Packet, round receipt or admission verdict. Producer
binding does not prove that the observed premises have authenticated donors, nor
that stored witness materializations preserve the required correspondence.
The depth parameter bounds schema producer proofs here, not a conclusion proof
that has yet to be reconstructed. Those duties remain the next integration step.

The common input packet is unchanged, including when private unit/theorem inputs
are replayed. Private producer receipts cannot borrow an unrelated X anchor.
Original strict scope/export behavior is unchanged; raw schema gaps remain visible.
