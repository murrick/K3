## Full-domain interpretation, not a named-value sample

A model supplies distinct typed named points and a concrete ordinary `otherRepresentative` outside them. Every other admissible ordinary value belongs to the ALL-other class. Relation tables have an explicit default for all unlisted class tuples plus bounded exact exceptions. The classes partition the entire value universe; they are not a finite search horizon. Every actual original/final constant must be named, including its exact semantic type. Uniform truth cannot skip that preflight.

Each existential declaration has an exact physical Source/declaration-position function key. Its total function table has the precise arity of preceding universal declarations, a default output class and exact tuple exceptions. All coordinates range over named classes and ALL-other. There is no predicate/dependency arity ceiling beyond input/work/resource bounds. Distinct functions may choose the same value; Source identity does not assert inequality.

This supplies a constructive full-value interpretation: classify every input value, look up the total function table and choose the named output point or `otherRepresentative`. Interpret every predicate by its class table. Universal class checking then covers every actual admissible value. Existential choices depend only on the original preceding universals. Models are separate per independent cut; whole physical TRUST members share one cut model. X is included in each exact cut, and each model interprets the common derived declarations it receives. This is per-cut compatibility, not an A/B union model.

The supplied finite quotient/table format is a class of possible interpretations. Failure or resource exhaustion is INCOMPLETE, not proof that no model exists. This stage performs no automatic model search. Model choices are detached data; their values are never installed as native knowledge.

## Independent actual-final carrier audit

The workflow runs a fresh bounded dependent cycle itself. It accepts no cached caller-supplied iteration result or manifest. Only a supported-unit FIXED_POINT can proceed to model checking; an actual sourced iteration refutation returns REFUTED. Failed supplied interpretations never produce REFUTED.

The final manifest is taken directly from the frozen barrier: every actual common proof ticket in every receiving cut, plus every actual visible private/common product occurrence in that cut. Repeated and strict-superset proof alternatives remain obligations. This deliberately counts occurrences, including overlapping common/visible manifestations; it is not the representative frontier or an invented head list.

The checker validates every carrier's exact producer/support and every nested witness Source/binder/dependency rank against the complete physical original declaration registry. Imported foreign functions may be needed in a receiving model even when that foreign original formula is not a receiving premise. Required signatures/functions must match exactly, with no missing/extra interpretation entries.

Actual detached term graphs are evaluated bottom-up from their typed values, variable assignments and supplied function tables, including nested expressions such as f(f(1)). Final universally free variables use a mixed-radix odometer, independently of the original DFS. The final-work budget and occurrence bound cover every actual common/private carrier across all cuts. Original success alone cannot create a final success; failures return no successful model prefix.

Here actual-final means actual frozen dependent transport carriers. It does not mean a materialized native DB candidate: dependent applications are still detached graphs, with no generated native Rule/Term publication. Native actual-candidate integration remains a separate required gate.
