# Stage2n: bounded audited multi-premise Horn coverage

The explicit inspectWithVerifiedHornCoverage entrypoint returns AUDITED_HORN
only after immutable synchronous rounds settle and every private cut passes
source conformance, native representative rotation audit and read-only proof
obligations. Default inspection, AUDITED_LINEAR_HORN and runtime write gates
retain their existing behavior.

## Scope and protocol

Primary declarations admit signed units or definite Horn clauses with at most
three literals (two premises) and two native variables across the entire rule.
Values are uninterpreted numeric/string constants; functions, calculations,
existential witnesses and non-Horn disjunctions are excluded. Distinct source
occurrences must have consistent declared shapes. All effective input shapes
are checked before linking. The family-wide maximum rank fixes the fresh
parameter basis from the start; family constants are shared as vocabulary,
never as foreign facts. Each participant still sees only X plus itself.

Actual native admission and database visits must cover the representative
assignments of each quantified rule in the final settled private replay. Proved
pool clauses are expanded by universal elimination into detached instance
evidence. Primary shape metadata cannot enter that evidence pool. Every source
unit instance and every applicable nonempty subset reduction must have an
existing proof, preserving each whole producer/donor source combination at
minimum depth no greater than max(input depths)+1. Universal elimination itself
has zero extra depth. A missing proof yields INCOMPLETE, never a synthesized
production or native collision witness.

A derived residual may contain zero positive literals: for example ~r reduces
~a || ~b || r to ~a || ~b. The detached checker now admits these negative Horn
residuals and verifies their reductions too. Primary nonunit declarations still
require exactly one positive literal. This does not widen primary syntax to
arbitrary negative constraints.

## Why the finite check is sufficient within the admitted scope

In a representative cut, assign true exactly to the proved positive ground
units. Source positive units have their required instances. Any definite Horn
clause whose premises are true must have its head proved by the all-premise
subset obligation; otherwise certification fails. A negative Horn residual
cannot have all of its atoms true: the corresponding all-literals-falsified
obligation refuses certification. Signed negative units cannot oppose proved
positive units. Hence this assignment is a model of the representative cut.
It is a model witness, not an assertion that unknown atoms are false.

The language has no interpreted functions, equality or value tests here. A
retraction fixing each family constant and mapping other values to fresh
representatives extends the finite model to arbitrary admissible values.
Fresh-parameter proof substitution preserves independent and diagonal variable
positions. The separately checked source/depth obligations certify the bounded
primitive residual transport surface, not every equivalent logical proof or
query/hypothesis history. Independent siblings need not share a common model.

## Native controls and an explicit conservative boundary

X forall x,y left(x)&&right(y)->out(x,y), A left(1) certifies the universal
partial residual without asserting its head. Adding B right(John) certifies the
joined out(1,John), supported by all three source occurrences at carried depth2,
in either participant order. Adding a third participant ~out(1,John) gives a
native collision witness in all six orders. A depth1 limit refuses the carried
join. Duplicate source occurrences retain separate residual proof alternatives;
opposing foreign siblings with no X-dependent consequence remain independent.

The eight signed Boolean input subsets of a&&b->r provide an independent oracle:
none/a/b/~r certify; a,b,~r has a native collision. The three consistent cases
with two falsifying units (a,b or a,~r or b,~r) currently return INCOMPLETE with
horn-residual-proof-missing. In particular a,b has the valid r proof at depth1
with all three sources, but no two-literal residual products. That proof cannot
stand for the required partial residual with a smaller whole source group.
This is a documented boundary of proof observation/certification, not evidence
that the native inference r is wrong or that the runtime accepted a contradiction.
No Core change is justified by this observation alone.

Later work must decide and verify how to observe those partial support groups
without treating shape metadata as proofs or enumerating sibling unions.
Runtime gate integration, real effective views/pins, witness transport and
question3 (query/hypothesis/orphans) remain separate pending work.
