## Typed symbolic step

New `ContextUniversalInputResiduals` treats each term as one of a clause-local
universal variable, an ordinary semantic value, or a rigid original Origin
(Source plus binder). Origins cannot be alpha-renamed into variables or values;
the same local binder number under another whole Source remains a different
origin. Distinct origins do not assert inequality, but do not supply a proof of
equality. Universal variables remain scoped to their residual; future resolution
between residuals must standardize their variable scopes apart.

For example consuming seed(c,1) in
`seed(u,1)&&gate(v,1)->rel(u,v)` proves `gate(v,1)->rel(c,v)` with c rigid and v
universal. It does not prove forall u,v rel(u,v). Conversely, the ground q(7,1)
conjunct in the starting example carries no witness argument, so u stays
universal in rel(u,7); the unrelated witness in that whole Source is not inserted
into the conclusion.

Every Step retains the exact checked schema Proof, negative body pivot, actual
sealed input Item and donor Support, consistent variable assignment, typed
residual and Support union at max(schema depth, actual donor depth)+1. Constants,
repeated-variable constraints and frozen identity are checked by the existing
opposite-literal matcher. A private kernel recomputes the match, substitution,
residual and Source/depth label before retaining the step. Exact duplicate
literals are removed; remaining variables/origins are collected immutably.
Residual equivalence permits literal permutation and consistent universal alpha
renaming, while preserving rigid origins and semantic constants.

## Exact enumeration boundary

The scanner rechecks the complete sealed unit-closure ledger and parent/target
cuts, then considers every schema proof, every negative body position, every
actual positive input Item and each of its authenticated donor alternatives.
There is no native encounter precondition and no caller-selected theorem subset.
Different matching pivots and Source alternatives retain separate proof steps,
even when residuals are equivalent. Support alternatives are not union-flattened,
relabelled as primary knowledge, or reduced by subset-source dominance.

Common input and owning PrivatePool entrypoints preserve exact input identities
and cuts. Private raw facts may be used only within their actual owning cut or
explicit trusted group. An unrelated X anchor never enters a private proof.
Carried X-dependent facts with private ancestry preserve their actual full donor
Source set and depth; origin.Source alone is not a replacement proof.

Depth<=64, steps<=65536 and shared scan work are bounded. A later required step
that exceeds a bound clears all earlier successful step prefixes. These bounds
apply to the enumerated step witnesses, not a claim of globally shortest proofs.
Wrong cuts, signed input, an unfinished/unsupported schema ledger, or work/step
limits return enumerated=false with no steps. The scan never returns COLLISION.

A successful result certifies exactly this finite one-pivot input projection.
An empty result can be vacuous. Positive universal schema units remain in the
checked schema ledger; no finite value enumeration replaces them. New residuals
are not recursively fed back in this scan. In particular, frozen residual/schema
interactions and later donor-enabled steps still require saturation. The result
constructs no Packet, native Rule, round stamp, family verdict or writer permit.
No existing native/public DMZ language scope is widened by its typed proof data.
