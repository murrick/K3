## Equivalent scopes and two clauses under one source

Shared form: `!($x (a(x)||b(x)))->q();`.
Independent form: `!(($x a(x))||($y b(y)))->q();`.
Unlike conjunction in the preceding stage, these forms are equivalent.
Existential quantification distributes over disjunction. Negating the
antecedent gives two universal clauses, `~a(x)||q()` and `~b(x)||q()`;
each uses one universal variable after clause-local normalization. Both belong
to the same whole original rule Source. No witness object is introduced by
these negative existential occurrences.

The376-check scope driver compares the two nested forms, their corresponding
prenex universal forms and alpha-renamed declarations, both atom polarities and
zero-arity/ground-unary heads. One primary entry, CLAUSES kind/zero witnesses,
exactly two two-literal clauses, one used universal variable per clause, exact
signs and consequent independence are checked. Each a/b branch occurs once;
corresponding clauses are alpha-equivalent in every form. This does not extend
positive existential witness support or permit source fragmentation.
