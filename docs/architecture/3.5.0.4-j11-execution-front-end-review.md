## Ownership review

- Parser owns only call-local token/AST state and UDF declaration parsing.
- Compiller owns no semantic identity; it publishes exclusively through Mind factories.
- Calculator owns operation catalogs and dispatch, not transactions, fixed-point or semantic units.
- Analyzer owns query-local interpretation and stores, not Rule persistence or convergence.

The existing `Functions` and `Predicates` classes remain built-in operation
catalogs behind Calculator. Their individual public operation methods are
assigned to the public API audit rather than duplicated as internal architecture.
