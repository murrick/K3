## Proven native false acceptance (capture disabled)

```
!$x p(x,1);
!@x p(x,1) -> q(x,1);
!@x p(x,1) -> r(x,1);
!@x q(x,1) && r(x,1) -> out(x,1);
!@x ~out(x,1);
```

Every compile succeeds. The existential witness for p must satisfy q, r and out,
contradicting the last rule. Bare native qualification also returns true. Putting
the denial first still accepts the inconsistent input. Replacing the existential
p by ground p(1,1), or by the primary conjunction exists(q && r), correctly rejects
the denial. Even the unary chain exists(p), p->q, q->out, forall(~out) is accepted;
the defect is therefore broader than the two-premise join.

The observed fork journal contains no complete out application. Its q and r
materializations have separate durable carriers. This is diagnostic evidence,
not yet a proof of the exact faulty Core operation. No Core repair or global
witness-root equivalence is introduced in this milestone.
