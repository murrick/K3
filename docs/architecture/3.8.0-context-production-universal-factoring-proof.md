# Stage3ar: detached source-authenticated flat factoring

The stage3aq diagonal counterexample proves why binary-only closure is insufficient:
@x @y p(x)||p(y) and @x @y ~p(x)||~p(y) stabilize without a binary opposition,
but diagonal instances require both p(v) and ~p(v). This stage adds a checked
unary factoring proof and independent one-step obligations; it does not yet
insert factoring results into the shared/private transport ledger.

## Same-parent MGU and the whole remainder

Clause.factor selects two DISTINCT same-sign, same-predicate/arity literals in
one complete compound. Variables keep their single shared parent scope. Flat
unification dereferences every binding, preserving repeated-variable constraints.
Different ground semantic values refuse; there is no apart-renaming of the two
selected literals. All remaining literals, including the retained selected one,
receive the SAME substitution, and remaining free roots are canonically renamed
together. Exactly the second selected occurrence is removed; subsequent literal
idempotence may collapse other identical instances. Empty clauses are impossible.

Examples:

* p(x)||p(y) factors to generic p(z), not a list of known-value facts.
* ~p(x)||~p(y) factors to generic ~p(z), retaining its sign.
* p(x,1)||p(2,x) refuses: the same x cannot be2 and1.
* p(x,1)||p(2,y) factors to the actual ground p(2,1).
* p(x,x)||p(y,y)||link(y,x) becomes p(u,u)||link(u,u).
* p(x,1)||p(2,1)||tail(x,y) becomes p(2,1)||tail(2,z); unrelated y stays free.

These primary fixtures stay within the existing native binding width/variable
limits. No expansion of the parser/native binding contract is part of this step.

## Checked unary proof and actual authority

ContextUniversalFactoringProof requires a sealed historical ledger and an entire
actual parent clause, authenticated up to alpha-equivalence against actual rows.
Matching selected literals cannot authenticate an invented parent missing a
remainder. Every actual parent Support alternative participates independently.
The factor keeps exactly that whole Source group and depth parent.depth+1; it
creates no Source and performs no Cartesian combination with an unrelated parent.
Private Evidence/Proof constructors bind exact ledger identity and immutable data.

The logical rule is unary universal instantiation: every valuation of the factor's
remaining variables extends through the MGU to a parent instance whose two selected
literals coincide. Their disjunction is idempotent, so the factor follows. This
argument applies to all admissible values, including unmentioned values. Ground
slots are ordinary semantic values; function terms containing variables and
existential witnesses remain outside flat factoring.

Work/depth overflow, invalid positions/signs, absent whole parent and alternative
limits return proved=false with no proof prefix, even if a direct shallow support
succeeded before a later deeper support failed.

## Independent factoring obligations

ContextUniversalFactoringCoverage inventories all actual semantic compound rows,
enumerates every unordered literal-position pair, and uses the independent
same-parent equality graph to decide feasibility. For each feasible pair the
kernel constructs the required factor and every original Support alternative;
actual supplied sealed Evidence must cover exact source/depth recipes and
alpha-equivalent factors. One shared work budget spans graph, kernel and matching.
Wrong/reopened ledger evidence, missing factors, parent depth and other bounds
refuse coverage. Conclusion construction deliberately reuses the kernel; this
is independent enumeration/feasibility, not a second MGU implementation.

## Concrete controls and remaining integration

The driver checks both generic units from the actual diagonal counterexample,
exact ground/repeated-variable/remainder behavior, whole-parent authority,
separate alternatives and bounded failure. Binary stabilization supplies the
same positive parent with original1-source/depth0 and derived2-source/depth2
recipes; factoring retains1/2-source proofs at depths1/3. A depth1 allowance
returns no earlier direct prefix when the later alternative needs depth3.

Independent exhaustive small interpretations instantiate the complete parent and
all factor instances, including fresh unmentioned values. Every parent model must
satisfy every result instance, with nonvacuous parent models. These finite searches
are counterexample controls, not the proof of universal validity/domain finiteness.

Factor proofs remain detached: no Row/Product is constructed, the unit kernel
cannot use a detached factor as an actual ledger parent, and the stage3aq stable
factoring refusal remains in force. Final counts are in the main checkpoint and
recovery journal. Next: integrate checked factoring and its independent audit
into immutable local steps/combined family coverage; only then replace the
unresolved boundary with an actual sourced refutation. Universal model/native
residual/witness/function scope, default authoring and question3 remain open.
