# Stage499: alternating-prefix native collision counterexample

## Required behavior and proof

The following pair is inconsistent over all admissible values, including values
not yet mentioned in the database:

```text
!@a $u @b rel(a,u,b);
!@a @u ~(rel(a,u,1)&&rel(a,u,2));
```

Choose any a (in particular 1). The first row supplies one u for that a, before
b is chosen. Instantiate b=1 and b=2 with that same a,u. Both atoms hold.
The second row forbids precisely their conjunction. This proof needs neither
a finite domain nor distinct existential witnesses nor a query/hypothesis oracle.

Moving the existential after b changes the result:

```text
!@a @b $u rel(a,u,b);
```

Together with the restriction this is consistent: interpret rel(a,u,b) as u=b
over the whole admissible domain. For each a,b choose u=b. Since the named numeric
values 1 and 2 differ, no single u satisfies both forbidden atoms. This is a
whole-domain interpretation, not an enumeration of currently stored values.

## Consequence and boundary

This demonstrates a missed native qualification collision under alternating
quantifiers. It does not prove a conceptual contradiction in independent A-X/B-X
contexts. It is distinct from stage2p's already documented forall-exists versus
exists-forall examples and its unresolved query/hypothesis observations.

DMZ native binding already refuses these mixed universal/existential rows. Keep
that refusal: this stage changes no production code, qualification acceptance,
writer path, model receipt or semantic baseline. No correction is proposed until
the native dependency/comparison path is localized against this counterexample.
The immediate next batch is that localization and a fix only if it preserves
both consistent controls and independent original/final checking. Full mixed-prefix
DMZ admission remains open after any native fix.

this investigation. Existing required universal-family RED101/missing8 remains
