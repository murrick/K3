## Documented boundaries

### Shared canonical identity

- equivalent Term descriptors resolve to one active canonical Term;
- equivalent Predicate name/range descriptors resolve to one active canonical Predicate;
- child calls observe the same registries as the parent;
- child creation does not imply private Term/Predicate identity.

### Persistence ownership

- each factory may borrow a current-generation schema `IBase`;
- cache misses may hydrate units through that attachment;
- root update may persist category changes;
- `User` / `IData` retain storage-generation and close authority;
- `closeConnection()` remains compatibility/authority debt for `3.5.0.5`.

### Reachability cleanup

`DictionaryFactory` documents:

- first full pack and later incremental candidate frontier;
- active Rule-term snapshots;
- temporary retention by solutions, hypotheses, and values;
- symmetric C-variable adjacency unlink during Term deletion.

`PredicateFactory` documents:

- compound identity by name Term and range;
- full-scan packing;
- retention through active Rules and current solution/hypothesis projections.

### Runtime versus durable state

- canonical units may participate in persistence;
- Dictionary C-variable adjacency remains Mind-owned transient runtime state;
- projection stores are temporary reachability roots, not factory-owned durable repositories;
- local synchronization protects specific mutations, not blanket thread safety.
