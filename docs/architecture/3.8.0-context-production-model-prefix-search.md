# Stage3bd — bounded quotient model search with false-prefix pruning

## Concrete cost boundary

Stage3bc retained a native-valid candidate
`!@x @y @z seed(x,y,z)->ready(z,y,x);`, foreign seed(1,2,3) and a different
negative ready(3,1,2). Its safe family inspection stopped at the existing model
assignment limit. The old false-first enumerator checked clauses only after all
Boolean predicate profiles were assigned: a prefix already falsifying a whole
clause still caused enumeration of every suffix. This was bounded incompleteness,
not an erroneous consistency or collision verdict.

## Changed search, unchanged independent witness check

Search now checks each encoded clause at every assigned prefix. Only profile
indices below the prefix length are assigned. A clause remains possible when it
has an unassigned literal or an assigned true literal. If neither exists, every
completion falsifies that clause and the entire subtree is rejected. Unassigned
tail slots, including stale values left by a previous subtree, are ignored.

No satisfiable completion is discarded: the only pruning condition is an already
fully assigned false clause. Branch order remains false then true in the original
profile order, so sufficient-budget search keeps the first lexicographic satisfying
interpretation. It does not propagate units, change quotient constants/profiles,
merge private cuts or create clauses, Sources, depths or knowledge.

Every returned total interpretation still passes the existing independent raw
ledger checker over all projected variable valuations before exposure. It does
not trust encoded CNF indices or the search assignment array. Independent candidate
and family audits remain mandatory. Failure to find a model still provides no
sourced collision proof; limits expose no partial model or certificate.

## Resource accounting

The existing model-attempt counter is now debited once for either a rejected
false prefix or a complete candidate model. Previously it was debited only for
complete Boolean assignments. A pruned prefix costs one attempt; its skipped
completions are not individually enumerated or charged. Thus equal numeric limits
can now reach models previously beyond the bound. A forced-positive one-profile
case with models=1 still stops after its first false attempt, without a witness.
The same counter remains shared across all private cuts. Every prefix and literal
scan charges the existing shared work budget; instance construction/check limits
and all public default numeric bounds are unchanged. No overall termination or
completion guarantee is introduced.

## Controls

An independent eight-valuation Boolean oracle tests all64 combinations of three
positive-pair clauses in X and three negative-pair clauses in the foreign source.
Each source is individually satisfiable; their union may be unsatisfiable. Actual
model existence must equal exhaustive oracle satisfiability. Every returned
interpretation must belong to the oracle solution set and independently check
against the raw ledger; failure has no model or source-bound collision. Original
ledger rows retain depth0. This exercises contradictory prefixes, satisfiable
alternatives and stale-tail backtracking without reusing search's CNF evaluator.

The stage3bc ternary budget example now must return CONSISTENT with an independent
all-value candidate audit under the same former limits. The same example with
models=1 remains INCOMPLETE. Existing model/work/instance/family shared-budget
controls, exact historical ledger identity, independent sibling interpretations,
unknown-value semantics and immutable model evidence remain in the regression.

Three-variable binding and width3 are unchanged. Four variables, witnesses and
variable-containing functions retain their current boundaries. Ordinary default
input is unchanged; last default contract3r RED56/2, general native residual scope
and question3 remain open.
