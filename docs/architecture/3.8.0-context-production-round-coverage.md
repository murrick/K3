## Separate certificate

The existing `exportCoveredNext` and full Horn closure verifier remain strict.
A new `exportRoundNext` authenticates the same owning whole source declarations,
re-verifies actual native proof routes, and checks all Horn obligations enabled
by its exact common input against the sound observed output. All donor source
alternatives and max-depth+1 requirements are included. Every carried input proof
must survive, or be replaced by a shorter proof with exactly the same sources.
An absent input-enabled head/proof still refuses.

Output-enabled bodies are obligations of a later common barrier. The checker
does not generate them or assert their closure. A private Packet constructor
seals `roundCut` separately from `coveredCut`, with the owning input identity and
producer cut. Generic family merge validates either tag's target and discards
both tags on the merged pool. Old branch results cannot be reused at another
input identity.

The family executor accepts either full closure or input-step coverage for a
changed barrier. All branches still receive the same immutable input; no branch
sees another branch's partial results. Before returning FIXED_POINT on an
unchanged merged barrier it explicitly verifies full closure of every complete
branch declaration snapshot against that final pool. Work/depth/event/round
failure still returns INCOMPLETE without a partial accepted packet or trace.
No assumption of finite termination is added.

The original same-cut fixture now takes two productive barriers and an unchanged
fully closed barrier. It retains exact four-source depth2 evidence; reversing

finds the delayed collision at merged barrier2. Round1 limits do not accept a
