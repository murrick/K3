# Stage3ad: sealed ground composition transport and independent coverage

The explicit ContextOrdinaryResidualRounds.inspectWithCompositions API combines
the existing full ordinary/parameter/unit-probe baseline with stage3ac checked
ground resolutions. The public old inspectWithProbes path is unchanged; its
implementation is shared privately so work/event/probe allowances are not reset.

## Sealed observation and transport

Composition observation replays each semantic clause in the complete baseline's
localProofs once, with every actual whole-source alternative and depth. It checks
whole-clause round trips and complete inputs, and refuses capture gaps. Native
candidate pairs are authenticated against that sealed baseline by the ground
proof checker. The checker shares the same work budget. New resolution outputs
are added only after candidate observation; they never feed another candidate
in this call. Full original/carried owners remain in the receipt.

Each proof retains the original source union and max(parent depths)+1. Only
positive-depth X-dependent proofs enter exported products. Foreign-only
compositions stay in localProofs. No raw sibling fact or local model assignment
becomes X knowledge. Composition results cross the existing exact-input,
all-cuts barrier via private-constructed Receipt/Product objects; callers cannot
inject a historical Evidence as a fresh receipt. Opposing actual ground units
are handled by the existing typed collision path. Work, events, probe, proof
count or depth failures return an unverified empty receipt without a successful
prefix. The complete family barrier must validate all cuts before any collision
or changed pool is accepted.

## Independent ground coverage

ContextGroundCompositionCoverage does not trust native candidate enumeration.
It independently examines every pair of distinct semantic compound ground
clauses and every opposite pivot in the chosen ledger. For every pair of actual
proof recipes it demands the complete remaining clause, exact whole-source union
and proof depth no greater than max(parents)+1. Missing proof means uncovered.
Unit donors are a separate ContextOrdinaryResidualCoverage obligation. Identical
semantic parent clauses are not a distinct pair in this scope.

INPUT_STEP uses original and carried owners; LOCAL_CLOSURE uses every actual
local proof, including newly proved compounds and foreign-only lemmas. Complete,
unique, collision-free receipts for the exact Frontier and every cut are
mandatory. Nonground clauses and exhausted depth/work remain uncovered. An
unchanged shared pool is insufficient; both local audits are still needed.
This is scoped ground coverage, not general language completeness/admission.

no new result was fed to a sibling within that round. The collision preserves

depths. Old reduction-only receipts fail the first composition coverage audit.
A separate consistent ground example reaches an unchanged second barrier and

second-step proof. The current one-pass composition method therefore cannot
certify this private chain. Next work must preserve/complete local composition
closure per cut without exporting raw foreign-only knowledge into X.
