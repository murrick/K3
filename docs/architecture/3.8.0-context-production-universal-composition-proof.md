## Apart variable scopes and coherent MGU

Clause.resolve is a structural helper only: no Source, proof, native assertion
or knowledge is created by that operation alone. It first renames EVERY variable
of the two complete parents into disjoint spaces. Local variable numbers and
lexical names in different clauses cannot identify a variable. The selected
pivots must have opposite signs, identical predicate and arity.

Flat unification dereferences variable bindings on every argument. It merges
variable roots or binds a root to an actual ordinary ground semantic value;
two ground values must be semantically equal. Repeated occurrences therefore
remain coherent: p(x,x) and ~p(1,2) do not unify. Terms here are flat universal
slots or opaque ground ordinary values. There is no function term containing a
variable, existential witness substitution or arbitrary term-building rule;
occurs-check complications of function unification are outside this scope.
A defensive cycle guard and shared work bound protect dereferencing.

The same substitution is applied to EVERY remaining literal of both parents.
Exactly the two pivot literals are removed. Remaining free variable roots are
canonically renamed together, preserving equality and independence; identical
substituted literals factor by idempotence. A universal unit conclusion stays
universal. No finite set of known constants is used to generate the resolvent.

The checked proof rule is ordinary universal resolution: under the MGU, the two
whole parent instances have opposite pivot literals, so every valuation of the
remaining variables satisfies their combined remainder. This argument applies
to every admissible value, including unmentioned values. The result is a single
proof step, not a claim of termination or complete first-order search.

## Actual parent authority and alternatives

The public prove API accepts a receipt, two proposed complete clauses and pivot
indices. BOTH parents must match whole actual localProofs up to alpha-equivalence.
A matching pivot alone, an invented partner or an absent foreign ledger cannot
authenticate. Every actual alternative proof of each selected clause participates
in the Cartesian product. Each Proof records both original parent Supports,
their exact whole-source union and depth max(parents)+1. Equivalent recipes can
collapse; different alternative source groups remain separate. Cumulative depth,
work or proof-count failures expose no earlier successful prefix.

Evidence/Proof constructors are private. Evidence binds the exact historical
Frontier and cut Snapshot, with explicit scope
ORDINARY_FLAT_UNIVERSAL_BINARY_RESOLUTION. Lists/clauses/scopes are immutable.
No result enters Receipt.localProofs, a shared Frontier, a model or storage.
The existing universal-unit transport refusal is not relaxed by this helper.
Foreign-only proofs remain local evidence, not automatically X knowledge.

## Concrete controls

* Independent x in p(x,1)||left(x) and ~p(2,x)||right(x) binds respectively to2
  and1, yielding left(2)||right(1). Sharing their native variable number would
  incorrectly report an unification conflict.
* Independent retained variables in p(x)||left(y) and ~p(y)||right(x) remain
  independent in @u @v left(u)||right(v). No information is lost to capture.
* p(x,x) versus ~p(1,2) refuses; p(x,x) versus ~p(y,z) propagates the merged
  variable into left(v)||right(v,v).
* Universal original X ~a(x)||~b(x)||~c(x) and A d(y)→a(y) yield
  @z ~d(z)||~b(z)||~c(z) with the exact two sources at depth1.
* A previously proved @x @y rel(x,y)→out(x,y) remainder composes with
  @u @v out(u,v)→done(u,v) into the generic rel→done rule. Direct/derived anchor
  alternatives keep separate3/4-source groups at depths2/3. A depth2 allowance
  returns no prefix when the later depth3 alternative is reached.
* Identical remainders can give a universal unit proof; no sampled ground fact
  replaces it. Same signs, invalid pivots, invented/missing parents, unverified/
  absent receipts and bounds cannot prove a step.

Independent counterexample search enumerates small interpretations of ALL parent
and result instances over a test domain containing the actual constants and at
least one fresh unmentioned value (two fresh values for constant-free cases).
It checks nonvacuous parent models and every result instance. These finite tests
are not a domain restriction or the justification for universal proof generation;
the structural universal-resolution argument supplies that justification.
