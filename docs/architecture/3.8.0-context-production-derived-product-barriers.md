DerivedTransfer for each expected cut, including X if X is expected. Every
receipt must refer to the same actual common input object, correct parent and
owning target. Missing/swapped cuts and mixed input barriers fail without a
partial Packet or private-pool map. A reversed expected-cut order and output-map

Private pools then rebase onto the one merged common Packet; original common,
local and post-transfer pools remain unchanged. Rebase uses the existing bounded
local preservation checks. Merge work and each rebase call remain bounded.

it supplies no closure, refutation, qualification or write verdict.
