# 3.5.0.7 runner isolation closure

This document records the final refinement of artifact 3.5.0.7.

Permanent regression, profiling and safety runners are retained, but removed from the production module source roots. Investigation-only wrappers and one-shot infrastructure remain retired.

## Qualification source tree

All 36 retained executable gates and reproducible profiling tools live under:

```text
kanger-qualification/src
```

The inventory was reconciled against the stabilization and optimization PR chain and then verified directly by a source-root scan. It includes:

- historical and stabilization corpus entry points;
- Mind, factory, transaction and rollback safety gates;
- Linker, C-variable and canonicalization gates;
- RuleCandidateIndex concurrency and contextual rendering gates;
- DUMB integrity, Q2 recovery and strict Q1-Q3 qualification;
- semantic planning, Linker profiling, yield/effect and performance runners;
- the historical D1/D2/D3 diagnostic gate.

Their existing Java package names are intentionally preserved. Several gates verify package-private lifecycle, canonicalization, transaction and storage contracts; changing their packages would either weaken those checks or require reflection-only access.

Maven attaches this tree only through `add-test-source`. Consequently qualification classes:

- are compiled on the test classpath;
- remain executable from CI;
- are excluded from the production JAR;
- are excluded from the owned production API and Javadoc surface;
- no longer clutter `kanger`, `kanger-console`, `kanger-data-dumb` or `kanger-udf` production roots.

Permanent workflow gates now:

1. reject any `*Runner.java` under production source roots;
2. reject any `*Runner.class` in the packaged production JAR;
3. require all 36 retained runner sources to remain test-compilable;
4. execute specialized DUMB gates from `target/test-classes`.

## Retired infrastructure

The artifact removes the investigation-only factory concurrency wrapper, one-shot scoped-C-variable Javadoc workflow and its patch script, together with their dead PR-specific CI job.

The final artifact is acceptable only after the complete regression and qualification matrix passes on the exact integration HEAD.
