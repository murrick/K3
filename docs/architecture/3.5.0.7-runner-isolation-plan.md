# 3.5.0.7 runner isolation closure

This document records the final refinement of artifact 3.5.0.7.

Permanent regression and safety runners are retained, but removed from the production module source roots. Investigation-only runners and one-shot infrastructure remain retired.

## Qualification source tree

All 29 retained executable gates live under:

```text
kanger-qualification/src
```

The inventory was reconciled against the stabilization PR chain, including the Mind/factory, RuleCandidateIndex, contextual rendering, DUMB integrity, Q2 recovery and strict Q1-Q3 qualification runners.

Their existing Java package names are intentionally preserved. Several gates verify package-private lifecycle, canonicalization, transaction and storage contracts; changing their packages would either weaken those checks or require reflection-only access.

Maven attaches this tree only through `add-test-source`. Consequently qualification classes:

- are compiled on the test classpath;
- remain executable from CI;
- are excluded from the production JAR;
- are excluded from the owned production API and Javadoc surface;
- no longer clutter `kanger-console` or `kanger-data-dumb` source roots.

The DUMB workflow executes all specialized gates from `target/test-classes` and permanently rejects any packaged production JAR containing a `*Runner.class` entry.

## Retired infrastructure

The artifact also removes the investigation-only factory concurrency wrapper, one-shot scoped-C-variable Javadoc workflow and its patch script, together with their dead PR-specific CI job.

The final artifact is acceptable only after the full regression and qualification matrix passes on the exact integration HEAD.
