# 3.5.0.7 runner isolation plan

This document records the final refinement of artifact 3.5.0.7.

Permanent regression and safety runners are retained, but moved out of module root packages into dedicated qualification packages. Investigation-only runners and one-shot infrastructure remain retired.

Target packages:

- `org.kanger.qualification` for core and console qualification entry points;
- `org.kanger.storage.qualification` for DUMB storage qualification entry points.

The production package roots must contain runtime/API classes only. CI continues to execute every retained invariant gate using the new package names.
