# Stage2q: primary existential conjunction bundle roundtrip

## Admitted carrier

ContextWitnessBundle captures exactly one sourced primary assertion in an
isolated Mind, without linking or querying. Its native normal form must be a
conjunction of at most eight single signed ordinary predicate atoms, each of
arity1..8, with at most four directly used existential binders. Universal or
function argument slots, disjunctions, conditionals, generated rules, dominating
witnesses and parent projections are excluded. A bundle must contain a witness;
ordinary-only clauses continue to use their existing carrier. Nonordinary nested
values cannot hide a witness in a fixed slot.

A binder receives an ordinal at first use across the entire conjunction.
Every repeated occurrence in every atom retains that ordinal. Different binders
receive different ordinals; this preserves distinct binding scopes without
asserting that their eventual values must be unequal. Signed predicate atoms
and fixed SemanticTermSnapshot values are detached and immutable. The exact
caller-supplied Source occurrence remains attached to the whole bundle. The
private constructor permits creation only through native extraction; supplied
source labels are still not authentication against real Context effective pins.

## Restoration and its check

restore creates a fresh disposable Mind and emits one existentially quantified
conjunction per complete bundle. Fixed values use semantic projection and queue
placeholders, never parsing their rendered values. Native C-variable IDs are
not copied. The resulting native rule is extracted again and compared with the
original: signs, predicates, fixed values and a global first-use binder bijection
must all agree. The comparison preserves sharing across atoms rather than
renaming independently in each atom. Source collisions with different bundle
shapes are refused before restoration. Resource exhaustion or roundtrip mismatch
throws; the partly populated private Mind is not returned.

Within this language the roundtrip is an alpha-renaming of the full existential
conjunction and preserves its models over ordinary fixed values. Combining
bundles in a test Mind checks one selected cut; it is not permission to merge
independent sibling Context knowledge into X. Native duplicate suppression may
reuse an equivalent assertion, which is logically idempotent. That does not
prove source-alternative attribution for derived products.

This is not an admitted existential saturation certificate. Restoration does
not attach source proof labels to derived native outputs, reconstruct support
groups or establish a stable identity across rounds. It does not qualify the
base assertions by itself: callers still need native qualification. No bundle
is inserted into the existing scalar production pool or runtime write paths.
Mixed quantifier prefixes, generated witnesses and conditional witness results
remain outside this carrier and outside AUDITED_HORN.

## Regression controls

The 45-check runner compares native qualification of original versus restored
assertions against universal exclusions, ground negative facts and unrelated
knowledge. Cases include a shared p/q witness, separate p and q assertions,
independent binders in one conjunction, signed atoms, repeated versus independent
binary positions, fixed numeric/named argument order, and duplicate assertions.
It also checks the sharing topology directly, refusal of mixed prefixes,
disjunction/conditional/function/ordinary-only inputs, conflicting source
occurrences and work exhaustion. Stage2p's independent expected-answer boundary
runner remains active, so roundtrip comparison cannot silently redefine those
native acceptance/rejection expectations.

Next: bind whole-source proof evidence to restored primary bundles and inspect
native child projections before any derived witness transport. Require concrete
shared-scope, source-alternative and carried-depth controls. Mixed-prefix
transport, effective view/pin validation, atomic runtime gates and question3
(query/hypothesis/orphans) remain pending.
