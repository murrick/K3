## Principal typed resolution

`ContextUniversalInputResiduals` now exposes package-private checked frame and
term-resolution helpers. Existing one-step scan uses the same frame preflight;
its result and scope remain unchanged. The frame requires actual matching
common/local input objects and mode, complete checked ordinary schema ledger,
exact parent/private cuts, positive input and carried depth bounds. This is
historical proof authority, not a replacement for live connection/provider leases.

For each resolution the two parent residuals' universal variables are first
standardized apart. A flat principal unifier dereferences variable substitutions
and binds variables to variables, ordinary values or rigid Origins. Different
origins do not unify without an equality proof; this does not assert inequality.
Origins and ordinary constants are never renamed as universals. All substitutions
are applied consistently to the remaining Horn clause; exact duplicate literals
are removed and remaining universal IDs normalized within that residual.

This prevents the same local variable number in a forall gate(w,1) unit and a
seed(w,1)&&gate(7,1)->mid(w,1) Horn clause from binding the unrelated seed/head w
to7. Repeated unit variables also impose real diagonal constraints: a newly
proved forall u pair(u,u) cannot establish pair(c,d) for independently carried c,d.
Universality remains over all admissible values, including unmentioned values;
there is no finite-value sampling or global frozen-root aliasing.

## Immutable rounds and proof DAGs

New `ContextUniversalFrozenClosure` accepts an entire sealed schema ledger plus
actual common Packet or owning PrivatePool, not selected step subsets. Initial
roots include every checked schema proof and each authenticated input proof.
Each round enumerates all positive unit proofs against all compound Horn proofs
and all compatible negative body pivots from one immutable prior ledger. Products
merge only into the next ledger. Success requires an exhaustive unchanged barrier.

Alpha-equivalent typed clauses share a ledger row, preserving minimum depth for
every exact whole Source set. Different Source groups remain separate, including
supersets; no Source-subset minimization is introduced. A known cheaper proof of
the same clause/Source set discharges a longer path. Over-depth candidates are
not retained, but their unresolved obligations are checked only after the bounded
ledger stabilizes: imported roots may already have different nonzero depths, so
a shorter path can require a later round.
The ledger does not enumerate all arbitrarily longer derivation trees.

Every root or derived Proof has a private constructor. Schema roots retain their
exact old schema Proof; input roots retain the actual Item and donor Support.
Derived nodes retain both typed proof parents and the original parent pivot,
with Source union and max(parent depths)+1. A kernel recursively recomputes the
resolvent and label and verifies every original root against the exact frame.
`check` re-verifies a sealed successful DAG at a later proof boundary.

Bounds: rounds/depth<=64, clauses<=512, Source alternatives per alpha-clause<=256,
and shared work. Typed clauses have one positive head, up to8 literals/arguments,
up to2 universal variables and up to8 rigid origins. These are proof-data bounds,
not wider native/public DMZ acceptance. Limits, unsupported/incomplete frames and
wrong cuts yield no successful theorem prefix. Cyclic rules may add a distinct
Source alternative for an already known head, but the same exact group keeps its
minimum depth. No general whole-engine termination or consistency claim follows.

The result retains common/local input IDs, owning cuts, exact frame and immutable
proofs. It creates no output Packet, native Rule, family STEP, refutation or write
permit. It certifies only the bounded positive unit/Horn projection; general
compound/compound resolution, other native language and all-cut compatibility
remain outside this component.
