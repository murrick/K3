# Stage2x: preserve closed primary existential witnesses in native inference

## Proven failures and the resulting behavior

Stages2v/2w proved false acceptance of a primary existential fact together with a
universal denial, and of unary/fork consequences followed by such a denial.
The generated materializer replaced a bound child by an unrelated root; alpha
lookup could also collapse different primary origins. The native Analyzer then
compared the wrong identities.

GeneratedCVarMaterializer now recognizes an ultimate durable root owned by a
live, non-query, non-generated primary conjunction. Every branch must contain
one complete ordinary literal, with TERM arguments only; its C-variables must be
local, non-dominating roots. The candidate root must actually occur in that
source. Universal/function/dependent existential clauses are outside this rule.
Parent traversal is cycle/depth guarded. No new persisted field or global root
union is introduced: this root already is the primary witness's durable identity.

For those roots, ACCEPT materialization uses the original durable primary root,
not the transient child or a new witness. A stored conclusion may thus refer to
a primary-owned root. Alpha lookup requires identical primary origins whenever
either side has one. Different primary witnesses consequently have separate
stored representatives, even for identical predicate shapes. Ordinary old
rebinding/alpha behavior remains for roots outside this eligibility boundary.

The positive fork now retains the same root in p, q, r and out; the universal
denial is rejected. Independent exists(q) and exists(r) retain different roots
and do not prove an out requiring a common value. Both polarity and whole-proof
source alternatives remain explicit in the independent evidence verifier.

## Additional witness-only production boundary

Removing the fixed numeric argument exposed another concrete counterexample:
exists(p(x)), p->q, p->r, q&&r->out, forall(not out) was still accepted. Linker's
historical skip for conclusions with only abstract arguments suppressed q/r.

In ACCEPT only, that skip now permits a conclusion whose arguments are all
eligible closed primary witnesses. It introduces no new witness root; the finite
input primary root family is retained. No termination claim is made for arbitrary
rules or function-generated values. CHECK/HYPOTHESIS keep the previous skip
policy. General universally dependent/generated witnesses are not admitted by
this exception.

## Verification changes

The old identity-loss diagnostic is replaced by
ContextWitnessPrimaryIdentityRunner: equal comparison before/after materialization,
durable ownership by the primary source, CHECK isolation, native fork identity,
repeated qualification/closure stability, failed-write rollback, separate primary
origins despite alpha shape equality, independent-witness joins and repeated
argument positions.

ContextWitnessForkContractRunner is now a green 21-check native contract,
including direct contradictions in both orders, unary/fork contradictions with
and without ordinary fixed arguments, and consistent independent-origin controls.
It runs with diagnostic capture disabled. It is registered in the green DMZ
manifest together with the primary identity and DUMB2 persistence controls.

The DUMB2 runner closes/reopens the database twice, verifies stable primary/result
witness IDs, rejects the denial after reopening, and checks unchanged revision
and rule count after failed write. Existing C-variable safety controls still
exclude transient children from generated storage, preserve closure convergence,
and retain query projection isolation.

Historical evidence assertions that required rebinding or alpha collapse of
these particular primary roots now require identity preservation and distinct
independent roots. They still check whole sources, minimum depths, signs, fixed
arguments, scope refusals and budget stops. The fork join runner now requires the
actual native out application and its complete four-source proof; it does not
synthesize a missing application. Materialization correspondence verification
itself is unchanged.

## Remaining scope

This repairs the demonstrated closed-primary witness cases. It is not a general
solver for generated dependent existential witnesses or arbitrary quantified
clauses. It does not add cross-round witness IDs, transport of derived witness
bundles, effective-pin authentication or runtime synchronous-round integration.
The separate authoring contract is still pending; question3 remains open.
