# Stage3ac: receipt-bound proof of ground binary composition

Stage3ab observes native ground branch pairs but supplies no composed proof.
New Core ContextGroundCompositionProof checks one such pair against an immutable
ordinary residual receipt and constructs a narrowly scoped binary-resolution
proof. This is an explicit proof rule, not a claim that the native engine already
materialized its conclusion. No hypothesis or privately assumed unit is used.

## Soundness and exact authority

For two whole ground clauses C∨p and D∨¬p, the conclusion C∨D follows:
if p is false the first parent forces C, and if p is true the second forces D.
The checker removes exactly the matching pivot from one parent and its semantic
opposite from the other, retaining every other literal. Equal retained ground
literals factor by idempotence; tautological conclusions remain valid. It
introduces no variables, substitutions, witness identities or domain enumeration.

Every observed parent alternative must match an ACTUAL complete clause and
exact Support (whole source set AND depth) in receipt.localProofs. Checking only
the pivot or a subset of a source is insufficient. Missing, unverified or
collision-bearing receipts cannot prove a candidate. A privately replayed pair
with caller-invented labels cannot bypass receipt authentication. Same syntax
from another original occurrence fails. The private-constructed Evidence binds
the exact sealed Frontier and target Snapshot. Evidence and Proof lists are
immutable. This is historical proof in that scope, not a freshness/write lease.

For each pair of authenticated parent alternatives the proof contains their
whole source union and depth max(parent depths)+1. Alternatives form separate
recipes; sources from different possible derivations are not indiscriminately
merged. Duplicate identical recipes collapse. Integer overflow, depth/work
limits or more than256 distinct recipes fail with an empty proof list, including
when a prior alternative had already succeeded. No successful prefix is exposed.

The original X ~a||~b||~c and A d→a, all at1, now yields precisely
~d||~b||~c with the two original sources and depth1. A previously reduced
compound parent retains its causes and contributes its cumulative depth.
Whole conjunctive primary source identity is also retained.

## Boundaries and next step

This helper checks ONE observed ground pair. It does not enumerate all pairs,
handle universal unification, discharge missing composition coverage or publish
the consequence. The candidate remains native-visit metadata; Proof is the
separate checked inference result. Proof checking does not mutate the supplied
receipt or Frontier. No result feeds another composition during the call.
A local foreign-only composition can be proved within its own cut; that does
not make it X knowledge. Future transport must enforce X-dependent export.
Candidate/provider/default write gates, old unit certificate and stage3aa
reduction-only certificate remain unchanged. Original default contract remains
last stage3r RED56/2; question3/hypotheses/orphans remains open.

Next: sealed composition transport across the immutable family barrier and an
independent ground composition coverage audit. Universal substitution and broader
admission authority remain separate unfinished obligations. The known X/A/B/C
family counterexample is not yet claimed fixed by this detached proof helper.
