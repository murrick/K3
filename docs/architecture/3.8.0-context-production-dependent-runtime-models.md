The pending lease can now prepare a typed runtime overlay with a separate truth check performed directly on its indexed product DAGs. `ContextDependentRuntimeModelInspection` builds the actual native candidate and projection afresh, rebinds the supplied proposed interpretations using only the internally fresh original-to-actual function maps, and evaluates every runtime product occurrence. A caller cannot supply a prior frame, diagnostic, rebinding receipt or truth result.

## Independent runtime consumer

`ContextDependentRuntimeModelAudit` reads VARIABLE/VALUE/APPLICATION nodes and ordered integer edges. It does not call the carrier `TermView` truth evaluator, MGU/Arena, discovery or projection builder. The native shape preflight independently checks actual primary row identities and derives physical predicate/function declarations and dependency ranks. It uses the existing native prefix decoder, so this is not an independent quantifier parser. Original formula truth and proof provenance still come from the preceding fresh candidate/four-model-audit/projection pipeline.

The shape check requires the exact child context/revision/fingerprint, every independent/TRUST receiving cut, one interpretation for each actual cut, all typed constants in the named basis, a distinct concrete OTHER representative, total default/exception relation and function tables with valid tuple/output classes, and exact Source/binder/rank keys. Common imports may carry function declarations from another physical member: global physical declarations are checked, while each receiving model covers its own originals plus its actual imported runtime vocabulary. Independent sibling originals are not joined into one premise set.

Every common and visible raw occurrence retains its role and ordinal, whole supporting Sources and producer. All runtime nodes must be reachable and topologically ordered, with no function choice embedded as an actual value. Each function declaration must occur in the product's physical ancestry. Preflight runs before any uniform-relation shortcut, including on every late product and node. No Source support alternative is minimized or merged.

The evaluator enumerates a Cartesian product of named classes plus OTHER for every free variable identity. Repeated variable ids use the same assignment. It computes graph nodes in topological order, reading the exact total function table on the ordered values of preceding dependency nodes, and then checks the product's signed predicate tuple. Nested g(f(x)) and arbitrary supported coordinate counts use the same algorithm. OTHER denotes all admissible unmentioned values under the supplied uniform quotient interpretation, not a selected new fact. An empty-exception relation can be checked uniformly only after full structural/model preflight.

Runtime shape/rebinding and runtime truth have separate work allowances, in addition to the preceding candidate/model/projection limits. Any exhaustion or failed interpretation returns INCOMPLETE with no frame, projection or successful occurrence prefix. It is not a semantic refutation. Actual sourced BASE_REFUTED/CANDIDATE_REFUTED outcomes preserve their proof and have zero runtime-truth counts. The successful occurrence count must equal the fresh qualified frozen-final count. Interruption preserves its flag and throws; stale actual views also throw.

## Owning session

`prepareDependentRuntimeModels` retains a successful result and its exact current frame only after the owning provider's post-check. `dependentRuntimeModels(UUID)` rechecks ownership/currentness and requires the same frame and epoch. Replacement by the structural-only stage520 preparation clears the runtime truth result, so a structural frame cannot masquerade as a model-audited frame. Failed fresh qualification clears both the frame and its audit; a wrong-thread call cannot clear the owner's state. Closing clears both. Detached results remain historical observations.

RUNTIME_MODELLED_PENDING proves this supplied interpretation on the indexed runtime product representation. Ordinary native inference/query dispatch, RuleFactory final-product state, writer/settlement activation, automatic model construction and durable recovery remain separate work. Neither model choices nor runtime truth results are written as facts. Known native RED gates and Question3 remain open. This implementation adds no public Console command and requires no operator-manual update.
