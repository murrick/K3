# Stage500: native unbound-variable collision diagnosis

## Counterexample reduced beyond existential scope

Native authoring on stage499 accepts both:

```text
!@x p(x);
!@y ~p(y);
```

The domain is nonempty (numeric 1 alone suffices). Instantiation at the same value
proves contradiction. Reversal is also incorrectly accepted. No existential,
function, query, hypothesis, cross-context transfer or recursive depth is involved.
Thus changing witness identity or the domini flag alone cannot repair stage499.
This is not proof that alternating witness dependency metadata has been lost:
there is an earlier missing symbolic comparison. Stage499's exact native routine
was still unknown; this stage narrows that diagnosis without rewriting history.

The universal-only binary rule plus shared-variable two-atom prohibition also
fails in both orders:

```text
!@a @b pair(a,b);
!@a ~(pair(a,1)&&pair(a,2));
```

Both ground/universal unary controls are correctly rejected. Independent
predicates and incompatible fixed argument positions remain correctly consistent.

## Actual control-flow boundary

On the unchanged production source:

1. Linker.linkDomains, lines828-829 and859-860, creates a substitution only if
   the opposite argument has a value. For two empty TVariables neither direction
   creates a value or symbolic equality. Native trace for the unary pair reports
   zero solved passes, no variable closure, and no collision.
2. rotateVariables recurses even when a variable has no TValue. This is an
   intentional control-flow fallback, but does not make that variable a term.
   linkDatabase lines1155 onward clears the branch candidates on an incomplete
   Domain, so the fallback cannot materialize a complete stored consequence.
3. Analyzer.checkDatabase lines328-329 compares only stored Rules. The surviving
   original universal rows are non-stored. No stored opposite pair reaches
   checkRight, and native authoring accepts the insertion.

For stage499 the trace does bind u in the negative row and b=1/b=2 in the positive
row, but never binds the shared universal a. Consequently the same completeness
boundary remains. Giving a=1 explicitly in the prohibition enables rejection.
The safe conclusion is a missing unbound-variable comparison path; whether other
mixed cases also lose a dependency remains a separate obligation.

The gate now prints detached post-operation observations for failing cases:
actual Rule id, stored/generated status, Domain completeness and number of empty
TVariable occurrences. Those observations are after compile returns, not a claim
that committed current substitutions are a trace of every intermediate state.
Runtime logs and the displayed source branches establish the earlier path.

## Fix obligations established by the counterexamples

The next implementation must compare universal variables symbolically, preserving
repeated-variable equations and standardizing independent Rule scopes apart.
An arbitrary database value must not become a persisted fact or restrict @x to
currently known values. Ordinary clause resolution already has a qualified proof
path; any native authoring integration must retain that proof and existing
collision evidence rather than merely changing Analyzer's stored filter.

For mixed rows, witnesses need their actual preceding-universal dependencies.
One global witness for forall-exists would make the consistent control falsely
inconsistent; independently freshening the two uses of exists-forall would miss
the real collision. The prefix, whole original Source, ownership and exact use
correlation must survive original and independent final auditing. No quick
replacement of an empty variable with a named value or a shared global CVar is
accepted as a correction. Stage500 implements no fix and adds no mixed admission.
The next structural batch is a proof-preserving comparison implementation and
its acceptance gates; the counterexamples remain OPEN until those gates pass.
