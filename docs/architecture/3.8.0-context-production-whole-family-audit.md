# Stage3bg — independent exact whole-family verdict audit

ContextUniversalFamilyAudit accepts a sealed inspection result, the expected exact
X snapshot and complete expected initialized foreign snapshot list. It does not
require an append-only candidate, statement text, parent reconstruction or a
candidate Source. This makes the audit applicable to complete proposed native
states, including multiple edits in one child. It is detached historical evidence,
not an owning pending-child lease or permission to commit.

## Applicability and independent replay

Preflight authenticates whole native inventories/roles, unique contexts, distinct
Source identities and exact snapshot OBJECT identities. A same-context/revision/
fingerprint rebind is insufficient. Expected foreign ordering is irrelevant;
missing, repeated or substituted snapshots refuse. The result must be complete
with at least one common barrier and belong to exactly that X/family.

For CONSISTENT, the auditor independently recertifies complete factored stable
family coverage and every exact private all-admissible-value model, using the
existing raw-ledger model checker. One instance allowance spans all rechecks.
Mixed or incomplete evidence cannot become a checked consistency verdict.

For COLLISION, it checks sourced products against the complete exact family and
depth bound, requires compound/factoring receipts, replays the complete common
merge, matches all opposition alternatives one-to-one, rechecks each actual unit
opposition with the resolution kernel, and verifies exact parent Source union and
max-parent-depth+1. It returns the immutable whole proofs without inventing a
single-candidate cause or dropping alternatives. Failures expose no proof prefix.

As before, the replay trusts private sealed factories for intermediate receipt
construction; it does not independently reconstruct every earlier private inference
or implement a second unifier. The final kernel/Source/depth/barrier/model replay
and exact applicability checks are retained from the candidate auditor, not weakened
or replaced by a status flag. One work budget spans the complete audit.

## Candidate specialization

ContextUniversalCandidateAudit still independently validates requested assertion,
base/staged identities, complete append-only staging and one-to-one semantic Source

counter, not a fresh allowance. Only after successful complete replay does it
translate original X Sources and compute usesCandidate from exact candidate Source
membership for each whole proof. Candidate-independent/mixed proof semantics,
no-attribution-prefix failure and immutable output remain unchanged.
