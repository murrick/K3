# Stage3am: independent detached unit-pair obligation coverage

ContextUniversalUnitCoverage audits a bounded one-step set of unit-resolution
Evidence. It is not a transport ledger, family collision verdict, fixed point or
write certificate. The old universal-unit start/transport gates remain unchanged.

## Concrete multi-pivot omission control

Given @x p(x) and @y ~p(y)||~p(1)||q(y), two different selected pivots produce

    @y ~p(1)||q(y)
    @y ~p(y)||q(y)

Both are whole-clause consequences with the same two original Sources at depth1.
Selecting only the first matching literal misses the other one-step consequence.
The driver supplies either result alone and verifies refusal, then supplies both
and verifies coverage. This demonstrates the obligation of an exhaustive
one-step audit, not a newly proved inconsistency of an existing writer or a claim
that both resolvents are indispensable in every complete search strategy.

Unit/unit opposition is a separate required result: it has contradiction=true
and no ordinary conclusion Clause. Missing that evidence must refuse coverage
rather than disappear from a loop which only searches for output clauses.

## Authority and independent obligations

Primary-only auditPrimary uses actual native-bound X and one foreign Snapshot
(or X alone). The frontier-based audit uses an actual Frontier and one of its
cuts, plus the exact-input/cut-bound successful compound Evidence made available
to the stage3al unit kernel. It inventories all actual primary clauses, carried
Products and those compound conclusions, then deduplicates semantic clauses.
Every original proof alternative is recovered by kernel authentication, not by
allowing the caller to provide Source or Support objects.

The auditor enumerates every unordered whole-clause pair and every pivot-position
pair when at least one parent is a unit. Self pairs are included. A separately
implemented argument-position equality graph, shared with the stage3aj coverage
auditor, decides feasibility: corresponding arguments and repeated variables
inside each parent form connected components. Variable identities of the two
parents are independent. Unequal ground constants in one component exclude the
pivot. This does not use the kernel's substitution algorithm or any enumeration
of known values. Flat-pivot arity above256 returns unknown/uncovered as before.

The stage3al proof kernel constructs each required result and all exact
whole-source/depth recipes. Supplied immutable unit Evidence must have the same
X Snapshot, input mode/Frontier and target Snapshot. Each required recipe must
match a supplied proof by exact Support and either alpha-equivalent conclusion
or typed contradiction. Equivalent recipes may discharge equivalent obligations;
pivot identity itself is not a new Source. Conclusion construction still reuses
the checked kernel, so this is independent enumeration/feasibility checking,
not a second proof of the kernel's MGU implementation.

## Bounds and explicit scope

One shared work budget spans inventory, evidence validation, independent pivot
feasibility, kernel calls and result matching. The kernel gained a package-private
budget-accepting overload; its public APIs still create one bounded allowance.
Carried/compound parent depths are checked before enumeration, and derived depth
remains max(parents)+1. Missing proof, wrong cut/snapshot/mode, stale input, failed
compound evidence and any bound yield covered=false, never a partial success.
The Audit contains only status/reason and cannot be used to manufacture Products.

Coverage is relative to the exact actual primary/shared inventory and supplied
sealed compound evidence. It does not prove that the separate compound inference
phase produced all possible compound results. The audit does not recursively
consume newly generated unit results, process arbitrary native local residuals,
close a private cut or certify the family. @x still ranges over every admissible
value including unmentioned values.

The expanded unit driver covers missing generic consequences and oppositions,
apart-renamed opposed schemas, impossible repeated-variable/constant pivots,
wrong-cut and primary/frontier-mode evidence, derived universal donors, bounds,
and the two-pivot omission control. Independent finite interpretation searches
also check both actual resolvents with fresh unmentioned values. Such searches
are counterexample controls, not finite-domain semantics.

Final counts are recorded in the main checkpoint/journal. Next: sealed unit
support ledger and typed opposition transport, then universal private closure
and family coverage. Existing ground writers/default authoring and question3
remain unchanged.
