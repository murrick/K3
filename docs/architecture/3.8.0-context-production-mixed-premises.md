# Stage3k: carried ground donors in witness-preserving steps

Concrete prior refusal: bound X contains `!$w p(w,1);`,
`!@w p(w,1)->warm(w,1);`, `!scalar(1);`; A contains
`!@w p(w,1)&&scalar(1)->q(w,1);`. Stage3j assembly control returns
INCOMPLETE. Native projection already records both premises, but seed replay
skips scalar items and the witness pattern constructor rejects ground literals.
This is a proof coverage gap; it is not evidence that inconsistent knowledge was
accepted. The old compiled assembly runner reproduced its 67 checks before the
extension.

Seed replay now imports ground packet items with their original proof groups
and depths. An explicit closure mode allows ground premise patterns. Ground
donors do not supply or replace a witness origin. Every witness donor must still
have the same origin; the actual conclusion must contain exactly one witness,
and native producer-instance authentication and materialization correspondence
remain mandatory. Sources are the union of all donors and the exact producer;
depth is one plus their maximum. Ground routes are retained in the input ledger
and not exported as new witness products.

The unary and shared-origin Session entrypoints retain strict witness-premise
patterns. This extension applies only to owning seed replay. It does not add
ordinary scalar inference, foreign primary facts as X knowledge, new witnesses,
or empty-cut coverage. Full positive Horn coverage is still checked separately
against the complete source declarations before reporting a scoped fixed point.

Controls cover the concrete successful mixed body, its exact three-source proof
at depth1, depth0 refusal, and a scalar(2)/scalar(1) mismatch that must not produce
q. Existing independent-origin, provenance, lifecycle and bounded-failure
controls remain part of the reference suite. Runtime authoring integration and
question3 remain open.
