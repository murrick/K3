# Stage3aq: exact combined-family coverage and proven factoring boundary

ContextUniversalFamilyCoverage is an independent diagnostic audit over actual
complete combined receipts. It has CLOSED_CUTS and STABLE_SHARED modes. Neither
mode is a satisfiability/model certificate or authoring permission.

## Sealed private closure evidence

Successful collision-free receipts now retain the exact stable combined Step.
The auditor checks status, unchanged recipes, whole original declarations and
common carriers, exact native family Source membership and depth, and equality
of the input/successor recipe inventories. It independently reruns both unit and
compound obligation audits against the stable Step input. Every proved nonempty
consequence must actually be retained, with the same whole Source group and no

Every positive-depth X-dependent private row must be exported, and each exported
row must be an actual qualified private recipe. All cuts including self must
have verified includesCompounds receipts for the exact common Frontier. Missing,
duplicate, stale, failed, unit-only or wrong-cut evidence refuses coverage.
One work allowance spans the audit and the existing complete family merge through
a new internal budget-accepting merge overload. A merged collision/incomplete
barrier cannot pass. CLOSED_CUTS permits a changing common pool and certifies
only the explicit one-round binary obligations; new carriers still need another
round. STABLE_SHARED additionally requires an unchanged common merge and rejects
the unresolved same-sign factoring boundary below. All success reasons explicitly
retain satisfiability/write-admission unknown.

## Concrete principal incompleteness of binary-only stability

Actual native-bound X and A preserve these two-literal, two-variable clauses:

    X: @x @y p(x) || p(y)
    A: @x @y ~p(x) || ~p(y)

The combined binary engine reaches unchanged recipes without a unit or opposition.
CLOSED_CUTS confirms that the two-parent unit/compound obligations are genuinely
covered; this is not an exhausted-budget artifact. Binary resolution keeps the
positive clause, negative clause and mixed p(u)||~p(v) form, with independent
remaining variables. Source alternatives also stabilize within bounds.

Nevertheless the theory is inconsistent over every nonempty admissible universe:
choose any admissible value v and instantiate BOTH variables with v. The first
clause gives p(v)||p(v), hence p(v); the second gives ~p(v)||~p(v), hence ~p(v).
This diagonal argument is the all-domain proof. An independent exhaustive model
control over two fresh unmentioned values also has zero models; that test does
not impose a finite-domain semantics.

This proves that an unchanged binary pool cannot serve as general universal
consistency admission. Existing ground/default writers were never redirected
to that claim. No separate factoring inference is introduced by this stage.
Instead STABLE_SHARED refuses this actual unresolved boundary as INCOMPLETE/
uncovered before any universal writer can interpret it as success.

## Same-parent factoring feasibility guard

The equality-graph helper now has a separate same-sign SAME-parent variable-scope
mode, while opposite-parent resolution keeps standardize-apart scopes. This
separation is necessary: p(x,1)||p(2,x) cannot factor because the SAME x would need
to equal2 and1. Conversely p(x,1)||p(2,y) can factor with x=2, y=1. The driver
checks both and verifies that the former is not falsely rejected as a factoring
boundary. Repeated variables, semantic constants, arity/work bounds remain checked.

The guard is conservative: any unprocessed same-sign unifiable pair stays outside
STABLE_SHARED, even if some other inference path already produced its consequence.
It is a scope refusal, not an invented collision or a factoring proof.
