# Stage3n: native-bound empty target scopes

## Reproduced refusals

The stage3m assembly rejects:

- X `!$w p(w,1);`, A `!@w p(w,1)->q(w,1);` because self-X has no producer.
- X `!$w p(w,1); !@w p(w,1)->warm(w,1);`, empty A because no primary
  Source exists from which to derive A's cut identity.

Evidence against the old compiled implementation:
`/tmp/k3-stage3n-probe.log`. Neither absence requires a synthetic productive rule.

## Explicit authority

ContextWitnessEmptyTarget has a private constructor and is derived from a whole
native-bound Snapshot. It checks exact primary inventory membership and
context/revision/role/view identities. A foreign target must have no primary
rows. Self-X may contain only already-accounted literal seed rows (whole witness
bundles or ordinary ground units); a producer clause prevents the certificate.
Foreign facts, universal units and producer rules cannot be called empty.

Cut identity may now come directly from the native inventory metadata, without
a fabricated Source/rule ID. Branch keeps its real declarations plus explicit
empty-target evidence. The default declaration APIs still reject a bare empty
list. The evidence-bearing path accepts zero own target declarations, checks
any remaining common X declarations normally, and rejects declarations that
contradict the target's absence. The plan still requires identical shared X
producer declarations in every branch.

Unchanged and productive round certificates carry the target authority with
exact input basis. A source-free empty branch can satisfy family membership
through this authority; all real producer Sources still undergo their existing
parent/foreign-cut checks. The evidence is not attached to logical literal proofs
and does not add sources or reset depths. Merge discards branch-local authority.
Direct collision scans include every supplied empty branch and all of its shared
X declarations. Final closure and synchronous barriers are unchanged.

## Verification and limits

Controls include seed-only X with/without foreign inference, both targets empty,
ordinary seed-only X, empty foreign with productive shared X, no fabricated rows,
source-free unchanged certificates, unchanged proof contents, all expected cuts,
stale input identities, wrong revision/view/role, nonempty target refusal,
contradicting declarations and work bounds. Missing X warm proof still prevents
an unchanged verdict even when the foreign target itself is empty.

Real DUMB2 creates a pinned empty foreign context and seed-only X. Qualification
succeeds without changing X revision or rule count. Private foreign
initialization then revokes the old provider lease; a fresh effective inventory
contains the added fact and returns INCOMPLETE under the existing foreign-fact
coverage boundary. An immutable historical absence certificate does not assert
that the current live view is still empty.

Entirely seed-free X, general foreign primary fact coverage, signed/TRUST/new
witness cases and question3 remain outside this stage. Main/Core/DB provider
implementation is unchanged. Ordinary authoring integration remains pending,
with last runtime contract RED56/2. Next: immutable candidate assembly and
qualification before ordinary authoring publication.
