# Stage2m: universal residual instance evidence

ContextUniversalInstanceEvidence is a detached, read-only universal-elimination
bridge for already proved clauses. It enumerates assignments over a supplied
finite representative basis using Clause.instantiate. A repeated variable uses
one assignment everywhere; different variables vary independently. Constants,
argument order and signed literals retain their semantic snapshots.

Each instance carries exactly the original whole source group and minimum
depth: universal elimination adds no rule-application step. If different proved
clauses instantiate to an equivalent ground clause, their source alternatives
are retained separately. Only identical whole groups may share a minimum depth.
The supplied pool is not mutated. The bridge does not resolve clauses, invent
missing native residuals, add predicate assertions or install bindings in Mind.
Its output is certificate evidence only; it must never be exported as newly
observed native events or used to upgrade primary shape metadata into proofs.

Boundaries: at most three literals and two clause-local variables per evidence
clause; quantified evidence needs a nonempty basis; unsupported/empty-proof or
duplicate input buckets throw. Work exhaustion propagates and cannot expose a
partly expanded result. The caller remains responsible for authenticating
universal proof entries and basis adequacy. The bridge alone proves neither
saturation nor native coverage.

The native fixture uses X: forall x,y left(x) && right(y) -> out(x,y),
A: left(1). The reference exports a proved universal residual
forall y right(y) -> out(1,y), supported by the whole X/A group at depth1,
without asserting out. The exact-ground stage2l checker cannot use that raw
symbolic residual. Structural instance evidence discharges its obligations for
1 and John with unchanged depth. Removing the native residual still fails.
This is a certificate representation gap, not a new Core inference bug.

Independent controls cover Cartesian assignments and permutations, diagonals,
overlapping universal/ground proofs, separate source alternatives, minimum depth,
unsupported ranks/clause sizes, missing representatives, duplicates, resource
stops, unproved shapes and opposing universal/ground units.

No runtime gate or reference certificate scope changes in this stage. Next:
combine this evidence bridge with source conformance and native rotation audit
in a separate bounded multi-premise Horn certificate, then verify all participant
orders and multi-source joins before admitting that profile. Query/hypothesis/
orphans (question3) remains open.
