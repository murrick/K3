The stage3k implementation returns INCOMPLETE at round1 with

## Extension

Owning seed replay now reconstructs actual captured ordinary Applications in
the same bounded proof pool as witness routes. Each application must have one
or two ordinary donors and one native reduction step. Its exact nativeRule must
belong to a captured whole primary declaration; singleton depth0 producer labels
must exactly match that owner. The observed signed conclusion plus opposite
premises must be an instance of a whole captured clause, with one consistent
universal-variable assignment across every literal. Matching predicate names
or rendered text alone is insufficient.

Ground routes have no witness origin. Their donor supports are combined by full
source-set union and max-depth+1, including alternatives and carried depths.
Only observed applications generate proof routes; the Horn coverage checker
continues to detect absent conclusions and absent support alternatives rather
than filling them in. Original X seed declarations retain their actual sources;
foreign unit facts do not become X seeds.

A purely ordinary snapshot does not require witness materializations. Any actual
witness observations still require the original correspondence verifier. Strict
unary/shared-origin Session entrypoints remain unchanged. Export transports both
ordinary semantic values and canonical witness origins without text conversion.
No-event passes still require a separate unchanged/empty certificate.

## Controls and remaining boundary

The ordinary family reaches a scoped fixed point with ready(1) at depth2 and
exact original X fact, X rule and A rule sources. Depth1 and round1 bounds refuse
without an accepted packet. Two-donor ordinary bodies and two alternative proofs
of the same conclusion retain their full source groups. An ordinary production
can feed a witness rule in another cut at the next immutable family barrier.
Direct negative authentication controls cover missing ownership, wrong source
revision, absent whole clause, wrong fixed value, wrong premise polarity and work
exhaustion.

A separate concrete same-cut boundary remains:

X: `!$w p(w,1); !scalar(1); !@w p(w,1)->warm(w,1);`

A: `!@x scalar(x)->gate(x); !@w p(w,1)&&gate(1)->bridged(w,1);`

The qualification returns INCOMPLETE / `Missing Horn conclusion instance`.
The observed native products do not supply a full proof pool for this same-cut
cascade. This stage deliberately does not invent bridged or mark the cut covered.
Splitting the two rules into distinct foreign cuts completes across synchronous
barriers with depth2 and all four exact sources. A focused follow-up should
inspect the missing native event/within-cut settlement before claiming broader
mixed closure; then explicit empty cuts and ordinary authoring integration.
Question3 and general signed/TRUST/new-witness coverage remain open. Runtime
ordinary authoring gate remains last RED56/2; this is qualification-only work.
