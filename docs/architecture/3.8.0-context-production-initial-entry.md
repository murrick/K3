# Detached opt-in native initial entry — stage449 (2026-10-29)

`ContextUniversalInitialEntry.assemble(x, foreign, limits, capacity)` is a package-private,
explicit assembler for the existing bounded signed kernel. It does not activate Console,
provider, admission, live writer, STEP, covered-cut, or full-family paths. This is planned
integration of qualified mechanisms, not a repair of a newly proved architectural fault.

## Atomic result

- READY exposes exactly one Entry: original X/supplied snapshots, primary common packet,
  actual witness pools, complete owning check map, and BOTH unit and compound carriers.
  Empty unit/compound contents are allowed; neither carrier can be absent.
- REFUTED exposes no Entry. It contains per-cut flags and existing authenticated, flattened
  empty-clause evidence only after ALL supplied initial cuts have closed and authenticated.
- INCOMPLETE exposes neither Entry nor refutation prefix. Unsupported rows, unavailable
  seeds/materialization, duplicate/overlapping physical contexts, limits, and failed
  collection/authentication remain incompleteness, never logical refutation.

The Entry and result inventories are copied/unmodifiable. They refer to the actual
immutable detached native/proof graphs used by the existing kernel; they do not grant
protection against hostile concurrent mutation/reflection. No continuation certificate
or global saturation claim is created by READY.

## Order and ownership

Identity/physical Context exclusivity precede full original row inspection (fixed existing
64-row cap). Every row/part is inspected, including original X and trusted physical members.
Primary seed capture alone cannot qualify the rest of X. The existing signed private-pool
materializer is invoked for each cut containing a witness bundle. Ordinary ground foreign
facts already enter through native closure, so they do not acquire unnecessary pools.
Classification alone cannot materialize a two-Origin literal. Two binders in separate
literals remain distinct even when their residuals have identical Source support.

All ordinary `closeSignedInstantiatedUnits` calls use one actual common frame, original
private pools, and no incoming symbolic/compound carrier. ALL closed results are
independently authenticated before checking refutation flags. Existing rejection-evidence
flattening preserves sourced contradiction without inventing a grouped-round identity.
Only a wholly consistent completed initial frame proceeds to both collectors. Both receive
one same owning map and must return its actual checks/barrier. A failed mandatory compound
collection cannot leak a valid empty unit carrier.

No separate inference, Source subset pruning, bare Origin-token transport, legacy transfer
bypass, or new certificate algorithm is introduced. Continued imported-Origin inference
still uses the existing local certificate, certified transfer and independent product audit.

## Bounded policy

`ContextUniversalFrozenBranch.Limits` retains its constructor bounds. Its rounds/proofDepth/
clauses/alternatives/work configure original initial closure; factDepth configures BOTH
carrier collectors, as in the controller. Capacity is explicitly bounded 1..4096. Events/
receipts fields are not consumed here; this assembler does not run those phases.

One cumulative Ground budget owns orchestration and authentication for the whole assembly.
Every existing inspector, seed/pool materializer, closure, collector and rejection-evidence
operation retains its OWN original work budget. There is no claimed single cumulative
budget over all child operations, and no reset of a child's owning budget. No limits raised.
