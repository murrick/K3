## Representation and audit

Each receiving cut contains every actual common ticket followed by every actual visible product occurrence. COMMON and VISIBLE remain distinct roles even when they refer to the same logical conclusion. No alpha-head compaction, Source-set minimization, duplicate elimination or replacement by model-chosen values occurs. Each product retains its exact producer Source, complete supporting Sources, depth, retained literal, polarity, predicate and ordered argument roots.

Each product has its own topological DAG of VARIABLE, VALUE and APPLICATION nodes. Application nodes carry the exact child/foreign-qualified declaration Source and binder position, with ordered dependency argument indices of arbitrary supported rank. Repeated references remain shared; distinct original nodes are not merged. Values remain immutable typed semantic snapshots. Different witness origins retain their identity without asserting inequality. Applications are never projected into scalar native Cvars.

A second traversal independently compares the indexed DAG with the actual frozen typed products. It checks the exact cut/role/occurrence manifest and metadata, every typed value/function Source/binder/arity, a bijection of variable identities, ordered edges, original sharing, topological ordering and absence of extra nodes. It does not treat a matching builder hash as evidence. Model interpretations are used only by the preceding truth audits; their chosen function results do not enter this copy operation.

Whole product and node limits are separate from copy-work and audit-work limits. An exhausted limit or failed audit returns INCOMPLETE with no frame and no earlier successful qualification prefix. Actual sourced BASE_REFUTED/CANDIDATE_REFUTED outcomes retain their proof and have no frame. Interruption and changed actual views throw. This is a representation audit, not a second native parser or an independent proof search.

## Provider ownership

`ContextPendingProductionSnapshotSession.prepareDependentRuntime` prepares under the existing provider lock, ownership, saved parent/child/retained inventory and physical topology guards. A successful post-check is required before the lease retains the frame. Each preparation has a fresh UUID; replacement makes earlier ids ineligible for live access. Owner validation precedes invalidation so a wrong-thread call cannot clear another thread's valid frame. A legitimate failed preparation clears any previous frame. The owning lookup rechecks actual currentness and requires the exact current UUID. Closing clears the retained frame. Detached immutable frame references remain historical data, not capabilities.

The representation is attached to the pending session, not installed into Mind's ordinary inference/query dispatch or RuleFactory. No original/generated native Term, row or revision is written. PROJECTED_PENDING is not READY, acceptance, settlement or durable recovery. Original native final-product qualification, query execution over this representation and writer activation still require their own next boundaries. Supplied-model success is not automatic model construction. Known native RED gates and Question3 remain open.
