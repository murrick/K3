# Stage3af: bounded ordinary ground family certificate

New Core ContextGroundClauseFamily combines private closed-cut receipts,
immutable common barriers, both independent coverage audits and separately
checked consistency models. The new GROUND_FIXED_POINT result has explicit
scope ORDINARY_GROUND_UNIT_AND_COMPOUND_RESOLUTION. It is not a general DMZ
certificate, candidate approval or publication lease.

## Family proof obligations

Preflight checks every original source and carried product in the whole family
before replay. All clauses must be native-bound ordinary ground clauses;
universal slots are refused, not instantiated over known constants. Horn and
non-Horn ground clauses are supported. The self cut and every foreign cut use
the SAME immutable Frontier. Each runs bounded private composition/reduction
closure with actual whole-source recipes and cumulative depths.

The exact-input all-cuts merge must authenticate every receipt before returning
any typed collision or new shared pool. Every changing collision-free barrier
requires BOTH INPUT_STEP audits. Only positive-depth X-dependent recipes export;
foreign-only proofs remain private. A changed pool cannot certify. At an
unchanged pool, both LOCAL_CLOSURE audits are mandatory, followed by a separate
model for each cut in canonical sealed cut order. Native candidate enumeration
alone cannot establish coverage. Scope includes unit-donor reductions and
resolutions between distinct semantic compound ground clauses; it does not
promise arbitrary logical weakening, universal composition or other languages.

## Separate, checked model witnesses

For each cut build the complete theory again from its WHOLE original source
clauses, shared carriers and actual local proofs. Semantically equal ground
atoms receive the same index, including their argument values; opposite signs
refer to opposite truth values of that index. A bounded propositional search
finds a complete assignment. The selected assignment is checked against EVERY
clause again before exposure. Model.positiveAtoms contains precisely the chosen
true atoms, and is immutable. All other ordinary ground atoms can be false in
this interpretation. Because the theory is ground, this extends to every
admissible value without a finite-known-value approximation or domain closure.
It does not assert any negative fact or change query behavior.

Each A–X and B–X has its OWN model. Raw p/~p sibling disagreement is valid and
does not force a communal assignment. Choice of a witness truth value does not
produce an X fact. Certificate constructors are private and bind the exact
sealed Frontier and target snapshots. Historical certificates cannot authorize
a live write or replace fresh snapshot/ownership validation.

The model search is deliberately bounded and does not infer a sourced collision
from search failure. Exhaustion or no discovered model returns INCOMPLETE with
no certificate, model prefix or collision prefix. Only the authenticated typed
proof route may return COLLISION. maximumModels counts complete assignments per
cut (false-first search); known units are still checked as clauses rather than
silently assuming a witness. Maximum256 indexed atoms protects recursion depth;
work limits bound search nodes and clause checks. Difficult/trivial-but-large
searches may be incomplete at a small allowance; no acceptance is inferred.

Common rounds, local rounds, cumulative depth, per-cut work/events/probes and
per-cut model assignments are explicit bounds. Separate preflight, merge/audit
and final certificate phases have their own work allowance, matching the earlier
bounded family APIs; all model witnesses in one certificate share its work
allowance. A late failing cut discards earlier successful witnesses.
