# Single-variable scalar Horn coverage

Stage2h extends the stage2g qualification reference. It does not connect a
runtime write/publication gate or certify multi-variable native rotation.
The older monadic certificate remains a distinguished subset.

## Admitted shapes

Each entire primary native Rule contains at most one distinct TVariable,
including all of its compiled branches. Every branch must have a detached
declared shape. Atoms have one or more ordinary scalar argument positions;
each position is that variable or a fixed numeric/named/string value.
Repeated variable positions and fixed positions are retained exactly. Clauses
are signed units or definite Horn clauses with one positive head. Ground
definite Horn clauses may relate arbitrary finite tuples of those constants.

Examples newly covered:

```text
@x pair(x,x)
@x pair(x,John) -> out(John,x,x)
@x left(x,1) && right(John,x,x) -> out(x,x,John)
@x p(x) -> out(1,John)
```

Functions, interpreted tests, structured terms, witnesses, zero-argument atoms,
non-Horn clauses and rules containing two or more distinct native variables
remain outside this certificate. Existing capture/resource gaps remain stops.
Classification only observes structure; shapes are never assertions or proof
pool entries. Declared variable roles survive current live bindings.

## Finite representative argument

Let C contain every fixed semantic scalar anywhere in the primary family.
Choose one arbitrary fresh parameter e, absent from every primary value.
For any admissible scalar value a let rho(a)=a when a is in C, and rho(a)=e
otherwise. A clause has at most one variable, so its complete set of instances
is represented by substituting each member of C plus e. This includes ground
heads, ground premises, repeated variable slots and fixed slots.

A model of the full ordinary scalar theory restricts to these representatives.
Conversely, extend a representative model by interpreting every relation on
tuple (a1,...,an) as its value on (rho(a1),...,rho(an)). Constants are fixed by
rho. Evaluation of every admitted literal commutes with this map, so every
clause remains true under every scalar substitution. The finite reduction thus
preserves consistency. It does not assert interpreted equality, inequality,
rich-term operations or finite-domain semantics for @.

The representative theory is definite Horn plus signed units. Its positive
least closure and negative-unit checks suffice for consistency. Native signed
propagation and clause reduction are sound additional operations. This does
not promise every entailed negative conclusion or conclusions requiring query
assumptions. The query/hypothesis/orphan question remains open.

This finite-model argument alone is not a certificate for the implementation:
the native observer must also visit the necessary instances. The entire rule
contains at most one TVariable, regardless of atom arity. Its native rotation
therefore visits each seeded representative without a multi-variable TSolve
join/filter. Repeated positions read the same binding; fixed slots retain their
semantic values. Inference and matching remain native. No Cartesian-product
inference engine or assumed predicate facts are added by the reference.

## Transport and scope

Ordinary private closure runs before representative closure. Every proved
application reconstructs its premises and whole source support, with carried
depth. Only X-dependent proofs cross the immutable round barrier. Foreign-only
intermediates stay private. Generalization replaces only actual fresh-parameter
slots, preserving fixed values and repeated identity. A ground head stays ground.

The existing global freshness checks, finite source-set closure and resource
limits apply unchanged. Unsupported quantified declarations cannot acquire a
certificate from an unrelated covered declaration or from absence of waiter
gaps. A completed admitted cut returns Coverage.SINGLE_VARIABLE_HORN; the older
strict unary/uniform fragment continues to return Coverage.MONADIC_HORN.
Collision witnesses need no saturation certificate. Legacy uncovered ground
observation closure still has Coverage.NONE.

## Independent controls and remaining boundary

The first new cross-participant universal-body control exposed an observer
defect already present in the monadic fragment:

```text
X: @x left(x) && right(x) -> out(x)
A: @x left(x)
B: @x right(x)
```

The old reference returned SATURATED with zero transported products, although
the X/A reduction `right(e) -> out(e)` is proved and should reach B. This is a
missing proved production/residual; the probe with an added negative ground
out still found COLLISION, so it is not evidence that this particular example
falsely accepts an inconsistent cut. Raw probes are retained under
`target/context-production-rounds/evidence-stage2h/`.

In Linker.linkDatabase, waiter-based hypothesis preparation clears the local
excluded/candidates collections before the old residual hook runs. The moved
hook observes the proved reduction before that clearing. It reads only actual
excluded literals; it does not use the assumed waiter set as premises and does
not change native inference or hypothesis behavior. A direct capture control
checks both presence of a proved premise and absence of an assumed-only one.

The tuple runner independently computes reachability for all64 combinations of
two tuple-schema rules, universal roots and negative ground units. The schemas
use fixed named/numeric slots and repeated variable slots. Further controls
check arbitrary named/numeric instantiation, positional mismatch, repeated
donor match/mismatch, constant heads, negative propagation, three-source joins,
all six participant orders for delayed collision, whole supports, depth stops
and independent opposite sibling universals.

A separate oracle enumerates all16 directed graphs on two values. It computes
two-edge paths by ordinary Boolean loops and compares all four resulting pairs
with native products of:

```text
@x @y @z edge(x,y) && edge(y,z) -> out(z,x)
```

These controls exercise shared middle variables, repeated assignments, cycles,
missing joins and head permutation. Their successful finite observations do not
prove arbitrary multi-variable tuple coverage: those cuts retain INCOMPLETE and
Coverage.NONE. The TSolve join/filter needs its own coverage argument before
that boundary can be widened. No native matcher defect is inferred merely from
this conservative boundary.

Runtime gates, real effective-view/pin verification, witnesses and DMZ proof
restriction completeness remain pending.
