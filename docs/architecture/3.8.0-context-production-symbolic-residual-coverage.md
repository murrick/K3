# Stage3x: symbolic ordinary residual coverage

ContextOrdinaryResidualCoverage audits actual stage3w receipts without inserting
any inferred result. INPUT_STEP uses original primary/carried clauses as owners
and their actual ground units as donors. LOCAL_CLOSURE additionally uses every
locally reconstructed clause/proof, including foreign-only intermediates. Those
intermediates remain local; the shared frontier still exports only X-dependent
proofs. Receipts retain immutable internal owner and complete local proof ledgers.

For each owner proof the audit enumerates every nonempty removed-literal subset.
Removed literals must coherently match opposite actual ground donor units. The
required remainder substitutes only variables bound by those donors and keeps
every other universal slot. Clause.remainder creates this structural obligation
only; it asserts nothing and supplies no proof. Every required nonempty remainder
must already have an observed proof with the exact whole union of owner/donor
sources at depth no greater than max(owner/donor depths)+1. Distinct alternatives
must each be covered; a shallower already observed proof may discharge a cycle.
Fully removed clauses require reported collision rather than an invented empty
clause. Universal unit remainders remain explicitly unsupported.

Variable matching preserves polarity, semantic constants, repeated variables
and cross-literal sharing. There is no enumeration of a finite constant domain.
In `@x @y left(x)&&right(y)->pair(x,y)` with donor left(1), the obligation is the
universally quantified `right(y)->pair(1,y)`, not a list of ground instances for
currently known y values. Exact alpha-equivalent symbolic clauses are required;
this audit does not invent a proof by specializing/generalizing another result.

All self/cut receipts must be verified, collision-free, unique and bound to the
same exact sealed input before any success is returned. Missing/stale/duplicate/
independent receipts or work/depth stops return uncovered, with no covered family
prefix. The public result deliberately says general saturation/admission UNKNOWN.
Even a covered local reduction set does not certify clause-to-clause composition,
all general native interactions or arbitrary-clause consistency. No default or
candidate gate is redirected, and the unit-only Horn certificate is unchanged.

## Concrete controls and newly exposed observation boundary

The split A-left/B-right fixture covers its partial residuals at input0 and the
carried depth2 consequences at input1. Omitting a partial residual fails even
when no unit conclusion is yet enabled. For X `b&&c->out`, A `a; a->b`, input-step
needs the native b proof but local closure also needs the c->out residual it
enables. Deliberately removing that residual distinguishes the two modes.
These omission controls edit only the internal audit test list, not native data
or caller-constructible receipts. Source-alternative deletion fails even when
the same semantic clause still has a different valid proof. Polarity, named
constants, repeated arguments, unrelated sibling opposites, dormant rules,
immutable ledgers and resource/receipt controls are explicit.

A separate real native control demonstrates an observation gap without deleting
anything: X `@x @y left(x)&&right(y)->pair(x,y)`, one foreign cut containing
left(1) and right(2). The native capture produces pair(1,2) and ground-specialized
partial residuals, yet does not provide the universally quantified partial
residual justified by the smaller X/left proof. Sound stage3w observations still
verify; the new INPUT_STEP audit returns uncovered with missing symbolic proof.
Thus complete-looking ground results cannot masquerade as universal coverage.
The earlier stage3w transport never claimed completeness, so this is a newly
reproduced boundary of observation, not a default-authoring regression.
