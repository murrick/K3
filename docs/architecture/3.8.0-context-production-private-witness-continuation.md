## Concrete obligation

Use common X `anchor(1)` and X rules `ready(w,1)->out(w,1)` and
`out(w,1)->~flag(w,1)`. Trusted A owns one existential bundle
`$w (seed(w,1)&&flag(w,1))`; B owns `seed(w,1)->hidden(w,1)` and
`hidden(w,1)->ready(w,1)`.

Replay the producers in three explicitly selected passes. After the first pass,
`hidden(W_A,1)` has exact `{A bundle,B first rule}` support at depth1. The common
packet is unchanged. After the second pass, `ready(W_A,1)` has exact three-source
support at depth2; the common packet is still unchanged. Only the third pass,
using X's rule, exports `out(W_A,1)` with exact four-source support at depth3.
The local negative clause then refutes with the original five sources at depth4.

Discarding local deductions between those passes loses the first two steps;
common equality alone cannot establish saturation. This is a concrete execution
obligation for the upcoming family integration, not a claim that the guarded
current full writer silently accepts this case.

## Implemented component

`ContextWitnessResultTransport.PrivateAdvance` seals local before/after pools,
separate common output, exact input-enabled Horn obligation count, and separate
local/common change flags. `advancePrivate` selects whole producers by original
Source from the exact native-bound snapshots. It captures all ordinary owning
declarations before selecting producers, preflights the selected Horn schemas,
performs a fresh native replay, reconstructs verified routes including foreign-only
derivations, and checks local-before/local-after obligations. Caller-supplied
statements or alleged proofs are not inputs.

`rebasePrivate` requires the new common packet to retain the old common proofs
and satisfy the same X identity and physical-cut checks. It rebuilds authenticated
raw seeds from the same original snapshots and merges the sealed local ledger.
Original Source+binder identity, proof alternatives and cumulative depth survive.
Local facts cannot migrate to another private cut through this API.

Common output retains only proofs with an X Source. Neither raw private seeds
nor private-only intermediate conclusions become common facts. The output has
no basis, roundCut or coveredCut: this component deliberately cannot establish
a shared-family barrier. Legacy verified exports still refuse private replay.
`verifyPrivateClosed` checks full closure of the explicitly selected whole
producer set on the local pool; it makes no claim about omitted declarations.

Existing bounds remain: positive bundles, one witness origin per literal,
rank8, atom64, support alternatives256, bounded work/events/depth, bounded whole
ordinary declarations and the existing native shape restrictions. Native target
capture still requires an ordinary target declaration; bundle-only targets need
explicit seed-backed target ownership before family integration. Signed bundles,
functions, mixed prefixes and broader native forms are not silently waived.

## Qualified cases

`ContextPrivateWitnessContinuationRunner` checks both trusted-member orders,
shared and split seed/flag bundles, original witness reuse over fresh carriers,
private progress with unchanged common contents, cumulative depth refusal,
exact final closure and stable replay. Independent private cuts do not receive
intermediates; a carried common product preserves its original cut's witness
rather than aliasing a sibling's same-spelled binder.

A separate case adds a second same-text producer from another original member:
only the proof alternatives change, no atom is added. Local change remains true;
both original support alternatives survive later private steps and X export.
Wrong-context same-text producers, seed-as-producer, unit/negative producers,
common rollback, another X cut, empty selection and exhausted work refuse.
The family assembler's private-bundle guard stays active.

Validation and recovery pointers are recorded below.
