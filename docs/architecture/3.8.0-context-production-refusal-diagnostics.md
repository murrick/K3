## Change and scope

The model-publication catch now uses the existing exception's `toString()`.
This is one production-source line. It preserves status, phase, original sealed
evidence, before/after revisions and the owning attempt lifecycle. No exception
base contract, inference, model search, resource policy or settlement algorithm
is changed. PUBLISHED and NATIVE_REJECTED keep their existing result construction.

Actual reports and Console now carry the existing refusal text, including its
`Runtime error:` prefix. The typed status remains authoritative: a resource stop
is INCOMPLETE, an audited negative proof is REFUTED, and native local refusal is
NATIVE_REJECTED. Explanation text is neither proof nor future write authority.
