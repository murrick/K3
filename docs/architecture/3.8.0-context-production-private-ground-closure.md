## Per-cut private iterations

The method first obtains the existing complete ordinary/parameter/unit-probe
baseline. Nonground ledgers are outside this new method's closure scope. Each
local iteration computes ground compositions from the preceding sealed local
ledger, then replays the proved result locally for native unit reductions. It
combines all actual proof recipes, preserving the initial full original/carried
owner list. No primary Source is invented. New carrier clauses keep their whole
original source alternatives and cumulative depths. A subsequent local iteration
may consume those proofs inside the SAME cut.

Unchanged means identical semantic clauses, exact source groups and minimum
recorded depths, independent of list order. Before returning a closed receipt,
both independent LOCAL_CLOSURE checks run on every actual local proof:
unit-donor residual coverage and distinct ground compound-pair coverage. A pool
that merely stops changing cannot bypass either audit. Work and event budgets
are shared across the baseline and every composition/reduction replay; probe
allowance is not reset. A separate maximumLocalRounds bounds the number of local
iterations. Exhaustion/failure returns an unverified receipt with no product or
collision prefix. A proved typed collision can still be returned for the full
family barrier to validate.

Each cut starts from the same immutable common Frontier. Private closure is
recomputed from its originals plus common X-dependent carriers on each call;
no private lemma is stored in another cut or global X. Only positive-depth
X-dependent recipes enter exported products. Foreign-only compounds and units
remain in localProofs. A sibling can consume exported consequences only after
the exact-input all-cuts barrier. The old inspectWithCompositions one-sweep API
is unchanged, including its negative private-chain control.
