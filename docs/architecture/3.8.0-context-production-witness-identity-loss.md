# Stage2w: isolate native witness identity loss before choosing a repair

The stage2v witness contract was reduced further. No derived chain is needed:

```
!$x out(x,1);
!@x ~out(x,1);
```

Both statements are accepted, in either insertion order. They are inconsistent:
the witness required by the first statement is among the admissible values
covered by the second. This is a native, capture-disabled failure. Independent
exists(out) and exists(not out) are consistent, and must remain accepted; so must
a denial at a different fixed argument or a rule for another predicate.

## Exact observed boundary

In the direct fixture the Linker binds the universal variable to a transient
C-variable child whose parent is the primary out witness. Before generated
materialization, the opposite signed Domain compares equal to the primary using
Domain.equalsBase (which delegates to ArgumentsList.equalsBase). The latter
recognizes exact term identity and immediate parent/child identity.

RuleFactory.add delegates to GeneratedCVarMaterializer.rebindForGeneratedRule.
In ACCEPT, that helper replaces a surviving transient child with a fresh root
owned by the new generated Rule. The opposite stored Domain consequently no
longer compares equal to the primary. Analyzer.checkRight compares stored
opposites through equalsBase, and misses the contradiction. Its final native
qualification accepts the program.

ContextWitnessIdentityLossRunner independently exercises those exact boundaries:
the source Domain compares equal before the helper, the returned Domain does
not, polarity and fixed argument are unchanged, the source child remains intact,
and CHECK bypasses the helper. Its green diagnostic marker certifies reproduction
of the information loss, NOT correctness of native inference. It is included in
the focused reference only, not the green DMZ manifest.

## Controlled ablation, not a proposed patch

A temporary /tmp classpath override of GeneratedCVarMaterializer made
rebindForGeneratedRule return its input. No repository Core file was edited.
With the same strengthened native contract, failures dropped from 5/15 to 1/15:
the remaining failure is the existential p -> q,r -> out fork followed by the
universal denial. The negative-first fork and unary-chain controls reject in
this experiment. Therefore rebinding explains the direct minimal failure and
several observed consequences; it is not a complete explanation of the fork.

The no-rebind experiment also fails KangerCVarRuleScopeSafetyRunner:
"generated Rule retains transient C-variable child: ?father(Alice,*9)".
Retaining runtime children as durable identity is incompatible with the existing
lifecycle boundary. Global alpha-root equality is also invalid: independent
witnesses may share a stored representative, as the stage2t/2u/2v controls show.
Neither workaround is installed.

## Repair direction and required evidence

Preserve semantic witness identity separately from a stored Rule's physical
carrier. The existing route verifier already separates original primary witness,
whole source proof and materialization occurrence. A native repair must retain
that distinction during qualification and all required producer applications,
without requiring the optional diagnostic capture.

Before integrating such a repair, reproduce the remaining fork with rebinding
bypassed and identify the additional unification/coverage boundary. Then exercise
shared-origin conjunctions, independent existential countermodels, alpha-reused
carriers, both insertion orders, rollback/query isolation and repeated closure.
A passed direct-conflict check alone cannot close the native witness contract.
No witness transport or runtime round gate is enabled by this diagnostic stage.
Question3 remains open.

In sequential no-rebind replay, the stored q(*3,1) and r(*5,1) have different
transient IDs and both report parent=-1 after their compile operations. Keeping
the child object does not preserve its historical lineage across that lifecycle.
This trace explains why the ablation cannot supply a durable shared-origin join;
it does not yet isolate every native matching condition for the residual fork.
