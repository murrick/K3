# Stage464 — audited signed-plan to native seed-frame adapter

## Contract

New explicit ContextWitnessResultTransport.signedWitnessFrame consumes an independently
checked signed-witness plan receipt, exact expected snapshots/row policy and explicit rank,
materialization-work and plan-audit-work bounds. It freshly checks the plan before and after
materialization. Cut enumeration uses the receipt's immutable captured foreign list.

The output is DATA: a signed common Packet containing only original X primary seeds, plus
one separate local Packet for EVERY foreign logical cut containing common+that cut's private
seeds. It is not a PrivatePool, initial-entry receipt, STEP, coverage, consistency result or
write authority. No classifier, initial/grouped controller, old positive-only API or writer
is redirected. Local raw primary proofs contain foreign-only alternatives and cannot pass
the existing shared-family parentX contract as common knowledge.

Witness seeds are converted with their exact Source/binder Origin, sign and ordinary value.
Opaque clause rows contribute only authenticated ground unit literals, including negative
units, under the WHOLE original Source at depth0. Other clauses stay unmaterialized and still
accounted by the audited plan; this does not qualify their inference shape. Duplicate atoms
coalesce while retaining EVERY singleton primary Source alternative. Common packets are not
mutated when local alternatives are added. Native adapter profile: arity<=8, at most ONE
Origin per literal, common+private rank<=explicit bound<=8, existing256 alternative bound and
explicit work. Broader data-plan shapes do not imply native frame support. Missing authentic
common primary seeds, unsupported shape/rank or any work/audit stop exposes no partial frame.

ContextSignedWitnessFrameAudit reads ORIGINAL bundle/unit-clause atoms directly, without
calling the adapter. It verifies exact cut inventory, sign/Source/binder/value, all singleton
depth0 alternatives, shape/rank bounds and absence of STEP/coverage stamps. It audits common
and each local frame separately, rejecting private leakage into common. Plan audit is freshly
replayed too. Historical receipts must freshly recheck, and have no live-provider authority.
Plan audit and frame work allowances are separate, not one combined work bound. Immutable
original graph precondition applies; controlled QA reflection is not a serialization/security
claim against hostile changes of the expected snapshots.
