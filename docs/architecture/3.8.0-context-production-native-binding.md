# Stage3i: native-checked whole-primary replay bindings

## Concrete origin countermodels

A native primary `exists w (p(w,1) && flag(w,1))` can have its origin metadata
changed to text with two independent binders. The metadata is syntactically valid
and a fresh inventory hash faithfully includes that changed text, yet replaying
it would lose the native shared witness. The reverse alteration would invent
sharing. Both are refused after capturing the new inventory, proving that the
rejection comes from native structural comparison rather than a stale hash.

Other controls change a native rule's conclusion sign, separate a shared body
variable, substitute a fixed semantic value, append another source statement or
remove the origin. Each refuses the entire binding. Alpha-equivalent universal
and existential binder names remain accepted. Native structure, not textual
spelling or a revision/hash label alone, determines the permitted replay.

## Whole row binding and scope

ContextProductionNativeBinding.bind checks the acquired inventory fingerprint
before and after reading all effective primary rows. For each row it uses the
actual native Rule ID to create an exact Source(context,revision,row,role,view),
where view identifies the frozen acquired inventory fingerprint. The raw origin
must compile as exactly one sourced assertion in a fresh disposable capture.
No native inference is run during that parse.

A primary containing a native existential witness must be a supported whole
primary conjunction. The existing ContextWitnessBundle extractor now serves the
native side as well as the fresh replay side. Comparison preserves global
first-occurrence binder ordinals across every atom, signs, predicate/argument
positions and ordinary semantic fixed values. Local primary ownership,
non-dominating roots, no parent witness, four binders/eight atoms/eight arguments
and other existing bundle limits remain unchanged. Mixed universal/existential,
conditional and generated witness cases do not gain support.

Otherwise, the entire native and fresh Rule must consist of ordinary signed
clauses:1..8 conjunctive branches,1..3 literals per clause,1..8 arguments per atom,
at most2 universal variables with the correct Rule owner, and ordinary TERM or
TVARIABLE arguments only. Native-checked clause shapes are compared modulo
universal alpha renaming and conjunct order. Calculated/system/function or other
nonordinary arguments refuse binding. Unsupported native content is not filtered
out of a supposedly complete binding.

Every effective primary row yields exactly one immutable Entry, with its exact
Source and original statement. A WITNESS_BUNDLE contains one detached typed whole
bundle. A CLAUSES entry contains all native-checked signed clauses of the source,
including explicit scalar facts and ground conjunctions; a source conjunction is
not split into independent source IDs. Generated cache IDs are recorded separately
and never acquire primary Entries or primary proof labels. The original complete
inventory remains attached for audit, including cache rows and available tombstones.

The binding returns a detached Snapshot only if all rows succeed. Missing text,
changed inventory, unsupported later rows or phase limits return bound=false with
no Snapshot/prefix. It constructs no derived production, no invented scalar/witness
seed, and no authoring verdict. Ordinary clause shapes become evidence only after
the complete original native Rule and its replay have been checked.

## Owning provider integration

The DUMB2 qualification snapshot lease now has bind(work,events). Under its DB
monitor it validates lease authority, binds X and every exact initialized foreign
view, and validates freshness again in finally. If any source binding or final
guard fails, no partial family Binding is returned. The family artifact is
immutable and contains no Mind/storage handle. close still belongs to the lease;
borrowed provider layers are never closed by the binder.

The real-storage controls now verify the stored whole witness bundle, exact pin
context/revision/role of foreign Source labels, explicit generated-cache exclusion,
and a private initialized scalar fact bound from its actual native layer. A
closed lease cannot authorize binding through its retained historical inventory.

The public low-level binder verifies native/text correspondence against supplied
inventory metadata; it does not authenticate arbitrary caller-chosen Context
labels. Actual acquisition authority remains the provider-owned lease. Detached
bindings may outlive that lease as historical artifacts, not live permissions.
Future qualification operations must remain guarded or reacquire current state.

knowledge or a false covered verdict. General native graphs outside these bounded
