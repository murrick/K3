## Required behavior and reproduction

```text
A: !left(1); !p(1);
B: !right(1); !~p(1);
proposed X: !@x left(x) && right(x) -> p(x);
```

Each original pair is consistent. Native X+B produces `~left(1)` (rendered
`?left(1.0) GB`). That product conflicts with A's `left(1)`. The candidate must
be refused, regardless of connection order. The current public write accepts
it and advances X from revision0 to1. The previously recorded narrower
observation about original pair consistency does not qualify the produced X.

Foreign-only A/B disagreement remains permitted. Do not implement this as an
unconditionally consistent monolithic union of all foreign authoritative rules.

## Round contract

1. Freeze candidate X, exact direct pins, effective private views, accumulated
   proved products and their causal supports at the round boundary.
2. Independently run ordinary native inference with that same input against
   each direct source. No participant consumes another participant's output
   from the current round. Local inference inside a participant may saturate.
3. Collect detached proved productions and alternative supports before
   destroying the temporary runtimes. Preserve semantic identity and exact
   source attribution, including participation by X. Do not accept hypotheses,
   conditional results or query presentation artifacts as knowledge.
4. Reject atomically on a disallowed collision. Otherwise merge the round's
   products/supports into the next immutable qualification snapshot. A semantic
   twin cannot erase an independent X-dependent support.
5. Finish only when there is no new semantic or support information that can
   change qualification. An operational stop is not a successful certificate.

Physical parallel workers are an optimization. The first executor may run
participants sequentially, provided the shared round input remains immutable.
Permutation enumeration belongs to regression checks, not the algorithm.
Existing native recursive-depth limits remain in force. No termination theorem
for the full inference language is claimed. Rebuilding participant runtimes
must not reset derivation depth at a transported-product boundary.

Qualification products remain transient. Durable commit contains authoritative
B_X and G_X reproducible from B_X alone. Failed qualification preserves revisions,
source states, topology, certificates, reservations and caller presentation.

## Implementation sequence and acceptance gates

1. Executable failing contract fixtures, native-production control and order
   permutations. Preserve the pre-fix failure as evidence, not a green gate.
2. A complete supported production/support transport surface and a synchronous
   reference executor. Include stored-conclusion suppression and semantic
   duplicates; a later X-supported proof must survive beside a foreign-only
   proof of the same conclusion. Existing experimental DMZ journals explicitly
   have bounded observation surfaces and cannot be assumed complete here.
3. A shared qualifier for live write/commit, publication candidates,

4. Regression gates: both signs, names/numbers, compound residuals, multi-round

## Stage2a — native journal and bounded ground reference

Implemented as an opt-in foundation. The ordinary publication/write/topology
gates are still unchanged; the pending authoring contract is still RED.

`ContextProductionCapture` captures native applications before suppression of
an already stored conclusion and before stored Cause optimization. An application
retains its whole ordinary concrete donor group, signed detached conclusion,
source producer alternatives and the native rule ID for diagnostics. Primary
semantic duplicates retain each declared exact source occurrence, including
local-X/foreign aliases of the same clause. A Source includes Context UUID,
revision, source rule, X role and caller-supplied effective-view identity; the
replay owner must verify those labels. This observational journal is not a
compatibility certificate.

Transport uses `SemanticTermSnapshot` values and placeholder assertions, never
rendered argument text. Materialized results are checked against matching
observed application/ground pairs. Unsupported source forms, unobserved
materializations and observation-budget exhaustion remain explicit gaps.
Query FALSE/TRUE/hypothesis passes are excluded: conditional query products do
not enter this qualification journal. The opt-in hooks have no inference effect
when the journal is inactive.

`ContextProductionRoundsReference` is deliberately in the qualification module,
not the runtime provider. Each participant receives the same previous round's
products, replays its independent immutable declarations and executes the
ordinary native ACCEPT lifecycle in a disposable technical child. A standalone
CHECK reconstruction is not substituted for that authoring lifecycle. The
source/donor graph is reconstructed only from observed native applications;
this reference does not implement a second clause/unification reasoner.

The reference retains independent source-occurrence support sets for each
semantic ground. Only supports involving X are transported between participants.
Cycles with an existing ground seed reach support-set closure without enumerating
infinite unfoldings of the same proof; observations still preserve native
application events. This representation is sufficient for the tested qualification
attribution, not a claim to enumerate all proof histories or DMZ restrictions.
Derivation depth is carried across transported products; the native flood limit
also applies inside each participant. Round, event and proof-work limits return
INCOMPLETE rather than SATURATED.

### Stage2f DRAFT: native eigenparameter experiment

This is an explicit experimental entry point, `inspectWithParameters`.
Default `inspect` retains stage2e's immediate INCOMPLETE coverage guard.
The experiment assumes that universal quantifiers range over arbitrary
admissible values, including values not mentioned in primary knowledge. This
semantic assumption has been submitted to the author for clarification and
is not recorded as an accepted architecture decision.

Ordinary participant closure runs first. If a generic waiter gap remains, a
fresh isolated replay additionally seeds native TValue bindings with arbitrary
fresh parameter terms. It installs no predicate assertion or new knowledge
source. Native compiler/Linker alone performs all inference. The existing proof
closure still requires independently proved premises and retains whole source
sets and carried depth. Only proved X-dependent results cross the round barrier.

Under the arbitrary-value quantifier assumption, a proved result `q(e)` for a
fresh arbitrary parameter e can be universally generalized: all original
premises remain unchanged under renaming of e because e occurs in none of
their constants. Parameter identity is preserved across every direct argument
slot, so `q(e,e)` becomes `@x q(x,x)`, while `q(e1,e2)` can retain two independent
variables. Parameters are semantic snapshots, not textual replacements.
Freshness is checked against primary constants, including nested values;
structured result values containing a parameter stop with INCOMPLETE rather
than silently escaping as ground knowledge.

The experiment carries one stable parameter registry across its private
replays, with at most three distinct variables per native rule. Planned added
parameter rotations and bindings consume the proof-work budget. Rank, event,
depth and work stops remain explicit INCOMPLETE. This rotation precharge is
not a complete accounting of native inference work.
