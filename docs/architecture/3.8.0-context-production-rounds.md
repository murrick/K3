## Required behavior and reproduction

```text
A: !left(1); !p(1);
B: !right(1); !~p(1);
proposed X: !@x left(x) && right(x) -> p(x);
```

Each original pair is consistent. Native X+B produces `~left(1)` (rendered
`?left(1.0) GB`). That product conflicts with A's `left(1)`. The candidate must
be refused, regardless of connection order. The current public write accepts
it and advances X from revision0 to1. The previously recorded narrower
observation about original pair consistency does not qualify the produced X.

Foreign-only A/B disagreement remains permitted. Do not implement this as an
unconditionally consistent monolithic union of all foreign authoritative rules.

## Round contract

1. Freeze candidate X, exact direct pins, effective private views, accumulated
   proved products and their causal supports at the round boundary.
2. Independently run ordinary native inference with that same input against
   each direct source. No participant consumes another participant's output
   from the current round. Local inference inside a participant may saturate.
3. Collect detached proved productions and alternative supports before
   destroying the temporary runtimes. Preserve semantic identity and exact
   source attribution, including participation by X. Do not accept hypotheses,
   conditional results or query presentation artifacts as knowledge.
4. Reject atomically on a disallowed collision. Otherwise merge the round's
   products/supports into the next immutable qualification snapshot. A semantic
   twin cannot erase an independent X-dependent support.
5. Finish only when there is no new semantic or support information that can
   change qualification. An operational stop is not a successful certificate.

Physical parallel workers are an optimization. The first executor may run
participants sequentially, provided the shared round input remains immutable.
Permutation enumeration belongs to regression checks, not the algorithm.
Existing native recursive-depth limits remain in force. No termination theorem
for the full inference language is claimed. Rebuilding participant runtimes
must not reset derivation depth at a transported-product boundary.

Qualification products remain transient. Durable commit contains authoritative
B_X and G_X reproducible from B_X alone. Failed qualification preserves revisions,
source states, topology, certificates, reservations and caller presentation.

## Implementation sequence and acceptance gates

1. Executable failing contract fixtures, native-production control and order
   permutations. Preserve the pre-fix failure as evidence, not a green gate.
2. A complete supported production/support transport surface and a synchronous
   reference executor. Include stored-conclusion suppression and semantic
   duplicates; a later X-supported proof must survive beside a foreign-only
   proof of the same conclusion. Existing experimental DMZ journals explicitly
   have bounded observation surfaces and cannot be assumed complete here.
3. A shared qualifier for live write/commit, publication candidates,
   connect/disconnect/revision switches, and effective private connection edits.
4. Regression gates: both signs, names/numbers, compound residuals, multi-round
   chains, independent/alternative supports, permutations, support cycles,
   recursion limits, rollback, refusal atomicity and no durable foreign products.
   Check DUMB2, relevant Core/Console/Server paths and existing DMZ drivers.
5. Publish implementation and exact evidence; then resume DMZ language/results/
   source-attachment readiness. Optimize only after equivalence qualification.

The new contract probe is deliberately outside the green DMZ suite until an
implementation satisfies it. It exits nonzero when the required refusal is
missing and checks all fixtures before reporting failure. This is stage1 of
the plan, not an implemented qualifier.

Run it with `python3 scripts/qualify-context-production-rounds.py`. Every
invocation compiles fresh production/driver classes and writes its raw log and
report under `target/context-production-rounds/run-*`. The process uses only
disposable Context fixtures, never the author's databases.

Stage1 validation on Linux/OpenJDK21.0.12.1, Java8 source/target: fresh compile
of 490 production sources and this driver passed. The driver executed 56 checks;
two failed, exactly the masked write refusal in each A/B order. Both unmasked
controls refused with revision0 unchanged; both foreign-only controls accepted
and advanced to revision1. Native signed-production and source-preservation
controls passed. This is expected RED evidence of the defect, not qualification
of an implemented fix. The production-rounds driver is not added to the green
DMZ manifest yet. No wider tests are claimed for this documentation/fixture slice.
