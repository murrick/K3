# Stage3w: source-bound ordinary signed residual transport in Core

ContextOrdinaryResidualRounds is an observed-proof transport channel for signed
ordinary clauses, including units and still-quantified compound residuals. It
reuses native-bound X/self/foreign scope validation and adds sealed immutable
Frontier/Product/Receipt authorities. It does not replace the older unit-only
executor or grant candidate/default admission.

Every cut sees exactly one common immutable input. Only that cut's actual
primary X/foreign declarations and carried X-dependent clauses enter its private
native replay. A semantic carrier is replayed once with every whole original
Support alternative; source groups and cumulative depths are preserved through
ContextProductionCapture.replayDerived, never relabelled as primary depth0.
Carrier and original whole-declaration roundtrips are checked. No raw foreign
clause is lifted merely because it exists or participates in a local replay.

The opt-in native residual-subset hook records actual reductions. Applications
join the same event stream as single-literal residuals. Before reconstructing
any output, ContextOrdinaryResidualVerifier authenticates every producer Support
against an actual original or carried owner and matches its entire clause to
the observed remainder plus opposite excluded premises. Bindings span the whole
clause and preserve repeated variables, fixed values and remaining universal
slots. Unsupported multi-step or source/instance-mismatched events refuse.
This is a structural check of an observed native reduction, not an alternative
inference engine or a generator of missing native conclusions.

Proof reconstruction starts from actual original clauses and carried recipes.
Only proved ordinary ground units discharge event premises. Each output Support
is the exact union of one whole producer alternative and one whole proof for
each donor, at max(producer/donor depths)+1. Repeated closure retains minimum
observed depth per clause/source group; a circular unsupported assumption cannot
seed itself. Every recorded native premise must eventually be reconstructed.
Only positive-depth outputs with an actual X source are exported. Pure foreign
intermediates remain local even when they supply real premises for an X proof.

Complete merge authenticates exactly one verified Receipt for self and every
selected cut, all from the identical input object. Missing, duplicate, stale,
independent or stopped participants publish neither a frontier nor a collision
prefix. Whole source alternatives remain distinct; proof/clause/work/depth/event
limits are explicit. Actual opposite unit proofs with an X-dependent side return
typed sourced COLLISION evidence. Native refusal or an unsupported nonunit
collision is INCOMPLETE unless a typed unit refutation was actually proved.

## Concrete results

X `@x left(x)&&right(x)->p(x)`; A `left(1)`; B `right(1)`:

- Barrier1 transports `right(1)->p(1)` with X/A sources at depth1, and the
  symmetric X/B residual. Neither raw sibling unit enters the shared frontier.
- Barrier2 obtains p(1) from actual native replay of a carried residual and the
  other cut's local unit, with exactly X/A/B sources at depth2.
- A/B order reversal retains that exact proof. With a separate C holding
  negative p(1), barrier3 returns typed opposition. The original masked A/B
  fixture still refutes at barrier2.

`@x @y left(x)&&right(y)->pair(x,y)` additionally retains a genuine remaining
universal variable at barrier1, then instantiates it in an actual native
application at barrier2. There is no enumeration of known constants as a
surrogate for the domain of @x. Named constants, negative heads, independent
same-atom source alternatives, wrong excluded donors/owners, foreign-only
residual isolation, immutable ledgers and no-prefix stops have explicit controls.
