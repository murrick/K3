## Concrete scope distinction

Shared form: `!($x (a(x)&&b(x)))->q();`.
Independent form: `!(($x a(x))&&($y b(y)))->q();`.
The corresponding universal implications are `!@x a(x)&&b(x)->q();` and
`!@x @y a(x)&&b(y)->q();`. Negative existential occurrences normalize to
universal input variables without witness objects. The first rule requires
both predicates at one value; the second permits different values.

With a1,b2 and opposite-q, independent antecedents force a collision, whereas
the shared form has a model with no common a/b witness. With a1,b1 both forms
collide; with only a1 both have a consistent model. Absence of b is not asserted
as universal negative knowledge: it permits a model without b. These semantic
controls apply over all admissible values, not just the active domain. Uniform
atom polarity reversal preserves the distinction.

The236-check scope runner compares nested existential forms, their respective
prenex universal forms and independently alpha-renamed declarations, both atom
polarities and zero-arity/ground-unary consequents. Each entry is one whole
primary Source/one three-literal clause, CLAUSES kind/zero witnesses. Shared
form has one used universal variable and exactly repeated a/b slot; independent
form has two distinct slots. Exact signs/ground consequent arity survive.
Shared/independent clauses are not alpha-equivalent, while their respective
prenex and renamed forms are equivalent.
