## Proven GC result

The canonical Term/Predicate sweep is not the primary defect.

A balanced technical child returns the root Mind to transaction quiescence and triggers canonical sweep. The original malformed-compile characterization instead left `transactionCounter == 1`, which prevented quiescence and therefore suppressed `pack()`.

The GC residue is therefore a downstream effect of leaked operation-local technical transactions.

## Required next model

Do not patch the five query families independently.

Introduce one Core technical-transaction scope with these invariants:

1. explicit user transactions and operation-local technical transactions are distinct lifecycle classes;
2. every technical child has exactly one owner;
3. a technical child must settle before the enclosing operation/command returns, on success or failure;
4. pre-settlement exceptions automatically roll back the technical child;
5. commit/release marks settlement as started before entering `Mind.commit`/`Mind.release`, so cleanup never retries a partially completed settlement;
6. the original Throwable remains primary; cleanup failure is suppressed;
7. no technical child is published as a user-visible transaction level;
8. root quiescence remains the trigger for `pack()/update()` and therefore canonical GC.

The implementation should be Java 8 compatible and preferably express ownership structurally (for example through an AutoCloseable scope) rather than through repeated handwritten try/catch blocks.

## Command-boundary acceptance target

```text
user transaction stack: U0 -> U1 -> ... -> Un
technical operation:                    T

command success: T commits into Un and disappears
command failure: T rolls back and disappears
command return:  no T may survive
```

At every command boundary:

- user-visible transaction depth and internal lifecycle state agree;
- `transaction == 0` implies no hidden technical reservation;
- failed `get`/compile/query cannot leave technical state behind;
- GC is not suppressed by an abandoned technical child.

No merge, release acceptance, publication, or production cutover is authorized by this audit checkpoint.
