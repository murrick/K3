# Stage3aj: detached universal compound-pair obligation audit

The stage3ai proof kernel proves a proposed resolution; it does not show that
all proposed pairs were considered. ContextUniversalCompositionCoverage audits
one exact verified collision-free receipt ledger against supplied immutable
kernel Evidence. It grants no transport, closure, family or write authority.

## Concrete omission: self-resolution

Copying the ground enumerator's distinct-clause restriction would be incorrect
for universally quantified parents. The single actual source

    @x p(x,1) || ~p(2,x)

resolves against an independently renamed copy

    @y p(y,1) || ~p(2,y)

to produce

    p(1,1) || ~p(2,2)

by selecting p(x,1) and ~p(2,y), hence x=2, y=1. This is a new ground consequence,
not an alpha-renaming of the parent or a tautology. Equivalently, the x=1 and
x=2 instances eliminate p(2,1). The single original Source occurs once in the
union, while cumulative proof depth increases to1. This demonstrates a missing
obligation in a proposed distinct-parent-only universal enumeration, not a new
failure of the existing explicitly ground-only writer.

## Audited scope

The auditor deduplicates whole compound ledger clauses up to alpha-equivalence,
then visits every unordered pair INCLUDING each clause paired with itself and
every ordered choice of pivot positions. Parent-support alternatives are not
discarded: the proof kernel authenticates all actual Cartesian combinations.

Pivot feasibility is checked separately from the kernel substitution algorithm:
a finite equality graph connects corresponding argument positions and repeated
variables within each parent. Transitive closure detects any component containing
semantically unequal ground values. Variables in opposite parents never share
an identity. Same signs, differing predicates/arity and incoherent repeated
variables create no obligation. This is structural flat unification, not sampling
of known values; all admissible values remain in scope.

For each feasible pair the kernel constructs the required conclusion and exact
whole-source/depth recipes. Every required recipe must appear in successful
supplied kernel Evidence bound to the same input Frontier and target Snapshot.
The auditor independently enumerates obligations and tests pivot feasibility;
it deliberately reuses the checked kernel for conclusion construction, so this
is not an independent proof of that kernel's substitution implementation.
Equivalent conclusions with the same exact Support can discharge the same
obligation. Invented caller Product/Support objects cannot authenticate evidence.

One shared work budget spans enumeration, equality checking, kernel calls and
matching. The package-private kernel overload accepts that budget instead of
resetting it per pair. Depth, work, invalid evidence, missing consequences and
pivot arity above256 return covered=false, never a partial success. Supplied
evidence is copied before auditing. The result contains no proof prefix.

Universal unit conclusions are obligations and can be discharged by detached
proofs; this does not relax the existing unit-transport refusal. Unit PARENTS,
factoring as a separate inference rule, function terms with variables, existential
witnesses, family completeness and fixed-point admission remain outside scope.

## Validation and next step

The existing universal proof driver now checks missing/foreign evidence, self
pairs, bounds, nonunifiable repeated variables, same signs and universal unit
conclusions. Independent finite interpretations check the self consequence,
including fresh unmentioned values, without imposing finite-domain semantics.
Final validation counts are recorded in the main checkpoint and recovery journal.
