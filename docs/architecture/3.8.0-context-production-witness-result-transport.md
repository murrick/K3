# Stage2y: detached primary-origin witness result transport

## Why separate existential assertions lose information

Given X: exists(p(w,1)) and A: p(x,1)->q(x,1), the derived q refers to X's same
witness. Replaying p and the result as independent exists(p(w,1)), exists(q(v,1))
admits forall(not(p(x,1) && q(x,1))). The original joint result contradicts that
prohibition. The new runner demonstrates both native outcomes. Exporting only
rendered existential atoms would therefore lose a required relation.

## Packet and eligibility

ContextWitnessResultTransport is a qualification-only component. export re-runs
the observed shared-origin join verifier on the owning private Session; callers
cannot supply an alleged verification result. Unsupported verification returns
no packet, and budget/rank/atom/support stops publish no prefix.

A witness Origin is the exact supplied Source occurrence plus its global binder
ordinal in the complete primary conjunction. Source carries context UUID,
revision, source-declaration rule ID, local-X role and effective-view label. The
source rule ID is NOT the rule ID allocated by this replay. No native Mind,
Rule, Domain, projection, route, materialization or replay-local term ID enters
the packet. Ordinary values use immutable semantic snapshots.

This identity assumes an immutable declaration at the supplied source snapshot;
live pin/view authentication is still pending. Cross-role source normalization,
revision migration and general dependent/generated witness identity are not
claimed. These are exact source-occurrence keys within the current family scope.

The packet includes:

1. X's complete primary existential bundles, with their whole depth0 sources.
2. Observed verified products with depth>0 and a complete proof group using X.
   Every physical root must equal its verified original primary root in this
   narrow transport scope. Roots without a primary binding are refused.

A foreign primary bundle is not imported merely to define a result's witness.
Foreign-only products are excluded. An X-dependent product whose original witness
belongs to the foreign context can be exported using that source's Origin key,
without exporting its other primary atoms. This preserves the proof authorities
and avoids importing unrelated foreign knowledge into X.

An Item contains one signed symbolic atom and separate complete Support
alternatives. The minimum depth is retained for an identical source group;
alternative source groups are never unioned into a fictitious joint proof.
Multiple atoms referring to one Origin share it; equal-shaped atoms referring to
different Origins remain separate. The packet and nested lists/source sets are
immutable. There is no mutable builder/constructor available to packet callers.

Limits:64 symbolic atoms,8 represented origins,256 source-group alternatives per
atom. The verifier and packing have separate work budgets of maximumWork each;
restoration has its own maximumWork budget. Native proof depth remains bounded
by the explicit verifier limit. No general inference termination claim is added.

## Restoration and proof ledger

restore creates a fresh disposable in-memory Mind. All included atoms are parsed
as one existential conjunction, with a single binder allocation table across the
whole carrier. Fixed values are projected through placeholders; their rendered
text is not reparsed. A complete readback checks predicate/sign/arity, semantic
fixed values, non-dominating primary root ownership, and a bijection between
Origin keys and the fresh native roots. A mismatch or work stop returns no Replay.

Each Replay has a fresh UUID namespace. Native numeric IDs may coincide between
fresh Minds, so they cannot be cross-replay identity. The detached Origin keys
remain stable. The Replay exposes a read-only origin-to-local-term map and the
unchanged immutable seed ledger. Materialization does not increment rule depth;
it also cannot turn a depth2 proof into a depth0 assertion or erase its sources.

The raw conjunction is a private logical carrier. Its apparent native primary
Rule is NOT authenticated primary proof evidence for the derived seeds. The
separate ledger is mandatory for subsequent verification. No existing capture
entrypoint is widened to label these products as primary. Universal producer
rules, ordinary scalar results and a full X snapshot are not transported by this
component; they remain separate replay inputs.

## Scope and validation

The new runner covers the concrete loss-of-sharing countermodel; same-origin
X/product/chain sharing; alternative whole-source groups and carried depths;
fresh namespaces and repeated restores; changing native allocation order;
foreign primary/product exclusion; X-dependent foreign-origin products;
independent X origins with identical result predicates; signs/fixed values;
immutable packets/supports; depth/work/rank stops with no exposed prefix.

Source Session disposal does not invalidate the packet. Native subsequent
qualification in the private replay confirms the preserved sharing. The packet
is not a model, coverage/SAT certificate, a base-consistency check, live source
pin authentication or a runtime authoring decision. Source labels retain the
same trusted-caller assumptions as previous qualification components.
