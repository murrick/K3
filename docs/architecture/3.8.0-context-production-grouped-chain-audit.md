## Explicit evidence scope

New `ContextUniversalGroupedChainAudit.inspect` takes the actual initial native,
common/private/unit/compound frame, expected local/kernel/fact policies, maximum
rounds and a detached grouped-round Result. It does NOT call the round controller.
It issues a private-constructor Receipt only after independently checking the whole
STABLE_GROUPED_POOLS chain. Receipt stores exact trace and initial frame, with copied
immutable supplied snapshots/private map. `check` repeats the verification under a
fresh declared work bound; no persistent trusted cache or live write authority.

INCOMPLETE and REFUTED cannot receive stable-chain evidence. This checker does not
reconstruct discarded failure histories or independently certify a refutation as a
complete family decision. Existing frame-free checked rejection DAGs retain their
separate scope. A failed audit publishes no successful receipt/prefix. Expected
refusal of an incomplete result is not a proof that its workload saturated.

## Independent semantic replay of every round

For every actual round:

- Replay all local certificates using the existing independent certificate checker.
  Recompute each initial ordinary compound closure under the expected kernel bounds
  on the SAME actual incoming frame and require full clause/exact-Source/depth pool
  equality. This is separate primitive replay, not rerunning the global controller.
- Rebind each signed product audit from its actual coverage/transfer. Compare the
  entire stored obligation inventory and actual theorem/input/Item/Support references,
  not just its bound flag. Check fact depth, unmarked Packets and independently
  recompute common/local transfer change flags.
- Recompute the complete fixed merge from the SAME actual branch transfers. Compare
  exact logical/proof contents, changed/localChanged flags, private cut inventory,
  actual private/common/native identities and freshly rebased local minima, physical
  sources and original declaration inventory anchored to actual initial native seeds. Shared allocation IDs are intentionally
  not semantic equality; the real trace nevertheless requires exact chain pointers.
- Independently collect symbolic units using the expected clause/alternative/fact
  bounds (that carrier does not seal a policy of its own). Compare full minima with
  its actual output. Check both complete actual carrier inventories/rebase receipts;
  compound carrier additionally seals and must match the expected policy.
- Recompute all four change flags from full fixed/private/unit/compound typed contents
  including rigid Origins, exact Source sets and minimum depth. Full unchanged last
  pools plus independently proved absence of earlier stability are required.
