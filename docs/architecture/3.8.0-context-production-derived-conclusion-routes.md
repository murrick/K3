## Proof boundary

The sealed native replay now retains its detached capture Snapshot and actual
restored seed proofs, mapped to fresh native root identities. No live Mind is
retained. These records come from the same successful replay as the exact
producer-proof ledger; callers cannot replace them with same-valued input from
another view or construct a successful replay receipt.

`ContextUniversalDerivedRoutes.reconstruct` consumes only that sealed receipt.
Each observed event is reconstructed from authenticated positive premise routes
and its exact schema proof alternative. The resulting DAG stores producer Proof,
ProducerEvent, ordered premise donors, any actual carried-root binding anchor,
and stored-occurrence crossing. No hypothesis is accepted as a donor.

A conditional conclusion has depth max(schema producer, all donors, binding
anchor)+1 and the union of those exact Sources. A universal unit instantiated at
an ordinary value also adds one level, without borrowing an unrelated X fact.
A ground unit theorem has already been proved by the schema DAG and retains that
proof's depth when materialized; it is never reset to primary depth0.

For a witness unit or head-free conditional, when premises do not already carry
the root, a real seed proof carrying that exact root is required. The seed may
itself be an X-dependent product with private ancestry; origin.Source alone is
not proof authority. Its full Sources and depth enter the conclusion. Independent
roots cannot be joined. Raw private results remain local receipts.

Existing per-occurrence materialization verification matches native producer,
matched literal and exact Support alternatives, with alpha-preserving stored
shape. Each stored route retains the same proof object/depth and a specific
crossing to its verified application; no global root equivalence is introduced.

Closure uses immutable prior pools for donor selection. It keeps minimum depth
for every exact fact/root/Source set, without merging different Source sets.
Per-event conclusion receipts are retained separately from the minimum shared
pool, so an equal cheaper/direct proof does not hide an observed derived
producer's checked donor recipe. Work, route count and conclusion depth are
bounded across retained pools, event and stored receipts; failures return no route/conclusion/materialization prefix.

Ground unit proofs in the replay's complete checked ledger are also projected
into local theorem routes. Native insertion may create no separate Application
for such a fact; the existing symbolic proof is sufficient and no observed
inference event is invented. These receipts remain separate from event
conclusions. Their depth is checked even if a cheaper input proof already exists.

The returned result preserves common/local basis IDs, replay namespace and all
outstanding native schema gaps. It cannot be passed to existing Packet export or
family-coverage APIs. Local observed reconstruction is not a proof that every
required interaction was observed or that all cuts have passed qualification.
