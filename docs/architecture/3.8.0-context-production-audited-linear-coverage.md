# Audited linear Horn qualification coverage

Stage2k adds the explicit inspectWithVerifiedLinearCoverage API and
Coverage.AUDITED_LINEAR_HORN. Default inspect, inspectWithParameters and the
measurement-only inspectWithRotationAudit retain their previous boundaries.
This is qualification-only: no runtime authoring/publication gate is connected.

## Admitted compiled fragment

Every primary occurrence must compile, in isolation, into ordinary scalar
signed units or clauses of the form p(arguments) -> q(arguments). Atoms have
at least one argument. Positions are numeric/named/string constants or
universally quantified variables, with repeated positions permitted. The
entire native Rule, across all branches, has at most two distinct TVariables.
Multiple branches and ground rules are permitted. Nonunit clauses have exactly
one positive and one negative literal.

Non-Horn alternatives, rules with two or more premises, rank3, functions,
calculated/system predicates, witnesses and structured constants remain
outside this profile, including cases where some visits happen to be complete.
This profile is narrower than the older single-variable Horn certificate in
its number of premises, and wider in its permitted variable relationships.
Unsupported inputs return INCOMPLETE without this certificate.

Source occurrences are checked against their isolated compiled branch shapes
again at the actual cut, before linking or transporting any product. A failed
input/roundtrip check stops that cut before it can contaminate NEXT.
Reusing one source label for different declarations
cannot acquire this certificate. This checks caller-supplied declaration
identity, not real persistent effective views or pinned revisions.

## Fixed representative vocabulary

C contains every semantic scalar constant in the whole supplied primary
family. The maximum native rank of that family is fixed before rounds start.
Every parameter pass uses C and that many fresh distinct parameters, even when
the current participant has a smaller rank. Freshness is checked globally and
at each actual cut. Thus participants do not silently certify different
vocabularies as a later participant increases the rank.

This is a finite representative construction, not a finite-domain meaning for
@. For the uninterpreted scalar fragment, a model over representatives extends
to other scalar values by a retraction fixing the representatives and mapping
each other value to one fresh representative. Literal evaluation commutes with
this map: constants are fixed, repeated positions remain repeated, and there
are no interpreted tests/functions that distinguish unnamed values. The
finite reduction preserves consistency of each supplied qualification cut.

Two distinct fresh parameters also preserve independent positions when a
native proof is generalized. Generalization of an ordinary unit-reduction
proof is by uniform replacement of fresh parameters absent from primary
assertions; a repeated parameter remains one variable. Fixed constants never
become arbitrary variables. This argument does not admit interpreted equality,
inequality, type tests, rich terms or C-variable witnesses.

## Conditions for the new certificate

Every participant must reach private proof closure and pass all checks on its
last settled representative replay:

1. Each catalogued quantified Rule/branch has all expected assignments both
   at terminal admission and at database evaluation. Unconfigured, incomplete,
   changed-scope or uncatalogued observations cannot discharge this condition.
2. The supplied native input shapes match the admitted declaration shapes.
   A replayed derived clause has an existing whole-source producer proof.
3. Every representative instance of a signed unit has a proof with its exact
   producer source set and at most its carried depth. Universal instantiation
   has zero additional application depth.
4. For every ground binary clause and every proved opposite unit that removes
   one literal, the remaining unit already has a proof with the union of the
   whole producer and donor source sets, at depth at most max(depths)+1.
   Every alternative support is checked separately. An existing foreign truth
   cannot substitute for a missing joint proof.
5. Opposite ground units cannot coexist without a native collision result.
   If such a pair escapes native analysis, the checker returns INCOMPLETE
   rather than inventing a collision witness.

ContextLinearProofVerifier is read-only. It structurally instantiates clauses
and checks membership of claims already reconstructed from native events. It
never adds a conclusion, proof, assumed predicate or native binding. Missing
obligations return INCOMPLETE; this is not a second production engine or
unification algorithm. Typed semantic values are used throughout.

The positive ground units of a passing pool define a model of the finite
definite-Horn theory: every positive source unit is present, and a true
antecedent has a proved true consequent. Negative source units are present
and have no opposite positive unit. Checking the signed reverse reduction is
stronger than needed for this model, but required for production transport.
Assigning the other atoms false constructs a consistency witness only;
unknown queries do not become negative knowledge.
The source-aware unit reduction checks also establish closure of the chosen
primitive production surface by induction over proof steps. They do not claim
every logically entailed conditional or negative conclusion obtainable through
hypothetical assumptions, arbitrary resolution, or the query/orphan protocol.

Whole support sets and minimum carried depths, not every proof history, are
the closure entries. Existing native application/residual capture and exact
premise reconstruction provide their derivations. No completeness claim for
DMZ proof restrictions, replay cache restrictions or unrestricted Core syntax
is added by this profile.

## Rounds, isolation and limits

The checker runs only after the private pool stops changing. Earlier visits
or missing obligations cannot taint a later complete replay. Any capture gap,
unreconstructed premise, transport mismatch or resource stop still prevents
certification. Native collisions retain priority within the admitted fragment.

Only X-dependent proof groups cross to NEXT. Foreign-only units remain
private, so opposite sibling universals can both be valid relative to X.
All participants consume the same immutable STATE. Certification is returned
only when the outer round adds neither a clause, a support group nor a better
minimum depth. Physical parallel execution is not implemented here.

For the chosen finite vocabulary, compiled rules and source occurrences, unit
claims and support sets are finite. This does not guarantee termination or
complete native CPU accounting. Event, rotation, comparison, proof-work,
round and transported-depth limits remain explicit INCOMPLETE stops.

## Independent evidence

The pure checker controls remove a needed conclusion, change its permutation,
substitute a foreign-only support, increase its depth and omit an alternative
source group. Each fails despite the presence of the relevant truth or premise.
Controls also check signed reverse reduction, an unreported opposite pair and
a universal unit represented by only one instance.

Native controls cover independent and diagonal parameters, typed fixed tuples,
an already-present foreign conclusion, duplicate whole proof alternatives,
opposite independent siblings, two-round conflicts in both orders and a
two-rule three-round conflict in all six orders. A separate Boolean reachability
oracle checks all64 combinations of two directed tuple rules, universal roots
and negative ground units. Unsupported shapes and resource stops retain NONE.

Witness transport, exact effective view/pin checks and shared atomic runtime
gates remain pending. Question3 query/hypothesis/orphans remains open.
