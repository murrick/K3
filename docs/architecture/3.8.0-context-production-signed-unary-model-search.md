## Contract

`ContextSignedUnaryModelSearch` receives an authentic QUIESCENT_SUPPLIED signed branch,
explicit concrete named-value lists for EXACTLY all its logical cuts, and bounded search/audit
policies. It constructs original unary interpretations, then requires the existing original-row
model auditor, then stage483 extension construction and stage482 actual-final semantic audit.
Only the latter's independently issued receipt can be returned. A valid original model alone
never appears as partial success if the final chain fails. No writer/admission path is changed.

The actual branch is freshly audited before inventory. Whole physical original rows are counted
including TRUST members. Per logical cut, the model vocabulary and Source-owned binders come
from X plus that cut's complete original rows, exactly as the direct original auditor requires.
Preflight every cut/whole row and basis before preparing any truth assignment. Supported shapes
remain unary, <=8 clauses/literals, <=1 universal variable/clause or one correlated existential
binder/bundle. Constants must already occur in the supplied basis. Lists are detached, nonempty,
semantically distinct and within original-model bounds. No fresh value or basis expansion is
silently invented. The named points are distinct ordinary values; Origin tokens do not impose
disequality. Different witnesses can choose the same point.

Mixed-radix enumeration covers Boolean cells for every original predicate at all named points
AND the ALL-other-admissible class, and one named-value choice per actual bundle Source. Slices
remain independent: common original clauses are checked in each cut; independent A-X/B-X may
assign private predicates oppositely. TRUST uses one interpretation of ALL physical members.
No inference from A's private fact into B is introduced by model candidate generation.

Each candidate is independently checked against original clauses/bundles. Only accepted original
receipts enter the final extension search. If a candidate's extension fails, the producer tries
the next original candidate rather than treating the original receipt as enough. Every successful
result can be freshly checked through the existing original and final receipt auditors without
replaying this producer. Search counts are diagnostics, not proof metadata or writer capability.

Hard original search limits:512 candidates,16 total original truth cells (ALL-other included),
8 total Source-owned witness choices, explicit cumulative construction work. Original-model rows/
points/predicates/work and extension candidate/cell/Origin/work/final-audit policies are separate
bounds. One native preflight, at most512 original-model audits, and at most512 nested extension
searches (each <=64 full final audits). This is bounded work, not a performance/scale promise;
child audit budgets are NOT one shared cumulative work counter. Highly exponential cases return
INCOMPLETE well before full space traversal. Larger models can exceed this construction profile
even though the original/final auditors support them.

CONSTRUCTED_FINAL_UNARY or atomic INCOMPLETE, never logical REFUTED/conflict. Failure includes
candidate/work/shape/coverage limits and complete exhaustion of the GIVEN fixed-basis space.
Uniform outside truth is a candidate model class, not a universal no-model theorem. Callers must
not turn failure into rejection on logical inconsistency grounds.

## Concrete checks

A positive original fact rejects all-false candidate before passing. Universal p requires both
named and ALL-other cells true. A signed joint bundle shares one assignment; separate Sources
may coincide. A theory with one positive and one negative existential p has no one-point model,
but the SAME actual completed branch has a checked two-point model. Therefore even exhaustive
fixed-one-point failure cannot justify a logical conflict claim.

Generated mark absent from original self vocabulary requires a separately constructed final
extension. With a one-candidate extension cap, valid original receipts do not bypass the failed
final chain and no prefix receipt escapes. Independent opposite A/B truths are constructed in
both family orders. A satisfiable TRUST aggregate keeps both physical member rows in one model.
