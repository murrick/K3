## Permanent corrections

### Close failure isolation

```text
red run: 30652087087
fix: 7ca03945ec1eecf0f97e76c4953f348c3dc20600
permanent gate: DUMB close failure isolation invariant
```

Every Base now receives an independent close attempt. Successfully closed bases
are removed immediately; only failed resources remain retryable. Multiple
failures are preserved through suppressed exceptions.

### Reversible reindex publication

```text
red run: 30652541987
fix: 05f4cb953a1b8acdcb345c593ca5db38810ef6cb
aligned permanent gate: 33f4e3d31a00de2ce58cc58339e3417373121fcd
permanent gate: DUMB reindex swap atomicity invariant
```

Live core files are backed up before temporary files are installed. Any runtime
publication failure restores the live generation and returns already installed
files to the temporary generation. This is exception atomicity in the running
process, not a new crash-atomic filesystem transaction guarantee.
