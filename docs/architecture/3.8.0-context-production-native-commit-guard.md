root inventories, including all retained Source alternatives. Capacity1 replay is supported.

upper bound on replay work. These are immutable detached graphs, not hostile-reflection
serialization or tamper-proof public capabilities. A historical evidence check verifies its
historical request; only the owning provider can qualify a current actual pending child.

Binding/currentness preserves stage455 full physical member inventories, trusted grouping,
original Source provenance, pins/initialization, raw lease topology identity, and separate
retained rollback sibling ownership. The proposed refresh excludes retained assertions.

## Integration boundary

This is opt-in package-private infrastructure. Default `validateCommit` and writer selection
are unchanged. QA installs an IData proxy at actual transaction validation, invokes the new
guard for the physical root's pending child, then delegates to existing validation. Nested
user preparation is left to its existing lifecycle. The guard itself performs no settlement.
This qualifies real rejection/publication/rollback/reopen behavior without enabling the new
path globally. No earlier architectural defect is claimed here.
