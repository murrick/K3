# Stage3ao: complete family barriers for universal unit carriers

ContextUniversalUnitRounds is a new opt-in immutable family transport path for
unit-resolution inference. It has separate private Frontier/Receipt/Barrier
constructors. Existing ground/ordinary-compound Frontiers, certificates, writers
and default authoring are unchanged. This is not general universal admission.

## Same common input, private unit closure

start authenticates actual native-bound X and up to15 distinct foreign contexts,
including whole universal unit declarations, with the existing role/source/view
checks and witness exclusions. No original foreign row is exported at start.

inspect opens a sealed private ledger from exactly X, the selected cut and the
common carrier pool. It runs immutable unit steps to an unchanged recipe set
under bounded local rounds/depth/work. Opening, every local proof step and its
independent unit audit share the same work budget. The cap is not reset per
local pass. Fresh local rows may feed the next private step but never another
sibling inside this common round. Private foreign-only intermediate results are
retained while closing the cut, so their later influence on an X rule is not lost.

Only positive-depth rows with an original X Source leave a successful cut.
Independent source groups and minimum cumulative depth remain intact. Whole
universal unit clauses are transported as schemas, without known-value sampling.
A private proved opposition is relevant to this family verdict only if its proof
depends on X. Foreign-only private inconsistency currently returns INCOMPLETE;
it is not silently ignored or relabelled as a candidate-specific collision.
Local bounds/errors expose no product/opposition prefix.

## Complete exact-input barrier

merge first requires exactly one verified receipt per cut, including X itself.
Every receipt must bind the exact Frontier object and target Snapshot. It checks
all receipt carrier/opposition depth and provenance bounds before any collision
verdict. Missing, duplicate, stale, wrong-cut or failed receipts block the entire
barrier, even if other cuts already have successful products or oppositions.

A complete family with an X-dependent private opposition returns COLLISION,
with exact sourced typed proofs and no next Frontier. Otherwise the barrier
merges only qualified carriers, preserving all source alternatives and minimum
depth per group under64-clause/256-proof bounds.

The combined pool is separately scanned for opposite unit schemas. An independent
argument-position equality graph determines feasibility; the unit kernel then
constructs every actual source-bound opposition in a sealed self ledger. Thus
opposites independently produced by A and B can collide in the SAME common
barrier, without adding raw sibling declarations to that self ledger. Unequal
constants/repeated-variable incompatibility do not create collisions. Failure to
prove a feasible opposition or exhausted work/depth returns INCOMPLETE, not a
partial collision prefix.

MERGED returns a new immutable Frontier with a previous-input identity and changed
carrier recipes. It does not certify compound saturation or write admission.
The next round qualifies each carried schema against every private cut again.

## Concrete controls

X @x p(x), A @x p(x)→q(x), B ~q(9): barrier1 carries generic q with exactly X/A
Sources at depth1. B cannot see q during its first private evaluation. Barrier2
proves opposition with exactly X/A/B Sources, in both A/B and B/A orders. Value9
need not be present in the producing cut.

X @x trigger(x), A trigger→p, B trigger→~p: both generic results are independently
qualified and their opposition is proved in barrier1 with all three Sources.

An unrelated X plus A @x p(x) and B ~p(9) yields no common products and no family
collision: raw sibling knowledge remains separate.

X q→done, A @x p(x), p→q, B ~done(9): the foreign-only q stays private but feeds
the X rule, producing generic done with all three original Sources at depth2.
The next common barrier detects the four-source collision. Recomputing private
closure prevents loss of the unexported q intermediate.

The driver additionally checks missing/duplicate/stale receipts, incomplete-cut
blocking of a prospective shared collision, local-round/work/depth bounds, merge
bounds, immutable inventories and wrong-cut input. A unit-stable compound-only
example explicitly retains admission-unknown status, demonstrating the scope
boundary rather than claiming a universal fixed point.
