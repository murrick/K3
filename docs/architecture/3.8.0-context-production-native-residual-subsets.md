# Stage2o: observing partial reductions during fully matched native visits

## Concrete observation gap

Stage2n's eight-case ground oracle exposed three consistent cuts returning
INCOMPLETE horn-residual-proof-missing. With a(1), b(1), a&&b->r, native linking
produced r(1) with the complete three-source group at depth1, but exported no
partial two-literal residuals. A whole X/a/b proof of r cannot establish the
smaller X/a proof of b->r or the X/b proof of a->r. The earlier observer only
called compoundResidual when no terminal production occurred and more than one
candidate remained. A fully matched rule bypassed that hook.

## Opt-in native observation

ContextProductionCapture.observeResidualSubsets enables a new observation hook
at the native linkDatabase visit, after domain classification and before
terminal production and waiter-based hypothesis preparation. The default path
is a fast no-op; only the explicit audited Horn reference enables it.

For each nonempty proper subset of literals that native matching has already
marked excluded, it records a Residual with:

- the remaining literals under the actual current native binding;
- the opposite ground facts of exactly those excluded literals as premises;
- the producer's complete source support alternatives and carried depth.

This is a projection of a witnessed native match into proof obligations. It is
not an independently compiled native production or a durable rule insertion.
Residual events do not themselves assert that premises are proved: existing
closure must reconstruct each premise from its proved pool and join its whole
support groups with the producer. Missing premises stop qualification. Shape
metadata, waiter assumptions and absent matches cannot supply those premises.
No excluded flags, bindings, generated native rules or query answers are changed
by the hook. Foreign-only residuals still cannot enter X/NEXT.

The hook is bounded to three branch literals, at most six proper subset events
per visit. Larger branches stop certification with a scope gap. Every event
consumes the existing participant event budget. Signed facts, unbound remaining
universal variables and producer alternatives use the existing capture helpers;
nonordinary evidence reports a gap. Query passes outside CHECK/ACCEPT are ignored.
This remains ordinary scalar qualification; no DMZ proof-restriction completeness
or runtime write-gate integration is claimed.

## Regression evidence

A direct capture control compares the same native full match with the option
disabled/enabled: default capture has no two-literal residual, enabled capture
records each one-premise residual and the joint reduction. Producer labels are
exact and donor proofs remain reconstruction obligations. No input facts yields
no residual events despite waiter processing. Other controls cover negative
head exclusion, duplicate source inputs and event-budget exhaustion.

The existing independent eight-case Boolean oracle now certifies all seven
consistent cuts and returns a native collision witness on a,b,~r. The mask3
control additionally requires each separate X/donor partial support at depth1
and preserves the original complete depth1 unit proof. Existing all-six-order
collision, cross-sibling depth2 join, source alternatives and independent sibling
controls remain active. The stage2n INCOMPLETE observations remain historical
counterexample evidence, not current expected outcomes.
