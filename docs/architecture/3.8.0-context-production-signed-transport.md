# Stage3t: sealed signed productions at common ground barriers

## Scope and authority

ContextGroundProductionRounds.start freezes exact native-bound X, self and every
selected foreign cut, validates all supported declarations before any pass, and
creates an empty shared production frontier. No raw foreign unit is lifted.
Frontier construction is private; its immutable input identity, scope and
production proof ledger are carried by authenticated branch Results. The legacy
single-cut observation API remains available but its independent receipts cannot
be reused at another barrier.

Each cut inspects the same Frontier. A fresh private runtime restores each
carried ordinary semantic literal once before capture starts. Original proof
alternatives and cumulative depths are separately imported as proof donors,
never relabelled as new depth0 primary rules. This runtime then receives only X
and that cut's own sourced primary declarations. New native applications still
undergo whole source/instance authentication and sound proof reconstruction.
Only proved X-dependent productions are shared; pure foreign knowledge remains
local, even when it supplies an actual premise for an X-dependent proof.

Merge requires one verified result for self and every exact selected cut, all
from the same input object. Missing, duplicate, stale, out-of-scope or stopped
results produce INCOMPLETE without a frontier or collision prefix. Complete
outputs retain each exact source-set alternative at its minimum observed depth.
Proof/atom/work bounds remain explicit. The merged frontier has a new identity
and points to its common basis, so old branch results cannot be replayed there.

## Refutation evidence

Before replay, a cut compares carried signed productions with its actual ordinary
primary unit clauses. Exact semantic opposite literals yield immutable evidence
with both original proof groups and their depths. Opposite X-dependent products
from complete sibling outputs are also detected at merge. All expected branch
results must authenticate before a family collision is returned.

For the original masked fixture:

- Common input0 has no lifted raw facts. X–B proves negative left(1) from the X
  rule, B right(1) and B negative p(1), depth1.
- Barrier1 shares that proved literal only. A has not seen it during input0.
- At input1, A's actual positive left(1) (depth0, its own Source) opposes the
  carried negative proof. Barrier2 returns COLLISION with exactly four causal
  sources. Reversing A/B order preserves the refutation.

Opposite raw sibling p facts with unrelated X still yield no shared production
or collision. Different ordinary argument values cannot form an opposition.
A shared negative literal can also feed a signed native rule in another cut,
retaining all four sources at depth2.

## Checks and remaining work

Controls cover original sourced refutation and order reversal, missing self,
wrong/duplicate/stale/independently-created receipts, cumulative depth and event/
work stops, withheld collision prefixes, two independent proof alternatives for
one restored semantic literal, cyclic source unions/minimum depths, immutable
scope/ledger, and unsupported later-source preflight.

The executor reports MERGED / COLLISION / INCOMPLETE. An unchanged MERGED pool
explicitly does NOT certify closure, consistency or admission. The next required
step is signed round coverage obligations and a final closed family verdict,
including native missing-result/refusal handling, before candidate/default gate
integration. Neither the existing candidate family path nor ordinary authoring
is redirected in this stage. The original default contract remains last stage3r
RED56/2. Question3 and broader language/TRUST/new-witness coverage stay open.
