# Проверка арифметических подключений в Console

Из корня репозитория, с Python 3 и JDK:

```sh
python3 scripts/qualify-context-production-rounds.py --prepare-arithmetic-console
```

Открой напечатанный каталог пакета и запусти `python3 console.py`. Можно
перенести весь каталог на другую машину с Python 3 и Java: пакет содержит
классы, ресурсы и библиотеки. Данные Console хранятся в его каталоге `home`.
Повторный запуск открывает те же данные, повторная сборка создаёт новый каталог.

Подавай команды из `arithmetic-console.commands` по одной или, для первого
прохода на чистом пакете, запусти `python3 console.py < arithmetic-console.commands`.

1. Создай Rules с правилом `seed(x)&&gate(x)->next(x+1)` и Gate с фактом
   `gate(1)`.
2. В X введи `seed(1)` и `~next(2)`, подключи Rules и опубликуй подключение.
3. Подключение Gate должно быть отвергнуто. Из X и Rules выводится
   `~gate(1)`, которая конфликтует с фактом Gate.
4. Сравни вывод `ctx` до отказа, после него и после повторного открытия X.
   Сохранённое подключение к Rules должно остаться единственным.
5. В XReverse подключи Gate первым. Теперь отвергается Rules с тем же
   конфликтом, а сохранённое подключение к Gate остаётся единственным.
6. В XCompatible замени отрицание на `~next(3)`. Оба подключения должны
   пройти и сохраниться после повторного открытия.
7. Для проверки после полного выхода запусти `python3 console.py` снова
   и выполни `storage use X`, затем `ctx`. Должен остаться только Rules.

Это пакет для проверки квалификации подключений в поддержанном арифметическом
фрагменте. Он включает экспериментальный обработчик топологии. Обычная запись
использует штатный маршрут. Общий обратный арифметический вывод, универсальные
остатки с несвязанными переменными и полная приёмка DMZ сюда не входят.
