## Bare `?` semantic invariant

Bare `?` is a special Core-level whole-program check, not an empty query.

The canonical Core path is:

```text
Mind.query("?")
  -> queryCheck()
  -> remove/refresh generated state in a child Mind
  -> link(null)
  -> analyze(null)
  -> commit on success
```

Late ingress repairs ensure the literal one-character request reaches this Core
path both from the standalone Java Console and from the Server/Browser dialogue
path. The Server path must not wrap bare `?` in the ordinary informational
request child and subsequently release it, because that would discard the
internal `queryCheck()` commit.

## Late stabilization fixes

### Browser file Save boundary

The iframe sandbox remains exactly:

```html
sandbox="allow-scripts"
```

No `allow-downloads` or `allow-same-origin` capability was added. Local Save is
implemented through a parent-owned file-download broker: the child sends only
sanitized filename and source text; the parent performs the browser download and
acknowledges initiation. This removed the previous false-positive `Saved ...`
status under the opaque sandbox.

### Bottom presentation layout

One final layout authority now owns the dynamic bottom strip:

```text
Results -> Solutions -> Hypothesis -> Log
```

Hidden panels leave the strip, splitters are rebuilt only between adjacent
visible panels, newly visible panels receive sane geometry, and proportions are
persisted/restored without competing layout authorities.

### Standalone Console authentication

The Console-owned `UserFactory` previously understood only the historical
Java-hash credential records while Server/Admin now use versioned PBKDF2
credentials. Console authentication now accepts current `v2` records and legacy
records. Console-created credentials are written in the current format, and the
`singleuser` account is provisioned only for explicit `-S` mode.

### User dropdown

The historical immediate `mouseout -> hide` behavior was replaced by stable
mouseenter/leave handling with a short delayed close. Moving from the user name
into the menu or between child items no longer collapses the menu.

### Predicate information UX

The accepted late predicate UX uses the informational `ⓘ` projection. Predicate
rows remain compose-only. The qualification contract was aligned with this
behavior rather than requiring the older `base predicate ...` action string.

### Development Browser artifact manifest

Late presentation support introduced four explicit adapters:

```text
bottom-layout.js
editor-local-file.js
file-download.js
layout-persistence.js
```

The development `html/` artifact therefore contains 22 files, not the original
18-file 3.7.0.5 development snapshot. The Server workflow now qualifies the
actual 22-file development Browser, including syntax and authority-boundary
checks for the new adapters. This does not change the immutable accepted
3.5.2 deployment contract, which retains its historical 15-file Browser
artifact.
