# Экспорт TValue: контроль без JIT/GC logging

Ветка `experiment/3.8.0-tvalue-export-no-logging`.
Родитель `66413653cf3764821b0bdd14d784226a281a834a`.
Native остаётся `2422f7f6d9e1af7608203b1566df64b5f29fe344`.

## Что проверяем

Предыдущая серия с LogCompilation и GC logging не воспроизвела сигнал
замедления экспорта на 32 значениях. Здесь logging отключено полностью,
добавлен контроль на 128. Сравниваются те же frozen context-snapshots jar
(baseline) и TOUCH strings jar (candidate), тот же ExportPhaseRunner и
fast-disabled hooked runtime. Исходники и классы драйвера не меняются.

48 JVM: default/batch ×32/128×6 пар. Внутри каждой пары порядок модулей
чередуется; порядок размеров и профилей также чередуется. `-Xbatch` — только
экспериментальный режим компиляции, не изменение production defaults.
Никаких LogCompilation, LogFile, Xlog, PrintCompilation или PrintInlining.
Отсутствие флагов логирования проверяется анализатором для каждой команды.
Точные JIT уровни в этой серии не наблюдаются: одинаковый режим компиляции
не гарантирует одинаковый скомпилированный код. Прежний факт C2 для batch
не переносится автоматически на эти JVM.

64 warmup/128 measured blocks, восемь export циклов на блок. Итого 49152
измеренных циклов и 6144 total blocks; каждый блок имеет восемь фаз.
Phase wall/CPU/allocation timers сохранены: это отсутствие JIT/GC logging,
а не отсутствие любой измерительной нагрузки. Счётчики CPU total не читаются
(поле 0), остальные фазы измеряются как в предыдущем драйвере.

## Проверки

Все 48 JVM завершились успешно, stderr пуст. Все native контроли совпадают
с прежним эталоном, 48 полных export traces совпадают побайтно и проходят
authority replay. В каждой JVM повторяемость полного export проверяет сам
драйвер. Обе authority проверки включены; owner и захваты освобождаются.
Jar hashes и fixture class hashes совпадают с frozen manifests. Native pin
чистый; runtime hashes совпадают с frozen fast-disabled manifest. Все tracked
parent файлы, включая production, runtime и диагностические исходники,
остаются побайтно прежними. Failure/wiring/context серию заново не запускали,
поскольку исполняемый diagnostic код не менялся.

## Время

Сначала медиана 128 блоков внутри JVM, затем медиана отношений шести пар.
Числа ниже не равны отношению общих медиан модулей.

| Профиль | Значений | Candidate/baseline wall | Диапазон пар | Пар медленнее |
|---|---:|---:|---:|---:|
| default | 32 | 0.979 | 0.836–1.069 | 3/6 |
| default | 128 | 1.001 | 0.856–1.127 | 3/6 |
| batch | 32 | 1.018 | 0.952–1.063 | 3/6 |
| batch | 128 | 0.967 | 0.870–1.034 | 2/6 |

Серия относится к resident diagnostic export на одном контексте, не к
пропускной способности inference. Хост общий, без pinning и эксклюзивного
доступа. Разные серии нельзя объединять как одинаковые условия: logging,
даты и конкурирующая нагрузка менялись. Статистическая значимость не заявлена.
CPU timings и per-phase measurements сохранены в summary и CSV.

В этом контроле прежнее замедление export-32 не воспроизвелось как
устойчивый однонаправленный эффект: default даёт около −2.1%, batch +1.8%,
в обоих профилях медленнее ровно три пары из шести. Для 128: default +0.1%,
batch −3.3%. Это не доказывает ни ускорение, ни эквивалентность. Открытый
сигнал можно закрыть как невоспроизводимый в текущем ограниченном контроле,
сохранив все прежние данные и ограничения. Продвижение кандидата в основную
ветку этим этапом не выполняется.

## Allocations

Парная экономия байт на фазу из восьми setters (mutate_b и mutate_a):

| Профиль | Значений | Mutate b | Mutate a |
|---|---:|---:|---:|
| default | 32 | 2720.00 | 2720.00 |
| default | 128 | 2816.00 | 2816.00 |
| batch | 32 | 2432.00 | 2432.00 |
| batch | 128 | 2816.00 | 2816.00 |

Эти результаты дополняют прежние callback allocation проверки. Расход памяти
целого export включает полные authority views и финальную сверку, поэтому
его изменение не равно только экономии формирования TOUCH. Не следует
распространять allocations на регистрацию большого числа контекстов или SMART.

## Воспроизведение

Сначала восстановить frozen модули и драйвер по
[tvalue-export-phase-study.md](tvalue-export-phase-study.md) и
[tvalue-journal-touch-strings.md](tvalue-journal-touch-strings.md).
Этот этап не компилирует и не заменяет модули. Java 17.0.20.

```sh
python docs/tvalue-export-no-logging/run.py
python docs/tvalue-export-no-logging/analyze.py
python docs/tvalue-export-no-logging/manifest.py
```

Не запускать timing вместе с другими benchmark процессами. Сохраняются
команды, environment, stdout/stderr, исходные CSV, native контроли, полные
export traces, парные результаты и SHA256 manifest.

## Границы решения

Производственные настройки и develop не менялись. TOUCH остаётся отдельным
экспериментальным кандидатом; общий end-to-end выигрыш не установлен.
Следующий шаг — проверка диагностического кандидата на прикладной resident
нагрузке, с сохранением exact native результатов и обеих authority проверок.
Дальнейшие повторы одного микротеста без новой гипотезы не требуются.
SMART persistence, полный inference corpus и native root-clear ID repair
остаются открытыми.
