org.kanger.interfaces

Interface IArgument


  • public interface IArgument
    Элемент строки аргументов - параметров предиката, функции, гипотезы или решения. В общем случае представляет собой объект типа терм, t-переменная, u-переменная, функция, вариант подстановки t-переменной или вариант результата функции. Объект может иметь текущее значение типа терм.
